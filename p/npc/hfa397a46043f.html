なにか確認したい事はあるかな？
あたしは、戦闘は苦手なんだけど
皆をサポートする事だけは自信があるの！
そんなあたしは、サポートの基本
回復についてを教えてあげる！

選択肢: 「01.体力の回復方法」 ／ 「02.お腹の減りと喉の渇き」 ／ 「03.自然回復について」 ／ 「04.ポーションについて」 ／ 「05.包帯について」 ／ 「★ 包帯・ポーションを実践する」 ／ 「06.ショートカットについて」 ／ 「07.マクロ(登録内容)の編集について」 ／ 「メニューを閉じる」

「01.体力の回復方法」

体力の回復方法は、色々あるよ。
自分の治癒力 自然回復スキル を使って
その場に座って回復する方法。



回復薬(ポーション) や 包帯 みたいに
アイテムを使って回復する方法などなど…
魔法 を使ってドバーン！と回復する方法
なんてのもあるけど、これはボクの専門外。



キミが一人で旅をするようになったら
知る事ができると思うよ。
一人の人間が覚えられる スキルには限度 があるから
回復薬や包帯、もしくは自分の治癒力を回復手段にして
いろんなスキルを覚えるってのも手だよね！

「02.お腹の減りと喉の渇き」

お腹の減り(満腹度) や 喉の渇き(潤喉度)は
自然回復の体力の回復量に影響があるの。



もし飲食しないで放っておけば
お腹(満腹度)が減る し 喉(潤喉度)が渇く よ。
満腹度 が 0 になれば
ヒットポイント(HP) マナポイント(MP) の
座った時の自然回復量 に影響して
潤喉度 が 0 になれば
スタミナ(ST) の 自然回復量 に影響するよ。
食べ物・飲み物 は
飲食すれば色々な効果が発揮される物もあるけど
それ以上に 満腹・潤喉度 の減り具合に気をつけてね。
ちなみに、ちょっとだけ豆知識！
筋力 スキル が高くなると 満腹度 の
精神力 スキル が高くなると 潤喉度 の
それぞれ 減少スピードが速くなる からね。

「03.自然回復について」

自然回復スキルは、自己の治癒能力が頼りのスキル。
スキルを伸ばせば、アイテムを使用しなくても
すごいスピードで回復できるようになるから
アイテムを買うお金が浮いて経済的♪
自然回復は、立っている時より座った方が
体力の回復が早くなるよ。



キーボード の Ｘキー を押せば
座る事ができるよ。
立つときも一緒だから、覚えておいてね。
モンスターに囲まれてると
なかなか座れないから大変だけど
これも一つの回復手段！
初めのうちは重宝するよ♪

「04.ポーションについて」

ポーション は、その場で素早く回復するための
とっても便利な回復手段！



ヒットポイント、マナポイント、スタミナを回復する
３種類の回復薬 や、敵を攻撃する 毒薬 もあるし
死んだ人を蘇らせる 蘇生薬 もあるんだ。
注意として、回復薬 は自分にしか使用できないから
友達を回復するなら、他の回復手段を考えてね。



それと使用後は、10秒程度待たないと
次の薬や包帯が使えないよ。

「05.包帯について」

包帯 は、巻くのに時間が掛かるけど
包帯スキル が高くなると
ヒットポイントがものすごく回復するよ！
それと ポーション は自分しか回復できないけど
包帯なら、友達も回復させることが出来るんだよ。
巻くには時間が掛かるけど
状況を考えれば、安定した回復を望めるよ♪

「★ 包帯・ポーションを実践する」

所持枠に空きが無い ため
実践に必要なアイテムを渡せません。



必要のないアイテムは
売る 捨てる 預ける 等を行い
整理してください。
アイテムを捨てる場合 は
捨てるアイテムをクリックして掴み
Item ウィンドウ 内にある ゴミ箱 アイコンを
クリックする事で、捨てる事ができます。
実践メニューを開始できませんでした。
それじゃあ、実際に試してみようか♪
包帯 や ポーション の使い方は簡単だよ。



回復する相手 を クリックでターゲット して
Item ウィンドウ からマウスで掴んで
USEボタン を押すだけ。
使用すると アイテム使用ゲージ が表示されるから
ゲージがなくなれば使用成功！
それじゃあ今回は 包帯 でチャレンジ♪
包帯を キミ自身 に使ってみようね！



まずは 自分をターゲット して
Item ウィンドウ を開いて
包帯を掴んでUSE してみてね♪
自分をターゲットしていません。



自分自身をクリックし
ターゲットを変更してください。
包帯 や ポーション の使い方は
Item ウィンドウ からマウスで掴んで
USEボタン を押すだけだよ？
それが アイテム使用ゲージ 。
ゲージが 0 になると、体力が回復されるよ。



注意として ゲージ が表示されている間に
攻撃を ３回 受けると
アイテムの使用がキャンセルされちゃうからね。
本来は 移動 や テクニック を使うこともできるから
包帯を巻きながら敵と戦ったり
移動しながら回復 することも出来るよ。
はい、これでアイテム使用については終了！



ショートカットにアイテムを登録 して
マクロ機能を編集 すれば
もっと簡単に 包帯 を使えるようになるよ。
マクロ機能の編集については
また後で説明するから
興味があったら是非聞いていってね。
チュートリアル終了報酬 を
銀行 へ転送しました。

「06.ショートカットについて」

それじゃあ最後に
アイテムの ショートカットへの登録方法 と
登録内容を編集する マクロ機能の編集 を教えるよ。
何度も使うような アイテムやテクニック を
使うたびにウィンドウから選ぶってのは面倒だよね。



ショートカット や マクロ は、そんな面倒な動作を
ボタン一つで簡単に行えるようにする便利な手段なんだ。
登録方法は簡単♪



画面右や下にある Menu / ショートカットバー に
よく使うアイテムやテクニックを マウスで掴んで
空いている枠に 持っていく(クリックする) だけ。
これで登録完了！
あとは Menu / ショートカットバー のアイコンを
クリックするだけで、アイテムやスタミナが続く限り
登録したものを簡単に使うことができるようになるよ。

「07.マクロ(登録内容)の編集について」

登録したアイコンをクリックしても
包帯は、ターゲットしている相手に巻いちゃうから
戦闘中だと敵に巻いちゃうんだ。 もったいないっ！



だから 包帯で自分を回復したい時 は
使う度に自分をターゲットしないとダメなんだ。
そんな時は 登録内容を編集する といいね。



登録内容を編集すると
自分にだけ包帯を巻くショートカット なんかに
作り変えることもできるよ♪
そんなショートカットの登録内容は
登録したアイコンを 右クリック すると表示される
MacroEditor(マクロ編集) 画面から編集できるよ。
仮に ビギナーズ バンデージ を登録しているなら
MacroEditor(マクロ編集) 画面には
"/useitem [ビギナーズ バンデージ]"
と表示されているよ。
これを 自分にだけ包帯を巻くショートカット に
作り変える場合は
"/useitem [ビギナーズ バンデージ]" を
"/useitem [ビギナーズ バンデージ]<1>" と
編集して OK を押せばいいんだ。
"<1>" って言う文字が
ターゲットを自分にする って言う意味に
なっているんだよ。
ちょーっと、最初は難しいかもしれないけど
慣れればすごく便利になるから試してみてね。
包帯をプレゼントするから
よかったらチャレンジしてみてよ！
