会話（ムトゥーム地下墓地）

マブ教の神殿には、行ったか？



ソウル・バインダー が居るから
魂の復活場所(ホーム・ポイント)を、変更せよ。
同じく神殿の前に、水と食料をタダで配っている
同志 ニーナ(Nina) がいる。
1度は声をかけて、みるといいだろう。



血塗られた御手に栄えあれ……
ギルド・ランクの上げ方について
説明しよう。良く覚えておけよ…



ギルド・ランクというものは
２つの項目を見て判断されている。
まず１つは、仕事(クエスト)をこなして貰える
ギルド・ポイントの数値 だ。



これはギルドへの貢献度を表している。
２つ目は、ネクロマンサーになるために必要な
４つのスキルの平均値 だ。 これは重要だ。
意識して４つのスキルを鍛えるようにせねばならぬ。



血塗られた御手に栄えあれ…

その他のセリフ:

マブ神 の祝福を受けた品物ばかり。



すぐに無くなってしまう 触媒 は
神殿の横にある部屋で、まとめ買いせよ。
クエスト内容が分からなくなったら
オカ…、いやギルド・マスターに
右クリック で合図せよ。
[暗使]に関して、分からない事があれば
アルターがある部屋の近辺にいる
マラクス(Marax) に聞いてくれ。



血塗られた御手に栄えあれ……
この部屋を出て右側のエリアに 銀行 がある。
[暗使(あんし)]と合わせて、利用するといいだろう。



血塗られた御手に栄えあれ……

会話（城下町ビスク ビクトリアス広場）

私はかつて暗使ギルドに仕えていた者だ。



他のギルド員には申し訳ないと思う。
しかし、私には仕えなければいけない人がいるのだ。
ザイオン 様も私も、あえて語ることは無いが
今はザイオン様の進む道についていく事のみ。



知りたいことがあれば 我が主に変わってお伝えしよう。
この坂の先に、モラ族が用意した Buffエリア と
呼ばれるエリアがある。



そこには二人のモラ族の子供がいる
そちらの世界で分からないことがあれば
そこの二人に聞くといいだろう。

選択肢: 「タイタンの力と制限」 ／ 「模擬戦について」 ／ 「ポイントについて」 ／ 「ボーナスポイントについて」 ／ 「段位とは」 ／ 「タイプの選別」 ／ 「メインパーツについて」 ／ 「サブパーツについて」 ／ 「拡張パーツについて」 ／ 「組み合わせについて」 ／ 「ノア・タイタンに乗るために」 ／ 「やめる」

「タイタンの力と制限」

この先の Buffエリア と呼ばれるエリアで
ノアの力を授かると、自身の回復能力は全て停止される。
スタミナが減ろうとも、生命力が無くなろうとも
その場に座って回復、という行為は全く意味が無くなる。



自分の体力やスタミナには、細心の注意を払って
行動することが必要となる。
体力等を回復をさせるには、ノアの力を回復させる
特殊な回復アイテムを使用するか
巨人の研究の中で復活させた 【回復の泉】
と呼ばれるノアの奇跡を利用してくれ。

「模擬戦について」

小型化したノア・タイタンのパーツに慣れてもらうため
ダーイン山で実戦形式の模擬戦を行っている。
パーティを組むこと以外は、エリア内に入れば
やることはほぼ自由だ。



あらゆる状況下で、常に自分の身を案じながら
戦い続けるのだ。

「ポイントについて」

模擬戦のエリアで相手を倒すと
倒した相手の段位に応じた
戦績ポイント を入手することができる。
倒した相手の段位が
初段 であれば 1 Point
二段 であれば 2 Point
三段 であれば 4 Point
と言った感じだ。
もちろん自分が倒されてしまった場合も同じように
自分の段位に見合ったポイントを失ってしまうから
気を抜くんじゃないぞ。

「ボーナスポイントについて」

模擬戦エリアで、相手を連続で倒し続けると
チェインキル というものがカウントされる。



このカウント数は、一度こちらの世界に戻るか
倒されてしまうことでリセットされるぞ。
エリア内に居続けて、相手を一定の回数倒し続けると
チェインキルボーナス として
戦績ポイントにプラスしてボーナスポイントを
入手することができるようになっている。
連続で倒した数が
5回以上 であれば +1 Point
10回以上 であれば +2 Point
20回以上 であれば +4 Point
と言った感じにボーナスされる。
効率よく相手を倒していくことができれば
ポイントも自然と増えていくことだろう。

「段位とは」

段位 とは、現在の戦績ポイントに応じて
自動的に決められるランクのことだ。



タイタンの力を、どれだけ自由に扱えるようになったか
ひとつの目安となるだろう。
初めは 初段 から始まり、ポイントが
10Point になれば 二段
30Point になれば 三段
100Point になれば 四段
と言った感じだ。

「タイプの選別」

ノア・タイタンのパーツは
それぞれ異なるタイプとして分けることができる。
基本能力のメインパーツのタイプは４つ
補助的なサブパーツのタイプは４つ
各５部位の拡張パーツのタイプは６つ
用意されている。
言葉として聞けば、数が多く大変かもしれないが
それぞれのパーツの特徴をよく知り
自分の扱うパーツを選ぶといいだろう。

「メインパーツについて」

メインパーツ は 指輪 として
身に付けることが出来るものだ。
見た目は小さなこのパーツには、ノア・タイタンの
基本となる能力が秘められている。



主に HP/ST/MP の基本能力が決まる大切なパーツだ。
タイプとしては
１：通常能力 の ノーマル
２：格闘重視 の バトル
３：射撃重視 の スナイパー
４：魔法重視 の ウィザード
の４つがある。
ノーマル　 は平均的な能力とテクニック
バトル　　 は近接攻撃主体のHP/攻撃/防御重視
スナイパー は遠距離攻撃を得意とした命中重視
ウィザード は魔法攻撃主体のMP/魔力重視
となっている。
細かな数値や扱えるテクニックについては
各パーツの詳細を見るといいだろう。



自分がどのタイプに向いているかは
何度か扱った上で決めてみるといいかもな。

「サブパーツについて」

サブパーツ は イヤリング として
身に付けることが出来るものだ。
このパーツには、ノア・タイタンの力を
補助する能力が秘められている。



メインには劣るが HP/ST/MP の基本能力を上昇させ
特徴ある行動を取れるようになるぞ。
タイプとしては
１：通常能力 の ノーマル
２：防御重視 の ディフェンス
３：速度重視 の スピード
４：特殊行動 の スペシャル
の４つがある。
ノーマル　 　は平均的な能力とテクニック
ディフェンス は盾を使った行動とHP/防御重視
スピード　　 は平均的な能力UPと回避能力重視
スペシャル　 はST/MPの向上に特殊行動
となっている。

「拡張パーツについて」

拡張パーツ は 頭装備 体装備
パンツ 腕装備 足装備 の
全身の５部位 に身に付けることが出来るものだ。
各拡張パーツには、メインやサブタイプで
決められた、基本能力を補うために
足りない能力や特化させるための能力を
付加させる役割がある。
タイプとしては各メインタイプの４つに付随して
１：攻撃タイプ 　２： 防御タイプ
３：命中タイプ 　４： 回避タイプ
５：魔力タイプ 　６： 抵抗タイプ
の基本能力６つを高めたタイプがある。
例として【バトル タイタン アーム 攻撃タイプ】は
メインタイプを バトル とした 攻撃タイプ の
腕装備であり 近接攻撃テクニック が使用でき
攻撃力を上昇 させ 命中力を減少 させる。
【スナイパー タイタン ヘッド 命中タイプ】は
メインタイプを スナイパー とした 命中タイプ の
頭装備であり 遠距離攻撃テクニック が使用でき
STと命中力を上昇 させ 攻撃力を減少 させる。
このように、その各パーツの数と種類としては
メイン４タイプ ｘ 各６タイプ ｘ ５部位分の
計120種類が存在している。
その他パーツの細かな数値や扱えるテクニックは
各パーツの詳細を見るといいだろう。

「組み合わせについて」

組み合わせについては、さらに複雑になるが
魔法攻撃を主体に戦いたい場合は
メインタイプを ウィザード
サブタイプを　 スピード
各拡張タイプを 魔力タイプ として
【ウィザード タイタン リング】
【スピード タイタン イヤリング】
【ウィザード タイタン ヘッド 魔力タイプ】
【ウィザード タイタン アーマー 魔力タイプ】
【ウィザード タイタン レギング 魔力タイプ】
【ウィザード タイタン アーム 魔力タイプ】
【ウィザード タイタン ブーツ 魔力タイプ】
というように、これら計７パーツを装備することで
魔法を主体として戦うことが出来るぞ。
発展や応用として、こういった魔法主体の装備の中で
近接戦闘も行いたいという場合は
【ウィザード タイタン アーム 魔力タイプ】 を
【バトル タイタン アーム 魔力タイプ】 へ
パーツを変更することで
魔力の低下を抑えつつ
バトル タイタン アーム の持つ
近接戦闘用テクニックを使用することが
出来るようになる。
こういった組み合わせを考え
自分なりの構成を考えて戦いに望むといいだろう。

「ノア・タイタンに乗るために」

小型化に成功したタイタンの装備だが
基本的な能力では、巨大なノア・タイタンの方が上だ。
もしノア・タイタンに乗りたいのであれば
【タイタン パーツ】を装備し
各戦闘エリアに置かれた ノア増幅器に
【巨人の上半身】
【巨人の下半身】
【巨人のコア】
以上の３つをトレードするのだ。



扱いづらい代物だが、強大な力を得ることが出来るぞ。
