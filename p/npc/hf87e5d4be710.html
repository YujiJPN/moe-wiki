「スキルについて」

ダイアロスでの生活は
あなたが どんな技術を伸ばすか によって
変化していきます。
料理人を目指したいなら 料理 スキル を
魔法で敵を倒したいなら 破壊魔法 スキル を
剣を扱う戦士を目指すなら 刀剣 スキル を
そんな戦士に武器を売りたいなら 鍛冶 スキル を…
全ての行動があなたの生活に結びつく と考えてね。



あなたは 伸ばしたいスキルを自由に伸ばして
あなただけの人生を送ることができる。
いくらでも人生のやり直しはできるから
屈強な戦士から、釣り人へ転身 なんて事もできるわ。
はじめは覚えられることがいっぱいあるから
いろんなスキルを伸ばしていくといいわね。



いずれ、あなただけの人生が見えてくることでしょう。
もっと詳しいスキルの説明は
この後、私たちの里へ行ってもらえれば
仲間が教えてくれるわ。

「操作・カメラモードについて」

キャラクターの移動(操作)方法は
キーボード操作 がメインの 固定カメラモード と
マウス操作 がメインの 手動カメラモード の
大きく分けて ２つ があるわ。
現在の設定は キーボード操作 の 固定カメラモード。



モードの確認は、画面の上( Mainバー )の左端にある
四角ボタンの中の表記から確認できるわ。
モードを切り替えていなければ、現在は ２ と
表記されているはずよ。
このボタンをクリックすると Ｍ２ へと切り替わり
マウス操作 の 手動カメラモード へ変更されるわ。
動作に慣れるまでは、あまりいじらずにいるといいわ。



ちなみに、これもまだ覚えなくても良い事だけど
操作キーの変更 については
画面上の SYSTEM から キー設定 を
クリックすると、詳細に変更できるわ。
最初は難しいから、頭の片隅にでも置いておいてね。



これから先、あなたが成長して余裕を持った時
あなたに合った操作方法を探してみると良いわ。

「移動・操作について」

ここへ着たばかりのあなたなら
まだ移動については不慣れよね。



最初の設定では、マウス操作がメインの
手動マウスモード になっているわ。
もしマウス操作が慣れないという場合は
キーボードの十字キーによる操作 や
操作・カメラモードの変更 も可能よ。
画面上の左端にある Ｍ１ と書かれたボタンを
クリックすると ２ と切り替わり
手動カメラモード から 固定カメラモード へ
変更されるの。
固定カメラモード では キーボードでの操作 が
メインとなるわ。



最初は 十字キー での操作になるけど
自分の扱いやすいように変更する事も可能なの。
まだ覚えなくても良い事だけど
キー設定の変更 については
画面上の ＳＹＳＴＥＭ から キー設定 を
クリックすると、詳細に変更できるわ。
最初は難しいから、頭の片隅にでも置いておいてね。



これから先、あなたが成長して余裕を持った時
あなたに合った操作方法を探してみると良いわ。
