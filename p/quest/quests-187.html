クエスト本文

ゼノ： 生産の道 を極めんとする若者よ。お前の目指す道は険しいぞ。 それでもなお、道を進むと言うのであれば、未来の創造主へ ワシから グレイトクリエイター装備 を授けよう。 近いうちに客人が来る予定でな、うまい食事と酒を出したいと思っている。 そこで ローストチキン を 2個、 スパークリング ワイン を 2個 作ってきてもらいたい。 お前の力を見るのにちょうどいい仕事であろう。 完成したらワシの所へ届けてくれ。 ――□□ 報酬 □□―――――――――― [1] グレイト クリエイター キャップ [2] グレイト クリエイター ウェア [3] グレイト クリエイター パンツ [4] グレイト クリエイター シューズ ※ 鍛冶 / 木工 / 裁縫 / 薬調合 装飾細工 / 料理 / 複製 / 醸造 の 　 各スキルが 40 以上で使いこなせる ――□□ 開始条件 □□―――――――― [1] 鍛冶 / 木工 / 裁縫 / 薬調合 装飾細工 / 料理 / 複製 / 醸造 の 各スキルが 40 以上必要 [2] グレイトクリエイター のシップ装備一式を持っていない ――□□ 注意事項 □□―――――――― [1] 依頼された製作物は、自分で作製したもの以外は受け取りません。
