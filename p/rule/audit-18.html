ルール称号・シップ・ギルド

「称号・シップ・ギルド」に関するゲームのルール 43 件。

WarAge：PresentAge（現代）から10年後の世界で、ビスク軍とエルガディン軍が戦争している（N = 中立）。各拠点の給料長が給料の支給とメダルの交換を行う（給料長の討伐は暗黙の勝利条件）。WP = ウォーポイント（スルト鉱山ではワープポイント）。軍階級はAmateurからWarlordまでで、Warlordが最高。ランクアップに必要なポイントは 0 / 1 / 6 / 11 / 21 / 31 / 51、日給は 200〜5,000。Commander、Captain、Warlordのウォーノルマは、82,944秒（23.04時間、ゲーム内表記は24時間）ごとに 1 / 3 / 5 ポイント。ウォーポイントは0-9999で、倒した側の階級 − 倒された側の階級 < 4 のときに得られ、死亡で失う。給料は将軍からゲーム内1日に1回受け取れる。Soldier以上はレベル60が必要で、戦功（war merit）を消費する。

ギルドランクアップの式：ギルドスコア = f x GP + (1 - f) x 100 x（スキル x 重みの合計）。f は戦闘系 0.5、生産系 0.6。ランク r にはスコア (r / 4)² x 10000 = 625 / 2500 / 5625 / 10000 以上が必要。戦闘系では GP + 100 x 4スキルの平均 >= 1250 / 5000 / 11250 / 20000。生産系では GP + 66.7 x スキル >= 1041.7 / 4166.7 / 9375。グロム・スミスは GP + 33.3 x（採掘 + 鍛冶）。
