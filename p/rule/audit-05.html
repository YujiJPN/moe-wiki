ルール魔法

「魔法」に関するゲームのルール 59 件。

必要スキルに連動する消費：消費MPが必要スキルに連動する魔法がある。この魔法は、1番目の必要スキルの値と同じだけMPを消費する。魔法以外のテクニックにも、STの代わりにMPを消費するものがある。

関連ページ：マクロ

レジスト判定：対応する耐性に対して最大3段階で判定する。1段目は常に耐性に比例して軽減する。2段目は確率で半減する（半減レジスト）。3段目はまれにさらに半減する。耐性は火、水（冷気）、地（毒）、風（雷）、無の5種類。軽減後の効果量 = 効果量² ÷ ((耐性 − レジスト貫通 + 1) × 0.01 + 効果量)。半減レジストの確率 = ((レベル + ボーナス) × 0.5 + 30) ÷ (耐性 − レジスト貫通 + 30) × 70 %。

魔法の系統スキル（破壊魔法、回復魔法、強化魔法、神秘魔法、死の魔法）：魔法の効果を上げる。高ランクの魔法を使うと上がる。破壊魔法は高耐性の敵への詠唱でも、回復魔法は大きな回復と蘇生でも、死の魔法は死の魔法で敵を倒すことでも上がる。上がりやすさは 必要スキル + 8 を基準に決まる。HPの低い相手への魔法は、そうでない相手への魔法の2倍上がりやすい。

魔法熟練：魔法使用効率、MPの自然回復量、レジスト貫通力が上がる。より過酷な状態で魔法熟練技を成功させると上がる。MPの自然回復は、毎秒62.5回、魔法熟練 × 0.2 ÷ 6000 ずつ増える（魔法熟練100で毎秒 +0.21）。

守護結界（魔法熟練80＋召喚魔法80、ペーパー ドール 5）：MP 46、詠唱 450、ディレイ 2450。サークルを作り、味方には魔法無効化、敵には6秒の行動不能デバフとノックバックを与える。サークルは35秒続く。詠唱のあるテクニックで、3回攻撃を受けると中断される。

呪文抵抗力：その値がすべての属性耐性に加わり（装備込みで上限180）、敵の魔法の効果を下げる。モンスターのレベル判定にも数えられる。耐性 = 基本値 + 呪文抵抗力 × 種族ごとの係数。半減レジストの確率は ((レベル + ボーナス) × 0.5 + 30) ÷ (耐性 + 30) × 70 % で、段階はなく連続的に変わる。スキルが 受けた魔法の必要スキル + 8 + スキル × 0.35 を超えると上がらなくなる（低スキルでは 必要スキル + 15）。プレイヤーのレベルには5つの耐性が含まれる。

集中力は1ポイントにつき詠唱時間を0.16 %短縮する（最大20 %）。詠唱時間 = 表記値 × (1 − 集中力 × 0.0016) で、これに詠唱速度バフの短縮（懐中時計 0.10、ラピッド キャスト 0.35）が掛け合わされる。2018年の計測では、ラピッド キャスト込みで約40 %短縮された。

詠唱継続率：攻撃を受けても詠唱が続く確率は、集中力0で約1 %、1ポイントごとに +0.6 %（100で61 %）。ホールドで一律 +35 %（両方で96 %）。継続する確率（%）= 集中力 × 0.6 + 詠唱妨害耐性バフの値（ホールドは35）。一部のテクニックは3回攻撃を受けるごとにしか中断しない。

魔法の効果量と効果時間は、詠唱スキルと魔力で伸びる。範囲の広さはスキルでは変わらない。低スキルの魔法も、高スキルの術者が使えば強い。神秘魔法は魔力をほとんど使わない。効果量は スキル − 必要スキル に応じて伸び（伸び方と上限は魔法ごとに違う）、さらに (魔力 + 300) ÷ 350 倍になる。魔力とスキルの効き方に決まった比率はない。

詠唱が完了すれば、射程内の対象には必ず効果が出る。ミスはなく、視界を遮る物も無視する。完了時に対象が射程外なら不発で、効果はない。弾道型の魔法は完了時に発射され、着弾で当たる。対象が射程外に出ても追尾する。魔法には回避判定がない。

属性耐性は魔法ダメージと一部の能力低下量を減らす。耐性が高いと半減レジストが起きる。半減レジストの確率 = ((レベル + ボーナス) × 0.5 + 30) ÷ (耐性 − レジスト貫通 + 30) × 70 % で、決まった境目はなく連続的に変わる。軽減後の効果量 = 効果量² ÷ ((耐性 − レジスト貫通 + 1) × 0.01 + 効果量)。属性耐性を使う効果と、呪文抵抗力を使う効果がある。

関連ページ：スキル/熟練(魔法)/破壊 / スキル/熟練(魔法)

モンスターには、火 / 水 / 風 / 地 / 無 の5つの属性耐性と呪文抵抗力がある。「無」は「属性なし」とは別の独立した属性。物理攻撃には属性がなく、防御力（AC）で軽減する。耐性の旧名は「RESIST」。耐性が魔法の威力を上げることはない。

関連ページ：スキル/熟練(魔法)

魔法の効率：総合ではポイズン ミスト、詠唱時間あたりではカオス フレア、MPあたりではアイス ボールが最も良い。強化魔法は戦闘技術と比べて効果が長く、STが要らず、他人にもかけられる。速度 / クリティカルのバフは アクセラレイション と アジリティ インプルーブ だけ。

関連ページ：スキル/熟練(魔法)/破壊 / スキル/熟練(魔法)/強化

熟練スキル枠に入る魔法の系統（系統スキル自体ではステータスは上がらない）：破壊魔法（攻撃、属性、DoT）、回復魔法（回復、MP増加、蘇生、解除）、強化魔法（バフ / デバフ）、神秘魔法（テレポート、エンチャント、睡眠、食料、明かり。ミスリル強化も）、召喚魔法（アンデッド / 悪魔、触媒はアイボール）、死の魔法（デバフ、死体、ヘル パニッシュの反射は最大100 %）。系統ごとに詠唱音が違う。

関連ページ：スキル/熟練(魔法)/死 / スキル/熟練(魔法) / スキル/熟練(魔法)/神秘

スキルと魔力ごとの効果量・効果時間（死の魔法のデバフ：スキル60-100・魔力0-200、回復：セルフ ヒーリング … セイクリッド サークル、エンチャントの効果時間、召喚の支援魔法、強化のバフ：スキル20 / 50-100・魔力30-150）は、どれも同じ形で決まる。スキル − 必要スキル に応じて伸び（伸び方と上限は魔法ごとに違う）、(魔力 + 300) ÷ 350 倍になる。ばらつきは ±10 %。

基本魔法のコストはスキル段階ごとに決まっている。スキル1：MP 5、触媒 ND1、詠唱 115、ディレイ 180 … スキル90：MP 53、触媒 PNQ1、詠唱 277、ディレイ 378。強化魔法は詠唱とディレイが +20。ただし強化魔法スキル70は 241 / 334 で、この規則から外れる。詠唱とディレイの単位は16ミリ秒（詠唱 115 = 1.84秒、277 = 4.43秒）。

関連ページ：スキル/熟練(魔法)/回復 / スキル/熟練(魔法)/強化

魔法の成功率：必要スキルちょうどで80 %、1下回るごとに -10 %、1上回るごとに +2.5 %（+8で100 %）。最低は1 %。複合魔法の成功率はスキルごとの成功率の平均で、各スキルの分は100 %が上限。そのため、いずれかのスキルが低いと失敗しやすい。移動しても下がらない。目安は100 %になるスキル（回復魔法 68 / 88 など）。複合召喚は、必要スキルちょうどで80 %、両方を8上回ると100 %。

関連ページ：スキル/熟練(魔法)/回復 / スキル/熟練(魔法) / スキル/熟練(魔法)/複合/召喚

詠唱妨害：攻撃を受けると詠唱が中断されることがある（集中力0で99 %）。継続する確率（%）= 集中力 × 0.6 + 詠唱妨害耐性バフの値で、集中力100とホールドで96 %。詠唱妨害耐性バフは最新の1つだけが有効。集中力は詠唱と移動しながらの詠唱も速める。判定のたびに集中力の上昇判定がある。

関連ページ：スキル/熟練(魔法)/回復 / スキル/熟練(魔法)

詠唱中にジャンプすると詠唱はキャンセルされるが、ディレイは発生する。重量過多でジャンプできないときはキャンセルできない。戦闘体勢の切り替えでもキャンセルされる。

関連ページ：スキル/熟練(魔法)

詠唱中の移動：移動速度が落ちる（通常速度 × (0.4 + 集中力 × 0.002)）。テレポート、アイテム生成、召喚の魔法は極端に遅いか、まったく動けない（センス オブ ワンダー で解除できる）。移動した距離に応じて効果量 / 効果時間が下がる。2 m未満なら下がらない。5 mまでで0.8〜1倍、50 mまでで0.5〜0.77倍、それ以上は0.5倍。

関連ページ：スキル/熟練(魔法) / スキル/熟練(魔法)/神秘

魔法のディレイは系統ごとに共有される：通常系、召喚系（他系統の「リコール〜」も含む）、マジック ドレイン。召喚系の魔法は詠唱が長く、専用の詠唱音、専用のディレイとチャージ枠がある。

関連ページ：スキル/熟練(魔法) / スキル/熟練(魔法)/召喚

魔法はMPと触媒を消費する。触媒は成否に関わらず最後に消費され、MPは成功したときだけ消費される。テクニックのコストには、触媒、金銭、酩酊度、MPがある。

関連ページ：スキル/熟練(魔法)

魔法チャージ：チャージアイテム（スペル ブック）を装備すると、完成した魔法を保持できる。保持時間は38.4秒で、スペル エクステンション で延びる。同じ魔法を使うと即座に解放される。魔力は解放時のものを使い、効果は常に100 %。保持した後は妨害されない。ディレイ系統ごとに1チャージ（同時に最大4つ）。ジャンプするとすべて消える。MPと触媒はチャージ終了時に消費される。スキルは解放時にだけ上がる。テレポートは、解放時に掴んでいるレコード ストーンへ飛ぶ。
