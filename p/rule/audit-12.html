ルール採集と栽培

「採集と栽培」に関するゲームのルール 45 件。

採掘エリア：エリアごとに等級（1-50）があり、それで中身が決まる。容量（エリアが枯れるまでに採れる鉱石の数：3-100）、再生までの秒数（1800 / 900 など。ウォーエイジのマップでは短い方）、最大4種の鉱石（確率、必要スキル、鉱石、破片）。1回の採掘では最初に成功した鉱石が採れる。確率の判定のあと、random(100) < min(95, 20 + 5 × ⌊d / 5⌋)（d = スキル − 必要スキル）で成功。続いて (5 − ⌊d / 5⌋) × 20 %の確率で代わりに鉱石の破片になる。鉱石は黒炭〜オリハルコン鉱石。必要スキルは銅 1、スズ 10、鉄 20、黒炭 30、金 35 / 50、銀 40、ミスリル 80、オリハルコン 90。枯れたエリアでは採掘できない。

鉱石の岩、木、竹、丸太、作物、生産設備、小道具などのフィールドオブジェクトは、NPC と同じように配置される。使えるものはそれぞれ決まったドロップを持つ。

採集できる対象ごとに、使える道具の種類と段階が決まっている。合う道具を持っていると、それに応じた採集になる。

苗床の収穫物は、土地の権限がない、土地の期限が切れている、苗床の耐久度が 0 のときは受け取れない（「ステータスが収穫ではありません」）。

苗床：収穫物を受け取ると「（アイテム名）(個数) を取得しました」と出る。受け取れないときは「この苗床は契約中ではありません」「苗床の契約期限を過ぎています」「ステータスが収穫ではありません」。

釣り：魚は mob 扱いで、餌は魚の近くの水中に落ちなければならない。引っかかった魚は再 POP を妨げる。/fishingstop でやめられる。初心者は大聖堂の手すりから真下の魚を釣る（低スキルでは飛距離が短い）。スペースキー＋矢印キーで手すりに飛び乗れる。スキルが上がるとイクシオンなどの mob が掛かる。投げのゲージの長さは int(釣りゲージ長 + 0.7 × 釣り) + 15。100 m 以内の魚から3秒ごとに食いつきの判定がある。引き寄せゲージの失敗マスは釣りスキル、魚のレベル、HP で決まる。

採集ダメージ（収穫・伐採・採掘）は採集スキル、道具の性能、筋力、種族で決まり、ステータスの攻撃力は関係ない。魔攻変換の装備で2倍近くになる。ダメージ倍率を上げるバフは効く。採集の固定ダメージは 威力 × 160 / 320、採掘は 200 / 400。

関連ページ：スキル/基本/収穫 / スキル/基本/伐採 / スキル/基本/採掘

採集の命中 = 採集スキル + 道具の武器スキルの 1/4（鎌と斧は刀剣、クワとつるはしはこんぼう）：100 / 0 で 100、100 / 100 で 125。ステータスの命中は使われない。採集の命中を上げるバフは効く。正確には 採集スキル × 種族 × (0.8 + 0.2 × 性能の割合) + 道具の武器スキル ÷ 4。

関連ページ：スキル/基本/収穫 / スキル/基本/伐採 / スキル/基本/採掘

採集のディレイ = 硬直時間 + 道具の攻撃間隔（刈る 90 + 攻撃間隔、掘る 110 + 攻撃間隔）、下限 150（2.4 秒）。ST による倍率：200 以上 ×0.9、40-99 ×1.1、10-40 ×1.2、10 未満 ×1.3。装備の攻撃速度補正とツイスト ダンスが効く。チェイン ソーでも ST 200 で下限まで下がる。

関連ページ：スキル/基本/収穫 / スキル/基本/伐採 / スキル/基本/採掘

採集のスキル上昇：どの対象でも上がり、対象の強さは関係ない（93付近で成功1回あたり約0.0015）。ミスでは上がりにくい。柔らかい鉱石でも硬い鉱石でも上がり方は同じ。収穫では生命力 > 筋力 > 持久力も上がる。基本の上がり方は採掘 0.0027、収穫 0.0028、伐採 0.0029。道具が必要で、疲労はない。対象ごとに上がる上限がある（隠れ里 ネヤの銅の鉱石・若木・ゴマでは 5.0 で止まる）。ステータスは筋力 / 生命力 1.0、持久力 0.25 の割合で上がる。

クリティカル率は 3 %。スキルでクリティカル率が上がるのは素手だけ（1ポイントにつき 0.2 %、上限 20 %）で、採掘・伐採・収穫のスキルでは上がらない。採集量は対象ごとのドロップで決まる。

採集量は対象ごとのドロップで、枠ごとに1回抽選する（「3-5 + 1-4 + 1」の表記）。どの木も樹脂を1つ落とす。悟りの石は別枠。岩石は主にそのエリアの一般的な鉱石を落とし、硬い岩石はより上位の鉱石と宝石を落とす。鉱石の精霊は鉱石3個か石を落とす。上位の採掘場ほど多く落とす。採掘・伐採・収穫は採集対象への攻撃で、その対象のドロップが採集量になる。

釣りの概要：釣り竿と魚の餌を使う。魚は目に見えるモンスターで、魚がいなければ釣れない。釣った魚はその魚のアイテムを落とす（大きさによってはレア）。捌くには料理スキルが最大20まで必要。魚拓でバインダーを埋め、コンプリートするとアイテムと交換できる。魚拓システムの沿革。魚はウキから 100 m 以内で寄ってくる。釣果はその魚のドロップ。魚のレベルが難しさを決める。

関連ページ：スキル/基本/釣り

投げのルーレット：止めた位置の12時の方向からの距離が餌の飛距離になる。ゲージの長さはスキルとともに伸びる。餌は自分の後ろに出て前へ飛び、水面以外やオブジェクトに落ちると失敗する。ゲージの長さ L = int(釣りゲージ長 + 0.7 × 釣り) + 15（10〜100 マス）。距離 = min(マス + 1, L) × 0.3。カーソルの速さは釣りゲージ速度で決まる。

関連ページ：スキル/基本/釣り

引き寄せのルーレット：食いつくと、スキルに応じて成功マスと失敗マスが交互に並ぶ。止めた距離だけ引き寄せる。魚が水中にいる間は繰り返す。普通の魚は約3回の引き寄せが必要。失敗マスの数 n = int(L × clamp(1 − a × (2 − r), 0, 1))、a = (釣り + 70 − 魚のレベル + 釣りヒットゾーン) × 0.01、r = 魚の HP の割合。成功マスでは (マス + 1) × 0.1 m 引き寄せる。9 m 以内（または高さの条件）で釣り上げ。制限 60 秒。

関連ページ：スキル/基本/釣り

釣りの失敗：長い間何も食いつかない、食いついたまま放置、餌が攻撃で消える。餌の耐久度は釣りスキルで上がるとされる。待ちすぎると餌がなくなる。引き寄せの制限は 60 秒（「魚に逃げられました」）。
