ルール死亡と生存

「死亡と生存」に関するゲームのルール 49 件。

/sensecorpse（死体位置確認）で自分の死体のある場所がわかる。見つからないときは「（名前） の死体は見つからない。」と表示される。

砂漠の規則：ハティル砂漠の屋外では、満腹度が夜に2倍の速さで、潤喉度が昼（4時〜21時）に2倍の速さで減る。

砂漠の渇き：ハティル砂漠では、昼（4時〜21時）に潤喉度が 0 だと毎秒 3.125 HP 減る。

死亡すると：STが0になり、死亡モーションになる。「復活ポイントに戻ります」と「ホームポイントに戻るとクエストの進行状況は死亡前の状態に戻ります」が表示される。開いているウィンドウはすべて閉じ、保留中のトレード、修理、ルートも取り消される。倒した相手の名前と時刻が記録される。復活までの時間は、マップごとの時間 + 9.6秒。ホームポイントへ戻ると、DL アイテムがインベントリ、装備、レンタル収納ボックスから消える。ChaosAge の6マップでは、CA アイテム以外の持ち物と装備がすべて失われる。

プレイヤーが死ぬと死体が残り、他のプレイヤーにも見える。死体は30分残る。

死亡時のドロップ：お金とアイテムは死体に残り、ルートできる。WarAge ではプレイヤーもアイテムを落とす。落ちるのは最大6個までで、個数は戦争の階級と領土による（0〜3）。「死亡時ドロップしない」アイテムは落ちない。戦禍の星 は、その耐久度に応じて WarAge のドロップを肩代わりする。死亡後にホームポイントへ戻ると DL アイテムが消える。ChaosAge の6マップでは、CA アイテム以外の持ち物と装備がすべて消える。

関連ページ：用語辞典

霊体はホームポイントで復活する。ホームポイントには旗のアイコンのソウルバインダー（10か所）がいて、死体を「SB回収」できる。ホームポイントへ戻るとスキルが減る。減る量は対象となるスキル合計の 0.25 %（合計 850 なら 2.125）。自分の死体で復活すると、死体回収 の上昇判定がある。

水と呼吸：止まっていると体が沈む。完全に水中にいると呼吸ゲージが減り、0 になると死ぬまでHPが減る（毎秒 3.125）。PageUp / PageDown で浮上と潜水。水泳スキルで呼吸が長くなり、泳ぎも速くなる。呼吸が続く時間は、水泳0で約26.7秒、70で約123秒。泳ぐ速さは、水中で 0.2 + 0.4 × 水泳 ÷ 100、水面で (1 + 水泳 ÷ 100) × 0.4。水中で水泳が上がる。

関連ページ：初心者ガイド

落下ダメージ：一定の高さを超えて落ちると受ける。重量オーバーで増え、落下耐性、テクニック、装備で減る。新しいキャラクターは8〜10 mの落下で死ぬ。ダメージ = (落下した高さ − (落下耐性 ÷ 100 × 30 + 2))² × 0.8 × (1 + 3 × min(1, 0.05 × 重量オーバー)) × 落下ダメージの倍率。倍率はテクニックや装備で下がり、最小 0.001。ダメージの上限は5000で、完全に軽減しても最低5のダメージを受ける。

満腹度と潤喉度：筋力が高いと満腹度が、精神力が高いと潤喉度が速く減る。移動中は × 1.5、ハティル砂漠では × 2（満腹度は夜、潤喉度は昼）。シップが旅人でスキル合計が100未満なら減らない。20未満になると自動で飲食する。満腹度が 0.5 以下だと、座ったときの回復ボーナスと 自然回復 の上昇判定がなくなる。潤喉度が 20 未満だとSTの回復が遅くなる。100から減るたびに髪が伸びる。

自分の死体と復活：死ぬと死体が残る。霊体は歩いて死体まで戻るか、ソウルバインダーにスキルのペナルティと引き換えに死体を引き寄せてもらう。死体の回収時間は 死体回収 0 で28.8秒、100 で0.86秒。復活時の HP / MP / ST は 20 %。死体で復活すると満腹度と潤喉度が 0 になり（リザレクション ではならない）、死体回収 の上昇判定がある。死体のルート中は座りと同じように回復する。泳いでいる間は耐火属性 +10。ホームポイントへの自動帰還までの時間はマップごとに決まっている。決まっていなければ、WarAge では 60 + 0.6 × 死体回収 秒、それ以外では1時間。

関連ページ：初心者ガイド / 雑学

ソウルバインダーのペナルティ：損失の合計は、対象となるスキル合計の 0.25 %（850 なら 2.125）。損失を減らす効果があれば、その分減る。損失は最大1.0ずつ、ランダムに選んだスキルから引かれる。低いスキルほど選ばれやすい（重み = 10 × (1 − スキル値 ÷ (2 × 平均)) + 5 × (1 − スキル値 ÷ (上限 ÷ 2))）。2.0 未満のスキルは対象外になることがある。1.0 を下回る判定は飛ばされる。0.1 未満の損失は表示だけ。死体が10.5 m以内なら損失はない。

WarAge の死亡時のアイテムドロップ：ペナルティは個人のアイテム喪失だけ。原因を問わず、死亡すると装備と所持品からランダムにアイテムを落とす。軍属が落とす数は、階級と場所（自軍 / 中立 / 敵の領土）による：Warlord 2 / 3 / 3、Captain と Commander 1 / 2 / 2、Soldier と Guard 0 / 1 / 2、Newbie と Amateur 0 / 1 / 1。国のない中立は敵の領土と同じ扱いで、階級がないので1つ落とす（ヌブール以外）。領土は本拠地、CC / DA のゾーン（保持している側で数える）、自由ゾーンに分かれ、ヌブールは非戦闘。ダーイン山とイルヴァーナ渓谷では落とさない。スタックは個数の半分を失う。「死亡時ドロップしない」アイテム（シップ装備はすべて）は落ちない。「先に落ちる」アイテムが優先して選ばれ、最大6個まで。軍属の死体は階級章を持つことがある。
