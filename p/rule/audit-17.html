ルール時代

「時代」に関するゲームのルール 82 件。

WarAgeの成績：ウォーポイントと軍階級のほかに、段位、ROBO POINT、チェインキルがある。

ウォーポイントの分配：WarAgeで敵国のプレイヤーに倒されると、倒された者から100 m以内のプレイヤーに通知が届く。ペットが倒した場合は飼い主が倒したことになる。倒した者は、倒された者の階級のポイント x 1.0 を得る。通知を受けた倒した者のパーティーメンバーは、それぞれ ポイント x (1 + 0.05 x (n - 1)) / n を得る（n はパーティー人数、小数点以下切り捨て）。どちらも「倒した側の階級 - 倒された側の階級 < 4」で、亡命中でない場合に限る。例：倒された者がWarlordで5人パーティーなら、各2ポイント。

軍の給料：将軍から1日1回受け取れる。給料は階級の日給 x 1.0（小数点以下切り捨て）で、1〜10,000 goldのとき支払われる。Amateur、Newbie、Guardは条件なしで受け取れる。Soldier以上はレベル60以上が必要で、満たさないと体がなまっているとして支払われない。受け取ると戦功（war merit）が減る：Commander -1、Captain -1、Warlord -2。

亡命：亡命の仲介人は自軍の兵士だけを相手にする。条件は5,000 Jade以上、軍階級2以上、亡命中でないこと。5,000 Jadeを払うと亡命先の国が保留になり、亡命の密約書を渡される。密約書はNT、LO、OP、CSで、死亡時に優先してドロップする。亡命中の兵士を倒すと密約書を落とし、それを自軍の指揮官に渡すと報酬がもらえる。亡命中に倒した相手は戦績にならない。敵の将軍のもとで新しい国に所属すると、友好度が10,000に設定され、WarAgeのヌブールの村へ送られる。中立になる場合も同じ手順。

プリズン・マインからの釈放：看守にプリズンマイン ゴールド10個を渡す。錆びた針金も持っていると脱獄の試みとみなされ、針金とゴールドを取られてやり直しになる。釈放されるときは監獄のアイテム（ピッケル、カッパー、ゴールド、ブレッド、ウォーター、針金）をすべて取られる。釈放先はWarAgeのヌブールの村か、レクスール・ヒルズ(War_Age)の自軍支配地域付近。監獄の水とパンはプリズンマイン カッパー20個で買える。道具を持たないプレイヤーはプリズナーズ ピックアックスと採掘の秘伝の書をもらえる。

拠点：WarAgeの戦場マップには拠点がある。レクスール・ヒルズに4、ヴァルグリンドの巣穴に1、ガルム回廊に2、イルヴァーナ渓谷に4、アルビーズの森に2、ムトゥーム墓地に1。拠点の表示は、どちらの守備隊が生き残っているかで決まる。拠点の状況はWarAgeの全マップで共通で、「Lexur-CC1 はビスク軍の支配下にある」のようにシステムウィンドウとミニマップで告知される。拠点の旗を倒したとき、その拠点の守備隊が全滅していれば、拠点は倒した者の国のものになる。新しい側の守備兵が出現し、「CC n がビスク / エルガディンの支配下に置かれた」と告知される。戦争フェーズ以外では、奇跡か呪いが選ばれる。奇跡では七賢者が現れ、それぞれ1つの祝福を与える。

チェインキル。 プレイヤーを連続で倒すとチェインキルが積み上がる。「（名前） のチェインキルが （数） になった」「（名前） は （数） ポイントのチェインキルボーナスを得た」と表示され、近くのプレイヤーにも見える。戦績ポイントと昇格がある。

タイムカプセルとWar銀行：ヌブール村の時の記憶「ヤーナ・タングン」で、タイムカプセル（WarAgeへアイテムを送る）とWar銀行が使える。ヌブール村以外のWarAgeは対人エリアで、死亡すると現金とアイテムを失う。TCのアイテムと盗品はタイムカプセルに入れられない。

時代間の移動：「時の記憶」を持つブランク ノアピースを装備して行う。時代ごとの旧ノアピースはもう機能せず、NPCにトレードする。/noahpiece でノアピースの状態を確認できる。ブランク ノアピースはチュートリアルで渡される。時代はPresent、War、Ancient、Future、Chaosがある。

AncientAge（「家Age」）：エルビン渓谷の箱舟遺跡のアルターから入る。エルビン渓谷ではホーリー レコード + テレポートが使える。夜間キャンプは、ゲーム内時間20:00以降に抜けるのが最も安全。AncientAgeのマップはモラ・タワー、ソレス渓谷、ユグ海岸、ゲオの深淵、ゲオの大空洞、ミトヤの大樹、シスの天空島。ゲーム内の1日は現実の86.4分。時間帯によって出現するモンスターがある。

AncientAgeへの行き方とノアピースの記憶：箱舟遺跡から行く。プレイヤーは土地を借り、NPCベンダーが代わりに販売する。後でアルターで移動できるように、2つの時の記憶をブランク ノアピースに記録しておく。/noahpiece で時代ごとに記録された記憶を表示する。ブランク ノアピースはチュートリアルの出口で渡される。

WarAgeの支配：すべての拠点を占領した勢力は「奇跡」の効果を、もう一方は「呪い」を受ける。奇跡と呪いには効果時間がある。支配状況は /warinfo で確認できる。勢力はエルガディン、ビスク、サスールの3つ。第三勢力サスールは、専用マップと階級装備とともに予定されていた。

WarAgeの友好度：PresentAgeとは別。ビスク / エルガディン軍の軍属は、自軍への友好度が最高、敵軍への友好度が最低に固定される。WarAgeの一部の地点では、Mobが支配勢力の側につく。中立プレイヤーは軍のMobを倒すことで、どちらかの側に寄る。所属する軍は亡命の仲介人で変えられる（軍階級2以上、5,000 Jade、亡命中でないこと）。占領された拠点には、占領した国の守備兵が出現する。

時代とアイテム・ペット：アイテムとペットは、WarAgeと他の時代とで共有されない。移すにはタイムカプセルボックスを使う。中のアイテムは、見ている側の時代のものとして扱われる。TCのアイテムと盗品は入れられない。1人1個のアイテム（OP）は、WarAgeで1個、それ以外で1個持てる。OPはショップでの購入、トレード、装備のときに判定される。WarAgeで死亡したときのドロップは、WarAgeのキャラクター自身の装備から出る。PresentAgeで装備中のDLのカオス装備は、WarAgeで死亡しても消えない。PresentAgeに置いてあるログアウトで消えるアイテムは、WarAgeでログアウトしても消えない。
