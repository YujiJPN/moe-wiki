ルールハウジングと土地

「ハウジングと土地」に関するゲームのルール 52 件。

/arealist と /authoritylist：/arealist でハウジングエリアを一覧表示する（ヘルプには載っていない）。/authoritylist enter / operation で、区画に入ったときやそこで操作したときに、土地の権限リストを表示する（オプションの authoritylist）。

ハウジングの操作：土地（名称変更、ストレージ拡張、取得、予約、進入規則）、アセットの一括設置解除、家の作成と設定、解体、アセットの作成・回転・移動・設置解除、アセットの破棄（契約解除）、ストレージとベンダーの更新、権限の追加・変更、全メンバーの削除、引越し。操作は1つずつ行う。結果はゾーン内の全員にすぐ反映される。

土地グレードと拡張の上限：アセット上限の拡張は、グレード1〜2で2回まで、3〜4で3回まで、5〜7で4回まで。グレードが変わると上限も変わる。ストレージの拡張は6回まで。土地をリセットすると、アセット拡張の上限は2回、ストレージ拡張の上限は6回になる。

ハウジングの操作：操作は一度に1つずつ行う。ゾーンに入って土地情報を受け取っている間は、「土地情報受信中のため、操作できません」と表示されて操作できない。土地や家の日々の消耗は1日1回まとめて計算される。

区画の名称変更：所有者は区画の名前を変えられる。

アセットの一括撤去：区画に設置したアセットを、1回の操作ですべてアイテムに戻す。ベンダーやノアドール、設置解除できないアセットが置いてあるとできない。

家の解体：所有者は区画の家を解体できる。

アセットの回転と移動：設置したアセットは4方向に回転したり、グリッド上で動かしたりできる。上にアセットが載っている、障害物がある、禁止エリアである、位置が固定されたアセットである、のいずれかの場合はできない。

権限リストの消去：1回の操作で、土地または家の権限リストから全メンバーを外す。

ベンダーの販売履歴：所有者はベンダーの販売履歴を見られる。件数と合計ゴールドが表示される。

家への入室：建築中（進捗度100未満）、土地の期限切れ、入室権限なし、耐久度0のときは家に入れない。家に入ると近くのプレイヤーにも見える。

所有地の知らせ：どのゾーンにいても、所有地についての知らせが届く。「所有している土地 [（土地名）] が返還されました」「所有している土地 [（土地名）] がグレード:（数字）になりました」。

期限切れの土地：契約が切れたAncient Ageの土地は公式の規則で処理される。コインを払うと有効期限が延びる。コイン1回分で住宅地は6日、高級・特別は5日、最上級は4日。期限切れの土地では、アセットの移動、契約解除、ベンダーの変更、家への入室ができない。中にいる者は追い出される。土地がリセットされると、所有者、日付、グレードポイントが消える。

土地の権限：共同所有者（土地の拡張と家の建築・撤去以外はすべてできる）、アセット利用者、ストレージ利用者、ベンダー利用者がある。土地には進入の許可・禁止と、操作の役割（管理者、ベンダー利用者、ストレージ利用者、アセット利用者）を設定する。家には入室の権限がある。

土地とベンダーのコマンド：/vendorlist <item> でプレイヤーのベンダーを検索する（Ancient Ageのゾーンのみ、最大50件）。/disparea enter / ownership で土地を色分けして表示する（許可は緑、禁止は赤、自分の土地は黄）。/townlist でAncient Ageの土地名を検索する。

屋外のアセットの消耗：設置したアセットは、現実時間の午前4:00を8回迎えるごとに消耗度が1減る（1回で使用可能回数5）。リストに戻すと使用可能回数を1消費する（消耗度1は40回分）。1日の消耗は基本5に清掃値の係数（0.4 / 0.6 / 0.8 / 1.0）を掛けたもの。0になると壊れる。

関連ページ：雑学

ホーム レコード：ホーム レコーダーのアセットで場所を記録し、ホーム レコード キーでそこへテレポートする。アセットは他人の土地のものでもよい。キーを使うと、約8秒後に記録した場所へテレポートする。パーティメンバーはリーダーに続く。待っている間にダメージを受ける、盗品を持つ、HP buffが切れると取り消される。待っている間はほかのアイテムを使えない。

関連ページ：スキル/熟練(技)/複合技/補助

Ancient Ageの土地アイテム：エンシェントコイン（ハウジングマップの土地を維持する）、特殊販売員 優先契約書（ペットを店員にする）、土地グレードアップチケット（サポート窓口を通じてグレード+1）、土地グレードアップチケットセット、スペシャル ストレージ キー（ストレージアセット用）、生産設備 設計図。コイン1回分の維持日数は6 / 5 / 4日。グレードはグレードポイントで決まる。ストレージ数はグレードで決まり、拡張1回につき4増える。

関連ページ：アイテム/課金アイテム/消耗品

スペシャル ハウスキット：建設期間なしで家が建つ。コテージ、モラハウス、ブロックハウス、ログハウス、ドラキア風ハウス、ヤマトハウス（700 SP）。レンガハウスとモラハウス2は2区画が必要。ほかに店舗ハウス、サンルームハウス、クリスタルパレス、湯屋、コーナーパーラーハウス。トイハウスはギフト。キットの家は種類ごとの建築時間がかかり、建築時間が0の家はすぐに完成する（進捗度100）。

関連ページ：アイテム/課金アイテム/消耗品

アセット(修理)：ターゲットした家のアセットを、アセットの素材のスキルで修理する。使用ST 0、必要スキルは鍛冶 / 木工 / 裁縫 / 装飾細工 1。何も修理されなくても、使うとアセット リペアー キットを消費する。右手のアイテムは使用可能回数が1減る。耐久度のあるアセットは毎日耐久度を失い（基本5×家の清掃値の係数）、0で壊れる。

関連ページ：スキル/生産/修理

他人の土地での栽培：他人の土地に植えるには進入の権限が必要。進入の権限だけでは、その人のストレージは開けない。ストレージには別の権限（ストレージ利用者）がいる。権限のない土地の区画からは収穫できない。

関連ページ：スキル/生産/栽培

Ancient Ageの栽培アセット：1区画に6つまで（どの土地でも同じ）。畝、グリーンハウス、原木 S / M / L があり、土のグレード、同時に植えられる種の数、初期栄養値、消耗度、入手元がそれぞれ違う。土地グレードがそのアセットの必要グレード以上でないと置けない。設置解除すると、栽培中の作物は消える。

関連ページ：スキル/生産/栽培

家のテクニック：日曜大工（ポストに使う。耐久度を1〜3回復、ディレイ28.8分）、家(修理)（木工30、耐久度を約30回復、ディレイ115.2秒）、建築（木工90、ディレイ57.6分。進捗度は時間でも上がる）。攻撃ディレイ短縮の装備で建築が短くなる。キットから建てた家は、耐久度100 %、進捗度0から始まる（建築時間0の種類を除く）。家は43種類で、建築時間は2〜5日。入室には進捗度100が必要。家は1日に耐久度 1.00 % ×清掃値の係数（0.75〜2.0）と、清掃値1.00 %を失う。

関連ページ：スキル/生産/木工

木工で作るハウジング用品：家のアセット81種、建築材料13種、ハウスキット13種（コテージ、モラハウスなど）、栽培アセット9種。キットの家は耐久度100 %で建ち、建築時間は0〜5日。アセットには土地グレードによる設置条件と上限がある。

関連ページ：スキル/生産/木工

Ancient Age：ハウジングの時代（Presentの13,000年前）。プレイヤーはハウジングマップで区画を持ち、家を建て、家具や装置（アセット）を置き、自動販売店（ベンダー）を開く。誰でもベンダーから買い物ができ、そこに置かれた銀行や生産アセットを使える。

関連ページ：AncientAge

土地権利書のNPC価格：土地権利書は1,000,000 Gから200,000 G、高級土地権利書は1,250,000 Gから250,000 Gに値下げされた（2016年）。

関連ページ：AncientAge

2017年11月の更新：蓄音機のアセット（七賢者の箱 Lv3）は、マナレコードを土地の音楽として流す。曲のリストはキャラクターごとに残る。旅の商人のアセットは自分の土地に置くNPCショップで、修理以外のすべての自動販売アイテムを売る。使用可能回数300（60日）、10,000 G。修理できず、ほかのアセットの上には置けない。ノアドールの美容が修正された。

関連ページ：AncientAge / AncientAge/アセット情報

ハウジングマップの便利機能：メインアルターで待つと移動速度上昇のbuffがつく（シスでは落下速度低下も）。ゾーン移動やログアウトで消え、/walk で遅くできる。ホーリー レコードは使えるが、外からテレポートはできない。マップの読み込みは遅く、まだ描画されていないアセットは透明な壁になる。ゾーンに入ってから土地情報を受け取り終わるまで、ハウジングの操作はできない。

関連ページ：AncientAge

土地の所有：土地を持つとストレージ、ベンダー、家が使え、アセットを置ける。エンシェントコイン（またはお試しコイン）で維持しないと所有権を失う。区画のポストは、ターゲットパレットか「アセットリストを開く」から使う（/tar ではポストをターゲットできない）。

関連ページ：AncientAge

区画の購入：管理エリアの看板に、権利書とエンシェントコイン1枚をドロップする。権利書は使い捨て。1キャラクターにつき6区画までと、予約1つ。区画のグレードで機能は変わらない。権利書はマイレージチケットやキャンペーンでも手に入る。

関連ページ：AncientAge

区画の種別と維持日数：コイン1回分で、住宅地6日、高級5日、特別5日、最上級4日。この4種別は1回分がコイン1枚。ほかの種別では1回分にコイン3枚または10枚が必要。

関連ページ：AncientAge

引越し：区画を予約し（すでに区画を持っている必要がある）、アセットを片付け、ベンダーを解雇し、家を解体する。グレード、残り日数、ストレージは引き継がれる。予約は1つまで。期限が切れた予約は10日間の返還準備期間に入る。

関連ページ：AncientAge

維持費の支払い：ハウジングウィンドウを開き（ボタン、F6のCommand、または /housing）、延長を選んでコインをドロップする。どの時代からでも払える。1枚から払え、365日先までが上限。

関連ページ：AncientAge

期限切れと支払保障：期限切れの区画は10日間の準備期間に入り、その後、家とアセットは削除される。一度に30〜49日分払うと保障回数が1減り、50日分以上で2減る（0より下にはならない）。猶予は3回まで。保障回数は「（回数） / 3」と表示される。残り日数が3日未満になると進入できない。

関連ページ：AncientAge

土地グレード：所有期間で上がり、毎日約05:00に更新される。グレードポイントは1日100増える。耐久度71〜100 %の完成した家があると1.05倍になる。グレードが上がるポイントは3,000 / 6,000 / 12,000 / 18,000 / 30,000 / 50,000で、それぞれ30 / 30 / 60 / 60 / 120 / 200日かかる。グレード1〜6のアセット上限は32 / 48 / 64 / 80 / 96 / 112、ストレージは8 / 12 / 16 / 20 / 24 / 28、特殊アセットは0〜5。グレード7はアセット128、ストレージ32、特殊アセット6。拡張1回につきアセットは+16、ストレージは+4。

関連ページ：AncientAge

アセットを置ける範囲：20×20の区画のうち内側の18×18マスと、隣り合う2つの所有区画の間の帯。上にほかのアセットを載せられないアセットがある（栽培、特殊など）。モラハウス系とブロックハウスは屋上にアセットを置ける。禁止されたマスには置けない。アセットリストはアイコン表示と一覧表示を切り替えられる。

関連ページ：AncientAge

アセットの消耗：消耗度1は使用可能回数40。アセットをリストに戻すと使用可能回数を1消費する。屋外では1日に使用可能回数5を消費する（消耗度1につき8日）。屋内では家の清掃値で変わり、71〜100 %で2、21〜70 %で3、1〜20 %で4、0 %で5を消費する。設置していないアセットは消耗しない。0になると壊れる。耐久度2未満のアセットは設置できない。

関連ページ：AncientAge

アセットの修理：テクニック「アセット(修理)」で、アセット リペアー キット（30 G、キャンセルしても消費）と修理素材を使う。所有者か、進入を許可されたキャラクターが行える。アイテムとして修理することもできる。

関連ページ：AncientAge

特殊アセット（販売員、特殊販売員、ノアドール）：土地グレードによる上限があり、置けるのは「グレード − 1」個まで。上限を超えた分はアセットリストで待機させておけない。上に通常のアセットは載せられない。/tar <near enemy> ノアドールNF でターゲットできる。

関連ページ：AncientAge / AncientAge/アセット情報

栽培アセット：1区画に6つまで（アセットの総数に含まれ、設置していないものも数える）。上にも下にも何も積めない。グリーンハウスの屋根には当たり判定がない。入手元ごとの種の容量と初期栄養値は、課金 S 40 / M 60 / L 100 / 鉢 5（栄養値は200中80）、生産 20 / 30 / 50（40）、NPC販売 10 / 15 / 25（20）。栽培アセットごとに必要な土地グレードがある。

関連ページ：AncientAge / AncientAge/アセット情報

土地のストレージ：所有者専用の枠で、銀行や所持枠とは別。数はグレードで決まる（8〜32）。エンシェントコイン1枚で4枠ずつ拡張でき、6回まで（+24）。ストレージアセットはそれぞれ2〜4枠を足し、1つのウィンドウにまとめて表示される。NPCキーのアセットは1区画に1種類1つまで。スペシャルキーのアセットは重ねて置ける。権限で他人と共有できる。

関連ページ：AncientAge

家の建築：使い捨てのハウスキットを、ポストの家タブにセットする。位置と向きは変えられない。モラハウス2とレンガハウスは隣り合う2区画が必要。建築時間はコテージの約48時間からレンガハウスの約120時間まで、種類ごとに2日、2日12時間、3日、3日12時間、4日、5日のいずれか。スペシャル ハウスキットはすぐに建つ。新築の家は耐久度100 %、完成するまで進捗度0。入るには進捗度100が必要。

関連ページ：AncientAge

家の耐久度と清掃値：毎日、耐久度は約02:00、清掃値は約03:00に下がる。修理は木工の「日曜大工」+3と「家(修理)」+30。掃除は美容の「お掃除」+2と「ハウス クリーニング」+30。清掃値の区分は71〜100 高い、21〜70 普通、1〜20 低い、0。耐久度0の家に入ろうとするとポストへ送られる。清掃値が高いと、耐久度の減りと屋内アセットの消耗が少なくなる。家の耐久度は1日1.00 %に係数を掛けた分減り、係数は清掃値71〜100 %で0.75、41〜70 %で1.0、21〜40 %で1.25、1〜20 %で1.5、0 %で2.0。清掃値は1日1.00 %減る。耐久度71〜100 %だとグレードポイントが1.05倍になる。

関連ページ：AncientAge

進入権限：土地と家それぞれに「禁止された者以外」（初期設定）か「許可された者のみ」を選ぶ。リストは1つ100名まで。禁止された、または許可されていないプレイヤーはポストの前に出される。中でスモール ワープを使ってもポストへ送られる。禁止されたプレイヤーも、ベンダーからは買える。所有者、許可された者、その他ごとに、銀行、アセットの操作、撤去、ストレージ、ベンダーの設定、ベンダーとの取引ができるかが決まる。土地の役割は管理者、ベンダー利用者、ストレージ利用者、アセット利用者。存在しない名前は追加できない（追加できれば、その名前は使われている）。所有者自身は追加できず、同じ名前は二重に登録できない。

関連ページ：AncientAge

ホーム レコード：神秘魔法1の複合技で、ハウス ガイドが売っている。どのホーム レコーダーのアセットにも使え、場所を記録できる。記録すると速度buffがかかる。記録した場所へは、専用のキー（装飾細工60 + 神秘魔法50）を使うと、約8秒後に他のゾーンからテレポートできる。HPが減っているときや、盗品を持っているときは失敗する。パーティのリーダーは、同じエリアのメンバーを連れて行く。

関連ページ：AncientAge

アセットの設置場所：壁用・天井用を除き、アセットは屋内にも屋外にも置ける。積み重ねには高さ約11.57〜11.64の制限がある（/loc のYの差。キャラクターのジャンプは1.52）。

関連ページ：AncientAge / AncientAge/アセット情報
