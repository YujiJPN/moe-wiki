ルールUI・コマンド・オプション

「UI・コマンド・オプション」に関するゲームのルール 94 件。

プレイヤーウィンドウとターゲットウィンドウ：プレイヤーウィンドウには、自分のHP / MP / スタミナのゲージがある。ポップアップは自分のメモ編集（Edit My Memo）、Auto、Close。ターゲットウィンドウには、ターゲットの名前とHPが出る。そのポップアップには、切り替え先の関連ターゲット（最大4つ）、Action、自分のメモ編集（Edit My Memo）、Friend、Ignore（プレイヤーのみ。/friend %t add と /ignore %t を実行する）、Auto、Close がある。/autotargetwindow と /autoplayerwindow で自動的に開く。/disptargetwindowname でターゲットウィンドウに名前を表示する。

チャットバー：/defchatmode <SAY / TELL / PARTY / SHOUT / ICH / AUC / CHSAY / FSSAY> {name} で、最初に使うチャンネルを決める。/keepchat で送信後もバーを開いたままにする。/chatformat short / normal で表示を切り替える。/chatbar <text> でバーに文字を入れ、/chatbar2 はそのまま送信もする（プレイヤー検索では /chatbar2 /who all が使われる）。/checkgamecommand は、「/」を付け忘れたコマンドらしい行に警告を出す。チャンネルごとにチャットを開くキーがある（スラッシュ、say、tell、パーティ、フェローシップ、返信、ターゲットtell、shout、オークション、エモート、勢力シャウト、チャンネル1〜3、次 / 前のモード）。フェローシップのログイン挨拶のオプション（[FSLoginMes]）もある。

チャットログ：/chatlog on / off で、チャットを userdata\mlog_*.txt に保存する。文字コードは game.ini の MsgLogUnicode で選ぶ。msgopt.ini で、ウィンドウごとにログを残す設定もできる。

パーティメンバーのウィンドウ：パーティのステータスウィンドウ1〜4に、各メンバーの状態が出る。ポップアップは Auto、Auto Size、Frame Fade、UseNewUI（別のパーティ表示）、LockDisband（うっかり抜けるのを防ぐ）、Close。

システムメニュー：システムメニューのウィンドウ（ログアウト、オプション、ヘルプ、GM呼び出しのボタン）と、Escape / 終了のダイアログがある。

行動ゲージ：詠唱ゲージ、水中の息ゲージ、死体回収ゲージ、アイテム使用ゲージがあり、それぞれ位置を保存できる。

色設定ウィンドウ：colorcfg.ini の317色を変えられる。チャットの種類、NPCの会話（重要な語、アイテム、テクニック、モンスター、NPC）、強調1〜5、種類と勢力ごとの名前、戦闘テキスト、勢力の友好度、コンシダーの段階、マジックダイス、スキル最大、すべてのウィンドウ部品、チャットの種類ごとの吹き出し、アイテム名のレア度、マクロの色10種。/savecolor と /loadcolor で設定をファイルに保存し、読み込む。

確認とメッセージのダイアログ：パーティやフェローシップの勧誘の確認、テレポートの確認（ワープストーン、時代移動）、ポップアップのメッセージ、NPCとの会話で出る選択メニューがある。

文字入力の補助：入力欄のポップアップに、コピー、切り取り、貼り付け、削除がある。日本語入力ではIMEの候補リストが出る。game.ini の ImeCtrlMode で動作（アプリケーション / 一部 / 全部）を選べる。

タイマーウィンドウ：位置を保存できる小さなタイマーの枠。

ウィンドウ管理：ウィンドウの配置は解像度ごとに wnd.ini に保存される（位置、サイズ、最小化、表示状態など）。メッセージウィンドウはタブとしてまとめられる（wnd_docking.ini）。/windowdefault で配置を元に戻す。/windoweffect で開閉時の効果を再生する（テーマはインフェルノ、グレイシャル、ストーム、グローブ、アンリミテッド）。ウィンドウごとにESC CloseとFrame Fadeを設定できる。全ウィンドウを隠すキーがある。/mainbar top / bottom でメインバーの位置を変える。自動で開く設定（/autopetwindow、autotrashcan など）がある。文字サイズとUI拡大率（100〜167 %）も変えられる。

オープニング：字幕つきのオープニングとスタッフクレジット、物語のナレーションがある。

移動の補助：/automove で前へ自動で進む。/follow on / off でターゲットを追いかける（3文字に省略できる）。/clickmovemode でクリック移動、/clickmovemodeautorun で距離に応じて歩きと走りを切り替える。ChangeClickLR でマウスボタンを入れ替え、RotateRate でキーボードの旋回速度を変える。

戦闘の表示：/dispdamage でダメージの数値を浮かせて表示する。/disptargethp でターゲットのHP、/dispstatus でステータスゲージを出す。/targetcursor でターゲットの上にカーソルを出す。遠隔攻撃の照準の大きさ（range_cursor_size）と色も変えられる。

クリックとキーの動作：左クリックはターゲットするだけ（/pickmyplayer で自分も選べる）。コンシダーで自動戦闘レベルより弱いと出たクリーチャーをダブルクリックすると、自動戦闘を始める。右クリック（またはキーの usecenterscreen、今のターゲットへの U targetaction）の動作は相手で変わる。プレイヤーはベンダーの取引を開くか、状態によってコンシダー、またはトレードの要求（保留中なら取り消し）。クリーチャーは攻撃と自動戦闘。作物は栽培ウィンドウと収穫。NPCは会話の後、そのサービスのウィンドウ（銀行、タイムカプセル、ショップ、ミッションメニュー、クエストメニュー、修理屋、ベンダーの取引）。死体は範囲内なら回収。ハウジングのオブジェクトはアセットの操作。扉、宝箱、採集ポイントはターゲットのみ。TABはカーソルの下のもの、次にその奥のものをターゲットする。3Dビューに右クリックのメニューはない。詠唱中、生産中、トレード中、演奏中、確認ウィンドウなどを開いている間は、どの動作もできない。

グラフィックのオプション（game.ini）：解像度、リフレッシュレート、色深度、フルスクリーン、トリプルバッファ。点光源、ミップマップ、影の種類（なし / 丸 / 形状 / 形状 PC / 形状 すべて）と解像度、アンチエイリアス、圧縮テクスチャ、頂点シェーダー、バンプマップ、特殊な色処理。レンズフレア、エフェクトの描画、空（なし / 1層 / 2層）、地形とキャラクターの描画距離、1フレームに描画・生成するキャラクター数。ガンマ、コントラスト、明るさ（/gamma）。/weatherdensity OFF / LOW / MID / HIGH。/preloadmap。生産中の描画を減らす設定（combinefps）。自動設定もある。

サウンドのオプション：BGM、効果音、音声のオン / オフと音量、サウンドの優先度、同時発音数、DirectSoundのデバイス、環境音、戦闘音楽、飛行音。コマンドは /bgm、/se。

入力とシステムのオプション：マウスのカメラ感度、アイコンをドラッグするまでの遅延、スクリーンショットのキーと形式（BMP / PNG / JPEG）、日本語と英語のフォント（インストール済みのフォントから選ぶ）、UIのスキンファイル。

スクリーンショット：すべてのスクリーンショットに、著作権表示の画像（333 × 16）が入る。

ロード画面：マップごとにロード画面の画像が決まっている。ほかにタイトル画像と、オープニングの画像8枚がある。

戦闘ログと浮かぶ数値：戦闘ログには「（攻撃者）→（対象） : （数値） ダメージ」、ガードで減らした「（（数値） ダメージ回避）」、「ダメージ回避」「攻撃ミス」「ミス ザ マーク」「0 ダメージ」、魔法・MP・落下のダメージ、回復と毒の表示が出る。クリティカル、カウンター、ガードブレイク、ガードロスト、リアクティブは後ろに付けて表示される。/dispdamage は数値を "Avoid" のラベル付きで表示する。詠唱が中断されると、30 m以内のプレイヤーに知らされる。

ターゲットの情報：ターゲットを調べると、「ターゲットなし」、死体が消えるまでの時間（秒または分）、「強さが分からない」、「（名前） Level （数値） (MyLv=（数値）)」のように表示される。

/split：「/split <amount>」は、同じゾーンのパーティメンバーにお金を均等に分けるコマンドだった（受け取った側はマクロ対策が解除され、渡した側は解除されない）。不具合のため2007年11月20日から使えない。今は「入手したお金の自動分配」オプションで、拾ったときに分けられる。

関連ページ：トップ / 用語辞典

吹き出し：パーティとtellの吹き出しは、位置を知られないよう画面の右下に出る。吹き出しの表示、固定、透明度、フェードはオプションで変えられる。

関連ページ：用語辞典

名前の色：ネームプレートは [ギルドまたは勢力]、フェローシップ>、名前 の順に並ぶ。白は通常（パーティなし）、水色はNPC、濃青は霊体、緑は自分のPT、紫は他のPT、赤は戦闘中のNPC（ペット含む）、青は育成可能なペット、など全10色。色設定で変えられる名前の色は、自分、PC、霊体、パーティ、NPC、飼育 / 召喚 / 一時ペット、死体、PvP、中立、ビスク、エルガディン、GM。

関連ページ：用語辞典 / よくある質問

頭上アイコン：若葉はスキル30未満の「旅人」、星はギルドランク、赤角は売露店、青角は買露店、天秤はNPCショップ、金貨はNPC銀行、猫はペット預かり所、十字はGM、唐辛子はマイページを閲覧中。War Ageでは、星は軍の階級、白旗は中立、赤はビスク、青はエルガディン。アイコンと初心者マークの表示はオプションで切り替えられる。

ゾーン情報の印：(P) パーティ中、(L) リーダー、(GM) ゲームマスター。GMは「（名前）(GM)」と表示される。

銀行員を開けないとき：露店やペットに邪魔されたら、ターゲットのマクロ（/tar <banker name>）、「ターゲットにアクション」キー（Alt+U）、「最寄りのNPC」キー（Ctrl+F9）を使う。/targetnpc でもNPCを選べる。

関連ページ：よくある質問

マップとフルスクリーン：マップはAlt+M、フルスクリーンの切り替えはAlt+Enter。一部のエリアではマップが空白になる（エイシス・ケイブ、タルタロッサ・パレス、ビスク地下水路、ダーイン山、ヴァルグリンドの巣穴、スルト鉱山、すべてのQoAゾーン）。マップは50〜600 %で拡大でき、自分、パーティ、ターゲットの名前が出る。

関連ページ：よくある質問

ウィンドウと表示：Alt+Enterでウィンドウモードになる。Alt+Tabでフルスクリーンのゲームを最小化すると、CPUの負荷が下がる。色設定でウィンドウの背景を半透明にできる。/viewport X Y で3Dビューを小さくする（引数なしならサイズを表示）。スキン（ウィンドウ・アイコンのセット、HPゲージの目盛り）は「skin」フォルダーにあり、オプション > 表示で選ぶ。

関連ページ：よくある質問

操作：キー設定には「FPSモード」と「RPGモード」のプリセットと、全リセットがある。カメラモード「M1」「1」「2」はボタンかF9 / F10で切り替える。Spaceでジャンプ。Ctrl+クリックでアイテムを1個、Shift+クリックでスタック全体を拾う。数量も入力できる。/afk で切り替える。/codelist <letter> でゲームコードを絞り込む。キー設定は184の動作に、それぞれ3つまでキーを割り当てられる。

関連ページ：よくある質問

マクロ：1つのボタンに最大6コマンド。メニューの5ページ目以降を右クリックして登録する。1〜4ページの既定のマクロは、「既定のマクロを復元・保護する」のチェックを外すと消せる。代入文字（%t、%1〜%5、%lt、%r）が使える。マクロは10ボタン × 10ページ。追加のショートカットバーが2つある（「Shortcut」「Shortcut2」、それぞれ10 × 10。「ShortcutとMenuの同期」のチェックを外して使う）。

関連ページ：よくある質問

キャラクターごとの設定フォルダー：userdata\<server>_<character>_ に、colorcfg.ini、keyconfig.ini、msgopt.ini、usergame.ini、wnd.ini、wnd_docking.ini などが入る。

関連ページ：よくある質問

ゲーム内ヘルプ：メインバー > SYSTEM > ゲームヘルプで開く。/gamehelp、/help、/? でも開く。一部のキャンプのNPCは古い説明をする。

関連ページ：初心者ガイド

ログアウト：ボタンを押すとデータを保存する。最低15秒待つ。攻撃されると取り消される。戦闘中などはログアウトできず、ログアウトできない場所もある。コマンドは /logout。

関連ページ：初心者ガイド

オプションのコマンド：コマンドでしか変えられない設定がある。タイトル画面のOPTIONには独自の設定がある。35のコマンドがオプションダイアログと対応する。/density 0.25〜1.0、/namebblimith 16〜64、/effect OFF / MIN / NORMAL / MAX、/bgm、/se、/fashion はチェックボックスと連動する。設定はPCごと（game.ini）とキャラクターごと（usergame.ini）に保存される。

関連ページ：初心者ガイド / コマンド

操作モード：マウス、FPS（既定）、RPGの3つ。FPSはAltなしで動く。キー設定では、1つの動作に3つまでキーを割り当てられる（Escで消去、DEFで元に戻す、1つのキーに複数の動作も可）。既定のキー設定には約120の動作がある（移動、平行移動、視点、ジャンプ、座る、歩き / 走り、自動前進、自動戦闘、メッセージウィンドウ、パーティのターゲット、ショートカットのページ）。設定できる動作は全部で184。

関連ページ：初心者ガイド / コマンド

メインバーとウィンドウ：メインバーは隠したり表示したりできる。ウィンドウの一覧がある。ウィンドウは最小化でき、最小化したときの位置は別に保存される。方位表示を切り替えられる。時計を右クリックすると、4つの表示（Disp Time / FPS / Net / Direction）を選べる。

関連ページ：初心者ガイド

メッセージウィンドウ：システム、会話、戦闘、Auction、Channel、Message5〜6、勢力、検索、演奏結果1〜2の11個。名前の変更、タブ、種類ごとに振り分けるメッセージフィルター、速度を設定できる。/msgclear all / 0-8 で、全部か1つのウィンドウを消す。

関連ページ：初心者ガイド / コマンド

ショートカットバー：ShortcutとShortcut2の2つで、それぞれ10スロット × 10ページ。「Switch Shortcut」で向きを切り替える。Ctrl+Alt+Spaceでウィンドウをロックする。オプション「ShortcutとMenuの同期」は削除された（2011年8月9日）。

関連ページ：初心者ガイド / コマンド

/viewport：3Dビューのサイズを表示または設定する（最小64 × 64、最大は画面の大きさ）。右と下は黒い余白になり、縦の視野角は変わらない。/viewport reset で元に戻す。サイズは解像度ごとに保存される。

関連ページ：初心者ガイド / コマンド

カメラモード：固定1（一人称）、2と3（キャラクターの後ろ）と手動がある。切り替えるとシステムメッセージが出る。キー設定の「視点切替1-3」で切り替える。

関連ページ：初心者ガイド

かつて予定とされた機能：ゲーム内のパーティ募集掲示板、耐久度表示の状態の保存、新しいエフェクト、フェローシップの拡張。耐久度ウィンドウ、/lfp、フェローシップ掲示板は実装されている。

関連ページ：雑学/未実装情報

マクロのタイミング：マクロは0.016秒に1行ずつ進む。pause以外の行は、どれも同じ時間がかかる（6行でpause 1と同じ）。/pause n（0〜599）で待つ。待っている間はほかのマクロを実行できず、中断もできない。pause 1 = ディレイ6 = 0.096秒で、最大57.5秒。必要なpauseは ディレイ ÷ 6。テクニックのディレイはSTの段階で変わる。装備の「ディレイ −1」は −1 %。秒は pause × 0.096 で測れる。

関連ページ：マクロ

マクロの実行：/cmd の行はテクニックを要求するだけで、次の行がすぐに実行される。/cmd の効果は1行遅れて出る。チャージ系は、次の行でチャージし、その次の行で放つ。/equipitem による装備のbuffも1行遅れてかかる。テクニックは発動時の装備を見る（多段のテクニックはヒットごと）。

関連ページ：マクロ

ターゲットの書き方：/tar（/target）と、/cmd [..]、/useitem [..] のターゲット指定には、% の代入（%1〜%5 パーティ、%lt、%r）と <..> の指定（<player>、<enemy>、<pet>、<near ...>）が使える。%lt の名前は同じ名前のNPCに当たることがあり、<lt> が本当の最後のターゲット。buffのマクロでは他人のペットを名指しできず、PvPの味方と敵を区別できず、War Ageでは制限がある。例：/target <near enemy(pet)> name。ほかに /targetpc、/targetnpc、/targetcps、/targetnear（いちばん近いものを探す）がある。

関連ページ：マクロ / コマンド

マクロの例：盾テクニックの順番使いと盾の持ち替え、コウモリやペットへのサクリファイス ディナー、tellで確認しながらのリザレクション、イリュージョン ソードとソニック ストライク、自分かターゲットへの包帯、矢・弾の持ち替え（矢のスロット）、弓の持ち替え、召喚した食べ物を食べる、/swapitembox（スタック全体をつかむ）を使った大量生産。どれも上のコマンドの組み合わせでできる。

関連ページ：マクロ

マクロの保存と読み込み：マクロを名前を付けて保存・読み込みでき、使えるマクロのページが倍になる。コマンドは /savemacro、/loadmacro、/savecolor、/loadcolor。/forgetmacro でカーソル上のマクロを消す。マクロは100個まで、1つにつき6行。ショートカットは62個。

関連ページ：マクロ / コマンド

キャラクターを隠す：/dispotherchara 0-6 で表示を切り替える（0 全表示、1 他のPCを隠す、2 NPC、3 PC + NPC、4 ペット、5 他人のペット、6 PC + ペット）。/dispmyplayer で自分の画面から自分のキャラクターを隠す。

関連ページ：コマンド

エモート：/sleep（120221）、/letsdance（ダンス 80 が必要、110726）。/emote または /em <text> で、名前を頭に付けた文を出す。エモートの後に " motion" を付けると、アニメーションだけを再生する。エモートは83種類あり、そのうち51種類にスラッシュコマンドがある。

関連ページ：コマンド

名前の表示：/dispcharaname で名前の代わりにシップ名を表示する。ほかに /disptargetbbname、/disptargetwindowname がある。Shift+F11 でNPCを含むすべての名前を隠す。オプションで他人の名前を隠したり、シップ名・ブレンド名を表示したりできる。

関連ページ：コマンド / 雑学

/sfxmode：マップの背景を1色に置き換える。QoA のイプス峡谷でのみ使える。使っている間は時刻が 12:00 に固定される。

関連ページ：コマンド

コマンドのヘルプ：/codelist でコマンドを一覧表示する。頭文字で検索できる。/? <command>（/help と同じ）でそのコマンドの引数を表示する。コマンドの分類は NORMAL / EMOTE / WINDOW / SKILL。

関連ページ：コマンド
