項目モンスター/出現条件

出現条件の種類

モンスターの出現には、次のような条件が付くことがある。

  • 再出現までの時間（ランダムの場合あり）
  • ゲーム内の時間帯
  • 指定したモンスターが全員いる・どれかがいる・全滅したあと・どれかがいない
  • 同じグループの仲間がいる・いない
  • マップの状態
  • 抽選（候補の中から 1 つだけが出る）
  • 別のモンスターの出現後
  • 特定のきっかけでのみ出現
  • 時間帯や、ほかのモンスターの有無で消える

条件の付いた出現場所の一覧：モンスターの出現条件（904 件）

ルール（10 件）

  • 抽選POP：再POPのときに、決められた種類の中から決められた確率で抽選し、出現するものが決まる。低確率で通常のものの代わりにレアなものが出る。条件Mobが複数いれば、複数同時に出ることもある。抽選で出る場所が決まっていることもある（例：ガブスは寂れた鉱山の5ヶ所中1ヶ所）。単純な抽選POPの組み合わせは17組（ゴールデン ゴーレム / シルバー ゴーレム、ゴールデン ガーディアン / ミスリル ガーディアン、タルタロッサ スパイラル、謎の覆面レスラー、アルビノ スネーク、黒竹 …）。確率の例：ネオク スパイダー 70 / 30。 →
  • repop時間：倒されてから次にPOPするまでの時間。リアル時間で数える（ゲーム内時間ではない）。再出現までの時間がランダムなMobもいる。時間経過だけでは再出現しないMobもいる。 →
  • 全滅条件：「全滅」は、対象のどれかが倒されたときに、ほかの対象が生きていないかで判定される。ぴったり同時に倒すと判定が狂うことがある。再出現した端から倒せば、その都度判定される。一覧：ブロンズ ゴーレム全滅後のファイアー ゴーレム / フレイム ゴーレム、ツィー / ツァー / ツヌーグの後のオーク ジャイアント、エリゴスとガープの後のエゼイジア、ベビードラゴン7体の後のネオク ドラゴン、グレイブン ロード4体の後のテスラ / ミスラ、キング ファンガス、マンイーター プラント、キラーアント クイーン（ガードはその15分後にrepop）、デスワーム、バードイーター（遺跡）、ター・フルーク / ター・メリア / イー・ラッカ、異国の剣士（15分 + 下忍全滅）。 →
