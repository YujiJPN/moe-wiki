ルール（11 件）

  • シップ装備クエストのクリーチャー：通常1種類の攻撃しか受けない。ギルドマスターの専用Buff（漢気、加護、呪詛）の追加攻撃でしか傷つかないこともある。反射ダメージは効く。Buffはエンチャント系で必中なので、速い武器（カッパーダガー、ディレイ84）が最適。詠唱するクリーチャーの妨害もできる。 →
  • クエストのBuff：効果時間はログインしている間だけ減る。制限時間はBuffの効果時間と同じで、クエスト中にBuffを更新することはできない。基本の装備は時間切れの後も報告できるが、複合の装備はBuffが続いている間だけ。 →
  • クエストのクリーチャーのドロップ：クエストを受けていなくてもルートできる。着用中の装備を上位段階に変えると2つ持てる（例：ガーズマン シールドを装備してディフェンダー シールドにし、もう1つ得る）。装備の段階の変化は称号で制限される。 →
  • スー・メリア クエスト：ギルドランク★★★になると、各ギルドが初心者をケール・タングンで案内するクエストを出す。初心者とは、ネヤを一度も出ておらず、イヤリング オブ モラを持ったことのないキャラクター（称号 旅人）。ギルドメンバーが率いる2-5人のパーティーで挑む。ゲートは30 秒、スイッチは5分。ボス「ター レン ゼー」は初心者しか傷つけられず、ギルド側はフロア ガーディアンを抑える。報酬は、初心者がイヤリング オブ モラ、ギルドメンバーがスー・メリア。スー・メリアは後でギルドのスー・メリアのクエストに納品する。 →
  • ケール・タングン：隠れ里ネヤから出たことのない初心者のためのゾーン。クエストのゾーン 1 つとボスのゾーン 3 つ（赤の床はスー・メリアのクエスト用で初心者同伴のときだけ、青の床のボスはピクシー ウィザード、緑の床のボスはモリ・サーティーン）。ネヤのチュートリアルのメニューで説明される。初心者のクエストもある。 →
  • ギルドランクアップの式：ギルドスコア = f x GP + (1 - f) x 100 x（スキル x 重みの合計）。f は戦闘系 0.5、生産系 0.6。ランク r にはスコア (r / 4)² x 10000 = 625 / 2500 / 5625 / 10000 以上が必要。戦闘系では GP + 100 x 4スキルの平均 >= 1250 / 5000 / 11250 / 20000。生産系では GP + 66.7 x スキル >= 1041.7 / 4166.7 / 9375。グロム・スミスは GP + 33.3 x（採掘 + 鍛冶）。 →
  • ギルドランクの表示：★ から ★★★★（アーテリックのみ ★★★）。5ランクの予定だった（ランクアップクイズの答えは「ランク5つ」）。どのギルドにも5つのランク名がある（例：武閃 無刀 / 木刀 / 鉄刀 / 豪刀 / 一閃刀）。 →
  • ギルドポイント：ギルドクエストで得られ、ランクにのみ使われる。最大10,000で、ギルドに所属している必要がある。ギルドクエストを破棄すると、ギルドランクに応じて -10 / -50 / -200 / -400 / -800 のGPを失う。失敗などのもう一方の場合は、ギルドランクに応じて -5 / -25 / -100 / -200 / -400。減る量はクエストのランクではなく、自分のギルドランクで決まる。 →
  • 降格：ランクのしきい値を下回る（スキルの低下またはGPの減少）と降格する。シップ装備は剥奪されないが、スキルが条件を下回ると着用できない。 →
  • ギルド：スキルグループごとのNPCの組合。会員はギルドクエスト、ギルド専用の技と装備を得る。ギルドは「無所属」のほかに9つ。9番目の盗賊ギルド「盗賊」（盗み x1、本拠地はビスク中央、ランク名は料理人ギルドと同じ）は、よく知られた8ギルドに含まれない。GMコマンドには /setnpcguild、/npcguildrankup、/addnpcguildpoint、/dispguildrankrec がある。 →
  • シップ装備クエスト：ギルドマスターは、称号を名乗れる者に特殊な装備を貸与する。その装備は壊れない（NB：耐久度は1で止まる）。ND（WarAgeの死亡で落とさない）も付く。ただし、ChaosAgeの門で死亡して戻ると、CAアイテム以外はシップ装備も含めてすべて失われる。 →
