ルール（5 件）

  • テクスエンドの通常クエスト ★ から ★★★★：「結ばれた、誓い」（綿の糸3個、50 GP）…「気持ち伝える、微笑」（520 GP）。冥王の針は5個単位。スー・メリアのクエストもある。 →
  • テクスエンドのランクアップクエスト：「【紡ぎ手】への課題」（ザムトのクイズ）、「【織り手】への課題」（自作のレザー シールド、チュニック、ブーツ）、「【裁縫師】への課題」（自作の胸リボンと小さなリュックサック）。 →
  • テクスエンドのシップ装備クエスト：「雷鳴に咲く、[裁縫]の花」（テント修復布 -> 仕立て屋 ハサミ）。「仕える心は、[ハウスキーパー]の証」（裁縫、料理、美容40。64レシピのバインダー、掃除の場所、衣服 -> ハウスキーパー装備）。 →
  • ギルドランクアップの式：ギルドスコア = f x GP + (1 - f) x 100 x（スキル x 重みの合計）。f は戦闘系 0.5、生産系 0.6。ランク r にはスコア (r / 4)² x 10000 = 625 / 2500 / 5625 / 10000 以上が必要。戦闘系では GP + 100 x 4スキルの平均 >= 1250 / 5000 / 11250 / 20000。生産系では GP + 66.7 x スキル >= 1041.7 / 4166.7 / 9375。グロム・スミスは GP + 33.3 x（採掘 + 鍛冶）。 →
  • 裁縫師ギルド テクスエンド：ギルドマスター レーヌ、ギルドガイド ザムト、本拠地 ネオク高原北東。ランクは 紡ぎ手 → 織り手 → 裁縫師 → 縫飾師 → 糸の魔術師。入会には織布の技とレシピバインダーが必要。ギルドスコアは裁縫 x1、f = 0.6。 →
