項目雑学/未実装情報

ルール（14 件）

  • 運営のメモ（履歴）：欠番のテクニックを埋める予定はない。PresentAge では回避が弱く感じられる。有料アイテムで合計 850 を引き上げる案が検討され、2006年のパッチで 120 を 100 として扱ったが、元に戻された。ギャンブルスキルとハイアー セラー / ハイアー バイヤーは未実装。ギャンブルスキル自体はあり、GAMBLE の画面にはポーカー、ブラックジャック、スロットマシンがある。 →
  • 実装されなかったシステム：着こなしスキルで装備のアニメーション速度が変わる戦闘態勢の切り替え、ディレイを短くするコンボ、フェローシップ対抗戦（ネオクのアリーナが追加された）、追加の種族（人間、妖精、オーガ…）。戦闘態勢そのものはある。戦闘態勢の外では被ダメージ × 1.1、戦闘態勢に入ると詠唱がキャンセルされる。 →
  • 魔法タイプのペットは、ペットの魔法が必中である（そのぶん威力が低い）ため、仕様としてMPが不足しがちになっている。調教シップのバッグは、もともとペットを入れるためのものだった。 →
  • シップ装備：3次シップ装備の染色が段階的に追加された（複合6種＋基本14種）。複合シップ装備は移送のためにワンダー クロースで梱包される。染料の調合は美容で行う。 →
  • レコード ストーン：バインダーには入れられない。/setlocmemo <文字> で、カーソルで掴んだストーンにメモ（半角10文字まで）を書ける。何も掴んでいないと「カーソルに何もありません」と出る。テレポートの行き先はホームポイントまたはこのストーン。 →
  • アイテムの経緯：銃 / 弓のクリティカルで射手を止める案があった。ミュージック スコアには入手方法がなかった。旧課金アイテムは再販されない。ジェネラル装備一式はお蔵入り。使われなかったアイテム：ウー成体、ドラゴンストーン、チップの交換、ギルドの旗、達人への報酬。銀製の防具は対アンデッドの予定だった（代わりに AC が高い）。満腹度 / 潤喉度 / 酩酊度の装備補正は未実装。耐久の減らないミスリル修理。特定の種類の相手に強い防具は、その相手からの攻撃に対して AC が上乗せされる。NC は修理で最大耐久度が下がらない。 →
  • 生産と作成可能リスト：材料がわかっていればレシピは要らない（一部のアイテムは必要）。ボックスに余分な材料がある場合やスキル不足の場合、アイテムは表示されない。2022-01-11 のパッチで、材料の足りないバインダーのレシピを隠す「作成可能」チェックボックスが追加された。必要スキルをすべて満たし、必要な道具を持っていないと候補に出ない。365 のレシピはレシピバインダーが必要。材料の枠は 8。 →
  • WarAgeの支配：すべての拠点を占領した勢力は「奇跡」の効果を、もう一方は「呪い」を受ける。奇跡と呪いには効果時間がある。支配状況は /warinfo で確認できる。勢力はエルガディン、ビスク、サスールの3つ。第三勢力サスールは、専用マップと階級装備とともに予定されていた。 →
  • PresentAgeとWarAgeでの効果の違い：技によっては、対人戦・WarAgeとそれ以外とで威力が異なる。WarAge専用の技と、WarAgeでは使えない技がある。アイテムにも、WarAgeの中または外で弱くなるものがある。 →
  • シップに関する記録（歴史）：複合シップのパッシブ効果の再調整はなし。アイコンだけの複合シップ（「FRE」）がある。ペット4体を操るブリーダーと、サムライの切腹は見送られた。複合シップ装備は8シップ（以前は11）で、存在は未確認。アイテムの成長とシップ専用装備のほかに、称号そのものの効果はない。 →
  • ギルドの歴史：ギルドランク5には到達できないとされていた（より多くの関連スキルの上位3つで判定する予定だった）。新ギルド（芸人または盗賊）は実現可能と言われた。ギルドは各5ランクで、盗賊ギルドもある。 →
  • 土地の権限：共同所有者（土地の拡張と家の建築・撤去以外はすべてできる）、アセット利用者、ストレージ利用者、ベンダー利用者がある。土地には進入の許可・禁止と、操作の役割（管理者、ベンダー利用者、ストレージ利用者、アセット利用者）を設定する。家には入室の権限がある。 →
  • ノアドールとNPCベンダー：決まったメッセージを話す。開店・閉店のメッセージと挨拶を設定できる。名前も変えられる。ノアドールはアイテム、顔、髪で着飾れる。 →
  • かつて予定とされた機能：ゲーム内のパーティ募集掲示板、耐久度表示の状態の保存、新しいエフェクト、フェローシップの拡張。耐久度ウィンドウ、/lfp、フェローシップ掲示板は実装されている。 →
