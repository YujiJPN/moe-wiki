シップの決まり方

シップ一覧（全 281 件）

  • スキル値が変わるたびに、種族が合い、必要スキルをすべて満たすシップの中から点数がいちばん高いものになる。
  • 点数 = (0.7 × 必要スキルの数 + 1) × 必要スキル値の平均² × 0.01
  • 点数が同じなら、そのスキルの自分の値の合計が大きい方。それも同じなら今のシップのまま。
  • どれも満たさなければ、初期のシップ（旅人など）になる。
  • シップのランク（初心者〜廃神）は、シップのスキルの値がスキルランクの表のどこまで届いたかで決まる。
  • 旅人でスキル合計が 100 未満のあいだは、満腹度・潤喉度が減らない。
  • シップには、シップ装備のほかに特別な効果はない。

ルール（8 件）

  • クラスはない：「シップ」はスキル値から自動的に付く称号。他人のシップは、PCの右クリック、consider（Alt+C）、ゾーン情報のPC一覧で確認できる。スキルが変化するたびに称号が判定され、「シップが （称号） になった！」と表示される。 →
  • 旅人：戦闘以外のすべてのスキルが30未満なら、称号は旅人。戦闘のみのスキル（および2012-03以前の自然回復）ではシップは付かない。どの称号の条件も満たさないときは旅人になる。旅人は、空腹と初心者マークに関わる初心者の状態でもある。 →
  • 基本シップと複合シップ：スキル1つが30 / 60 / 90に達すると基本シップ。あるセットのすべてのスキルが40 / 70 / 90以上になると複合シップ。称号は281種類で、うち274に条件がある。条件はどの種族でも同じ。 →
  • 複数が該当するときに表示されるシップ：基本1次 < 4スキル以下の複合1次 < 基本2次 < 5スキル以上の複合1次 < 基本3次 < 4スキル以下の複合2次 < 5スキル以上の複合2次 < 複合3次。順位はスコア = (0.7 x n + 1) x 平均² x 0.01 で決まる（n = 必要スキル数、平均 = 必要レベルの平均）。スコアは順に 15.3 < 60.8 < 61.2 < 72 < 137.7 < 186.2 < 220.5 < 307.8+。同順位なら、キャラクター自身のスキル値の合計が高い方、次に現在の称号が優先される。 →
  • 称号が変わるタイミング：いずれかのスキルで「0.1 up」のメッセージが出たときにだけ変わる。例：回復魔法 90.0500 と 魔法熟練 90.0501 ではプリースト ロードのまま。称号の条件は整数のスキル値で判定され、結果が変わるのはスキルが表示上の0.1刻みをまたいだときだけ。 →
  • シップ装備：各シップには専用装備（ギルドクエスト、FutureAgeほか）があり、シップとともに1次 → 2次 → 3次と成長する。別の称号を表示していても、シップの条件を満たしていれば着用できる。条件を満たさなくなると、効果も見た目もなくなる（釣竿などのルーレット効果は例外）。装備は、条件を満たした最後の段階の形で表示される。成長するアイテムは668種で、うち582種の説明に「シップ装備」とある。 →
  • マスタリー：複合シップの「究極奥儀の書」を使うと、シップの条件を満たしている間働くパッシブ技を覚える。強さは1次 / 2次 / 3次で変わらない。技名は「（シップ） マスタリー」で、必要スキルは40。例：ウォーリアーは刀剣のディレイ短縮、アルケミストは詠唱高速化。称号そのものには効果がない。 →
  • マスタリー同士の干渉：ウォーリアーの補助を付けたサムライが二刀流を失った。NECとEVIを同時に使うと、NECの効果がなくなる（「現段階では仕様」）。 →
