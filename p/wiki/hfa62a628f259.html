ルール（33 件）

  • 時の欠片交換カード：赤の廟堂の交換ボックスで、時の欠片（個人用の時の石）と交換できる。カードも時の欠片も NT。時の欠片は封印されていて、使うとブーストの上限が決まり、そこまでスキルが 30 倍の速さで上がる。 →
  • 愚者の石と輪廻の石：愚者の石はスキル 1 つの上限を 1.0 下げる。輪廻の石は上限を、現在値以下の選んだ値まで下げる（90 から 10 まで 10 刻み）。 →
  • スキルアップ ポーション：スキル上昇率 +20 %。DX は +50 %。効果時間は 652.8 秒（約 11 分）。ガチャ限定。同じ種類は上書きされる。スキル上昇率の Buff は、先に付いたもの 1 つだけが効く。 →
  • プレミアムチケットとスペシャルチケット：使用中はスキル値が下 4 桁まで表示される。プレミアムチケットはスキル上昇 +20 %、死体引き寄せ時のスキル減少 −50 %、満腹度 / 潤喉度の減り −30 %、ゲージ速度 −15 %。スキル成長強化プレミアムは +40 % / −70 %。生産向けプレミアムチケットは +10 %、−50 %、満腹度 −20 %、ゲージ速度 −20 %、滑り −15 %。スーパープレミアムは +100 % / −100 %。スペシャルチケットは 1日 +100 % / −100 %（SP +120 %）。プレミアム系とスペシャル系は 1 つずつ同時に使え、ボーナスは加算される（100 + 100 + 100 = 300 %、時の石は +3000 %）。上昇率 = 1（時の石のブースト中は 30）+ チケット 2 枚分 + スキル上昇率の Buff。範囲は −50〜50 倍。2016-06-28 以降、死体のスキル減少の軽減はすべてのエイジで効く。プレミアム中は /killmyself の待ち時間がなくなる。 →
  • 秘伝の巻物 ツイン ショット：両手のハンドガンを続けて撃つ。左手に銃がなければ右だけ。片手銃のみ。 →
  • 課金の戦闘バフ（効果時間 652.8秒）。タイプAは自分、味方、ペットにかけられ、PresentAge と ChaosAge で使える。デメリットなし。タイプBは自分だけ、全時代で使えるがデメリットがある（ND）。風神の加護 移動 +20 / +10（Bは毎秒 1.625 ST 減少）、戦乙女の加護 攻撃力 +10（B 最大ST −20）、戦神の守護 防御力 +20（B 耐性 −10）、オウル アイ 命中 +10、忍者の極意 回避 +10（B 最大ST −15）、英霊の加護 魔力 +10（B 最大HPとMP −10）、愛のチカラ 最大HP +30、賢者の秘術 耐性 +20（B 防御力 −10）。風神の加護 SP は移動 +50、30分。風神の加護 A / B / SP は移動系テクニック（ツイスター ラン、ラスト スパート …）と重複しない。 →
  • 2010-01-19 から、タイプAのバフと 風神の加護 SP はヌブール村では使えない。 →
  • バエルウォッチャーの契約書：バエル ウォッチャー（Lv 30、HP 80、MP 226）を8分間召喚する。その間、使用者は定期的に10ダメージを受ける（バエルが死んでも続く）。同時に1体。召喚魔法と併用できる。SP版はレベル50。 →
  • マンドレイクの種：植えるとマンドラゴラを召喚する。栽培スキルが高いと同時に多く出せる（100で3体）。マンドラゴラは Lv 30、HP 138 で、時間では消えない。その叫びは魔法ダメージ（22）と、対象を逃げさせる固定10秒の技使用不能のデバフを与える。 →
  • ペットの成長と速度のアイテム：ラブペット ペットの成長 +20 %（652.8秒。ゾーン移動かログアウトで消える）、DX +100 %、SP 32.6分間 +100 %、ALL 全ペットに +50 %（バフはプレイヤーにかかる）、M（30分。ペット死亡時の忠誠度低下なし）、シルフのキス 自分のペットの移動 +30 %（Ａ）/ +16 %（Ｂ）。ペット側の成長率は加算される。ラブペットとラブペット SP は重ねがけできない。 →
  • ワーシップ ポーション：自分の死んだペットを、レベルを下げずに蘇生する。 →
  • ぱくぱく フード：ペットの忠誠度を約60回復する。エサの種類ごとに1種類ある（食べ物、飲み物、酒、金属、木、布、皮、石、紙、クリスタル）。 →
  • ノアクリスタル オブ フクモ ドール：成体のホムンクルスのペットにトレードすると、元の見た目に戻る。変化の秘石：ペットの見た目と能力を変える。 →
  • チカラ モチ：空腹を解消し、約10分間最大所持重量 +50 %（P / C / W）。満腹度 +12。SP 版は +100 %。 →
  • 課金ポーション：グッド ヒーリング / スタミナ / マナ ポーションは HP 40 / ST 40 / MP 30（アイテムディレイ約11秒、薬調合の影響なし、ND）。ファイン ポーションは HP / ST / MP 各20。万能治療ポーションはステータス ダウンを2つ解除。アイテムディレイはすべてのアイテムで共通。 →
  • マーメイドの誘惑：約3分間（195.8 秒）泳ぐスピードが上がる（泳ぎ +50）。その間、足防具の耐久度が減り、着脱できない。マーメイド ミミックに上書きされる。 →
  • スーパー バンブーシュート：約3分間巨大化する（ガチャ限定）。巨大化はサイズ × 2、ジャンプ × 1.4、攻撃力 +20、移動速度 +20。WarAge ではステータスは上がらない。 →
  • 変身アイテム：誠意の証（10分間マスコットに変身、リボーン（自動蘇生）付き）と雪の妖精（5分、サイズ 3.0）。どちらもジャンプで解除される（ガチャ限定）。 →
  • 生産用バフ：人間国宝の爪のアカ（1 分間ゲージの滑り −15 %。チャージ、属性付与、ミスリルには効かない）、匠のワザ（MG +3 マス）、職人のワザ（HG +3 マス）、偉人の極み（ミスリルの成功マス増加）、先人の知恵（ミスリルのルーレット 15 % 遅く）。SP 版（滑り −30 %、MG / HG +6、成功マス 3 → 6、ルーレット 30 %。販売終了）、マイレージから交換できる EX 版、G-MONEY の特典。 →
  • 鬼の魂：メフィスト武器シリーズのガチャ限定素材。 →
  • 秘伝の本：使用回数付きの課金レシピ本（1 回、4-10 回、300-4,500 SP。コンバイン 1 回につき成否にかかわらず 1 回減る）で、課金の外見セットを作れるようになる。セットごとの生産スキル：裁縫、裁縫 + 木工、裁縫 + 装飾細工、鍛冶 + 装飾細工。レシピ本を持っているときだけ作れる。 →
  • 課金の染色アイテム：スペシャル花びら（6 色 200 SP、白／黒 500 SP。ネオク山の NPC クノッヘンに渡す）、箱入り染色液（350 / 700 SP。ハロウィンの色と RGB の割合）、脱色剤、イロモドール（染色した装備を未染色に戻す）。染色では色材料の RGB が平均され、もとの色と混ざる。 →
  • 課金の美容アイテム：顔見本 No.6 / No.7、医学書（性別変更）、ホムンクルス美容手術用のホムンクルス人形 8 種（種族 × 性別）。 →
  • 課金の育成アイテム：植物用栄養剤、植物成長促進剤、栄養剤＆促進剤 Lv1-4 を 10 / 50 / 100個のパックで。育成アイテムの効果 = 強さ × 個数（作物の好きなものなら × 2、嫌いなものならマイナス）。促進剤は残り時間を 個数 × アイテムごとの分数 だけ減らす。栽培スキルが必要。 →
  • 預かり品お届けサービス（銀行からの引き出しのみ）と出張買取サービス（買い取るだけの商人）。どちらも召喚ペットとして数えられる（ペットの上限に入る）。Present Age のみ。約 130 秒（130.56 秒）で去る。 →
  • テレポート ゲート：50 %の確率でスキル 1 つが 0.1 下がる代わりに、ホームポイントへテレポートする。レコード ストーンと組み合わせられる。Present Age のみ。 →
  • ギルドからの召集状：自分のギルドのマスターのところへテレポートする。ギルドがなければビスク中央のアルターへ。Present Age のみ。 →
  • Ancient Ageの土地アイテム：エンシェントコイン（ハウジングマップの土地を維持する）、特殊販売員 優先契約書（ペットを店員にする）、土地グレードアップチケット（サポート窓口を通じてグレード+1）、土地グレードアップチケットセット、スペシャル ストレージ キー（ストレージアセット用）、生産設備 設計図。コイン1回分の維持日数は6 / 5 / 4日。グレードはグレードポイントで決まる。ストレージ数はグレードで決まり、拡張1回につき4増える。 →
  • スペシャル ハウスキット：建設期間なしで家が建つ。コテージ、モラハウス、ブロックハウス、ログハウス、ドラキア風ハウス、ヤマトハウス（700 SP）。レンガハウスとモラハウス2は2区画が必要。ほかに店舗ハウス、サンルームハウス、クリスタルパレス、湯屋、コーナーパーラーハウス。トイハウスはギフト。キットの家は種類ごとの建築時間がかかり、建築時間が0の家はすぐに完成する（進捗度100）。 →
  • 記憶のスクロール：青のダンジョンで、リセットされた後も前回の進行から再開できる。廟堂は階層ごとに進行を記録し、ポータルを使わずに死ぬか時間切れになるとリセットされる。 →
  • 戦禍の星（WarAge 限定、2010年に販売終了）：死亡時に落とすアイテムの数を、星の残り耐久度だけ減らす。耐久度が残っていれば星そのものが落ちる。例：2つ落ちる場面で、耐久度 3/3 なら 1/3 になった星だけが落ちる。2/3 なら星は消え、何も落ちない。1/3 なら星は消え、アイテムが1つ落ちる。 →
  • 気まぐれな死神：他のプレイヤーの死体を使用者のもとへ引き寄せる（霊体に使う。コープス ミーティング と同じ）。使うと使用者の HP、ST、MP が 1 になる。同じエリアでのみ使える。ボスの音楽が流れる。両者が離れると死体は元に戻る。 →
  • シスター ソング：使用者以外の死んだプレイヤーを復活させる。復活した者は、満腹度と潤喉度も含めて全快でホームポイントに戻る。 →
