ルール（9 件）

  • サムライ マスタリーと二刀流：左手に刀剣（盾やこんぼうは不可）を持ち、右手が片手武器か素手のとき、右手の攻撃が命中すると続けて左手でも攻撃する。左手の攻撃には別に命中判定がある。ステータス上は 2 回と数える。左手のダメージ = 左手武器の攻撃力 × 0.463 × (1 + 0.01 × (刀剣 − 1))。ディレイ = 武器の間隔 × ST の係数 × 装備の係数 × 特殊な係数（バーサーク 13 %、レモン かき氷 20 %、リリース オブ フォース 25 %）。ディレイの下限は 150（2.4 秒、例外あり）。神秘魔法のブレイド付きでは 168。 →
  • マスタリー：「究極奥儀の書」で覚えるパッシブ技。条件を満たしている間有効で、1-3次で強さは同じ。条件は表示中の称号ではなく、技自身のスキル条件（2つのスキルがそれぞれ40以上）。待機モーションを変えるマスタリー（SAG、DKF）は、戦闘状態とそのAC +10 %を打ち消す。 →
  • マスタリーによるSpeciality / Spellの短縮：最新の一つのみが適用される。同系統の他の効果（Specialityはバーサーク、Spellはラピッド キャスト）とは重複しない。例：ウォーリアーと海戦士。 →
  • マスタリーの書の入手元：基本マスタリー5種（ウォーリアー、アルケミスト、フォレスター、ネクロマンサー、クリエイター）は、かつてはチュートリアルでのみ入手できた。現在のチュートリアル出口の出発キットには含まれない。現在は複製で作成でき、技書屋で売られている。無関係な課金の書もある。 →
  • ディレイまたは詠唱時間を短縮するマスタリー：ウォーリアー 刀剣ディレイ x 0.95。フォレスター 弓 x 0.95。海戦士 槍 x 0.95 と泳ぎ速度 +17。爆弾男 罠 x 0.95。チンピラ こんぼう x 0.95。ネクロマンサー 召喚魔法 x 0.95。イビルナイト 死の魔法 x 0.94。ブリーダー 調教 x 0.95、ペット経験値の表示、ペット経験値 x 1.2。傭兵 最大重量 +10、攻撃ディレイ -3。ブラッドバード 音楽スキル +5 とシャウト x 0.95（音楽の短縮は2021年に置き換え）。アルケミスト 詠唱時間 x 0.95 のみ。 →
  • ステータスや回復を上げるマスタリー：ブレイブナイト 防御力 +5。デュエリスト 攻撃力 +3。酔拳士 回避 +3 と酔いの待機（および移動）モーション。荒くれ者 HP回復 毎秒 +0.69。アスリート ST回復 毎秒 +0.875。コレクター 最大ST +10 と最大重量 +10。エレメンタルナイト 火 / 水 / 風 / 地の耐性 +10。 →
  • 特殊効果を持つマスタリー：アサシン 斜面で垂直に立つ、移動速度 +6、クリティカル +0.1。アドベンチャラー 落下ダメージ x 0.9 と泳ぎ速度 +6。スパイ 盗み確率 +3。ドルイド 毒を解除。テンプルナイト アンデッドへの聖なる追加攻撃（強さ2.3）。紺碧の賢者 詠唱中の移動 x 1.36 と賢者モーション。物好き 移動できない技を移動しながら使える、傷ついた戦士のモーション。新人アイドル / オールド アイドル キラキラ（見た目のみ）。パイレーツ 水中呼吸。自由人 走る速度 x 1.05。 →
  • 生産系マスタリー：クリエイター 鍛冶と木工のゲージ速度 -10。グレート クリエイター 最大重量 +20 と8つの生産スキルのグレード x 1.1。マイン ビショップ 鍛冶のグレードゾーン +2.2。厨房師 料理と醸造のヒットゾーン +1。ハウスキーパー 裁縫のヒットゾーン +5 と裁縫のゲージ速度 -10。アカデミアン 複製のヒットゾーン +5 とグレード x 1.1。 →
  • コスプレイヤー マスタリー：ほぼすべてのシップ装備を、そのスキルなしで着用でき、ランクも保たれる。スキルを満たしていれば、通常どおりランクに応じて変化する（コスプレイヤーなしでは、スキル0でナイト装備は装備できない）。 →
