ルール（5 件）

  • グロム・スミスの通常クエスト ★ から ★★★★：「その涙、地にひそむ」（銅鉱石、20 GP）…「その鎖、谷をみつめる」（550 GP）。針金は10個単位で渡す。スー・メリアのクエストもある。 →
  • グロム・スミスのランクアップクエスト：「【砕石の槌】への要務」（クイズ）、「【粗金の槌】への要務」（スチール カイト シールド、鍛冶29）、「【黄金の槌】への要務」（自作のシルバー スピア、鍛冶54）。 →
  • グロム・スミスのシップ装備クエスト：「[鍛冶]で固めよ、国威」（再利用できる焼印でドラゴン サドル -> 鍛冶師 ハンマー）。「[採掘]に砕けよ、遺物」（夜にゴーレムのエルブかジガンテを採掘だけで倒す -> マイナー ピックアクス）。「[マインビショップ]への要務」（40分のBuff「忘れぬ魂」、ガルム岩 -> マイン ビショップ装備）。 →
  • ギルドランクアップの式：ギルドスコア = f x GP + (1 - f) x 100 x（スキル x 重みの合計）。f は戦闘系 0.5、生産系 0.6。ランク r にはスコア (r / 4)² x 10000 = 625 / 2500 / 5625 / 10000 以上が必要。戦闘系では GP + 100 x 4スキルの平均 >= 1250 / 5000 / 11250 / 20000。生産系では GP + 66.7 x スキル >= 1041.7 / 4166.7 / 9375。グロム・スミスは GP + 33.3 x（採掘 + 鍛冶）。 →
  • 鍛冶屋・採掘師のギルド グロム・スミス：ギルドマスター マレウス、ギルドガイド ハスタ、本拠地 ネオク高原。ランクは 砕石の槌 → 粗金の槌 → 黄金の槌 → 珠玉の槌 → 竜神の槌。入会には採掘の技、レシピバインダー、つるはしが必要。ギルドスコアは採掘 x0.5 + 鍛冶 x0.5、f = 0.6。 →
