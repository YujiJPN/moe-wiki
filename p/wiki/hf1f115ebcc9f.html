ルール（17 件）

  • 消耗度表示のアイテムは見えない使用回数で動き、1 ポイント = 40 回。耐久度ウィンドウの % は表示される消耗度より正確。 →
  • 生産と修理のテクニックは、名前のある NPC（鍛冶屋、大工道具屋など）が売る秘伝の書で覚える。 →
  • 修理テクニック：鍛冶(修理)（スミスハンマー、ST 0、発動 100、ディレイ 1000）、洋裁(修理)／大工(修理)／装飾合成(修理)。ディレイ 1000 は 16 秒（1 = 16 ms。16.67 秒は 1/60 秒で計算した誤り）。 →
  • 素材で修理スキルと NPC（金属／布／木／アクセサリーの修理屋）が決まる：鍛冶はカッパー 1、ブロンズ 10、アイアン 20〜クリスタルとカオス 90。裁縫は綿 10、絹 20 など。木工は木 1、骨 15 など。プラント製品は布の NPC、骨／石／紙は木の NPC、ガラス／クリスタルは鍛冶屋（2012-02-21 / 2012-02-28 パッチ）。装飾品はすべてアクセサリーの修理屋。アイテムの「素材」の行で確かめる。 →
  • 最大使用回数が 40 以下（1/1 と表示）のアイテムは修理できない。回数表示のアイテムは 40 回で 1 と数え、修理でさらに 1 回分を失う。 →
  • NC のアイテム（シップ装備）は修理しても最大値が下がらない。 →
  • 最大値と現在値の差による修理費用の倍率：消耗度表示は 20 から ×2、10 ごとに +1。使用回数表示は 150 から ×2、75 ごとに +1（NPC の料金とプレイヤーの材料数）。材料 = max(1, int(減った分 × 0.1))、回数表示のアイテムは × 1/75。 →
  • NPC 修理：90-100 % → 最大値 = 残り。30-90 % → 最大値 × 0.90。30 % 未満 → 最大値 × (d / 3 + 80) %。NPC の修理料金は料金表どおり。最大耐久度の回復は価値 × 0.4 かかる。 →
  • プレイヤー修理：96-100 % → 最大値 = 残り。30-96 % → 最大値 × 0.96。30 % 未満 → 最大値 × (d / 3 + 86) %。必要スキルちょうどだと減りが大きい（必要スキル + 20 を勧める）。アイテムを壊すことはなく、スキルが足りていれば必ず成功する。3 回以上修理するなら、30 %で修理すると合計の使用回数がいちばん多い。正確には、スキル ≧ 必要スキル + 20 なら ×0.96。そうでなければ確率 (スキル − 必要スキル) ÷ 20 で 0.9 + 0.003 × (スキル − 必要スキル)、それ以外は ×0.9。30 %未満では、この倍率から (0.3 × 最大値 − 現在値) ÷ (0.3 × 最大値) × 0.1 を引く。新しい最大値は現在値より下にならない。 →
  • プレイヤー修理の「バグ」：計算で表示上の最大値が変わらない場合でも、アイテムが 1 ポイント丸ごと失う（9/9 ではなく 2/9 → 8/8）。安全な閾値 R < 42 − 11700 / (N × 40 + 39)、最大値ごとの表、−0.1 %の余裕。仕様かどうかの議論もある。回数は整数に切り捨てられ、さらに 1 回分を失う。 →
  • 状態修理（錆、ヒビ、ほころび、硬質化）は NPC で購入価格の 0.4 倍、または NPC だけが売る材料（金属研磨剤、木工用接着剤、布修復パッチ、皮柔軟剤。重さ 0.8、価格 350）で行う。 →
  • ほかのプレイヤーのための修理：客がアイテム、材料、代金を入れる修理ウィンドウがある。トレードは要らない。 →
  • 修理に使えない似たアイテム：研磨剤は金属研磨剤ではない。テントの補修布は使えない。弓はノコギリで修理する。 →
  • NPC の修理料金 = 素材の基本値 × スキル係数（装備の必要スキル ÷ 40、最低 0.025）× 耐久係数（(200 − %) ÷ 100）× 差の係数（差 ÷ 75 または ÷ 10、最低 1）、切り捨て。素材の基本値：カッパー 80〜オリハルコン 900、木 12、竜の皮 72、クリスタル 2,880、カオス 5,400。 →
  • 修理 NPC：4 種類（金属、布、木、アクセサリー）と設置場所。エルビンの行商の修理屋は決まった曜日だけ。AncientAge のオートベンダーは 4 種類すべてを扱う。修理屋の種類はアイテムの修理の種類と合っている必要がある（何でも直せる修理屋もある）。 →
  • アセット(修理)：ターゲットした家のアセットを、アセットの素材のスキルで修理する。使用ST 0、必要スキルは鍛冶 / 木工 / 裁縫 / 装飾細工 1。何も修理されなくても、使うとアセット リペアー キットを消費する。右手のアイテムは使用可能回数が1減る。耐久度のあるアセットは毎日耐久度を失い（基本5×家の清掃値の係数）、0で壊れる。 →
  • 装備の耐久度ウィンドウ：F6 の一覧か /window durable で開く。色は黒、黄（50 %）、橙（30 %）、赤（10 %）。 →
