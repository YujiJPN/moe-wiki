ルール（4 件）

  • フォレールの通常クエスト：「黒き、災」（コウモリの羽。コウモリには矢だけが効く）、「死の、棘」、「砂の、罠」、「闇の、手」、「黄泉の、姿」（冥王の矢）、「古の、獣」（バルドスの肉5個ごと）、「白き、望」（スー・メリア、書 [ アサシン ]）、「眠りの、場」、「友の、瞳」（ガルムイクシオンの入ったアニマルケイジ）、「風切る、羽」（タルタロッサの羽根50枚ごと。F = 65X - 5 のとき矢を作る際に余りが出ない）。一部のクエストでフォレスターの信頼度が上がる。 →
  • フォレールのランクアップクエスト：「【一粒の種】への一矢」（カルマの10問に連続正解、書 [ ブリーダー ]）。「【朝露の芽】への一矢」（夜にナイトメア ウィスプからナイトメア クォーツ、書 [ 爆弾男 ]）。「【新緑の木】への一矢」（タルタロッサ・パレスの朝霧の露、05:00-12:00）。 →
  • フォレールのシップ装備クエスト：相手は夜のアルビーズ北西のキャンプの山賊（カザとエンテは常にアクティブ）。「鬼舞の、弓」（森の恵み6個）。「えせ笑う、物まね」（物まねでぴーちゃんを呼ぶ）。「悪(わろ)ぶ、調教」（ガルム鹿をレベル20より上に育てる）。「迷乱の、自然調和」（センス ヒドゥンで盗品4つを見つける）。「毒唄う、罠」（スライムの毒10個、罠の攻撃のみ）。「フォレスターへの一矢」（山賊の長ナトゥーラ）。「爆弾男への一歩」（透明のドルドレイ。罠、投げ、アタックのみ）。 →
  • NPCギルド：戦士ギルド 武閃（ギルドマスター オグマ、ビスク西。刀剣 / キック / 盾 / 戦闘技術）。芸人ギルド アーテリック（ギルドマスター アドニー、ネオク。音楽 / ダンス / パフォーマンス / 水泳）。闇教徒ギルド 暗使 / マブ教（ギルドマスター エクア、ムトゥーム地下墓地。牙 / 死の魔法 / 召喚魔法 / 暗黒命令。入会には習得済みの技が必要）。錬金術師ギルド アルケィナ（ギルドマスター代理 フレッサ、ビスク大聖堂。4種の魔法。入会にはマイナー バーストが必要）。フォレスターギルド フォレール（ギルドマスター ガスト、ランダル洞窟。弓 / 自然調和 / 物まね / 調教）。ギルドは9つと「無所属」があり、この5ギルドは4つのスキルを0.25ずつの重みで数える。ランクは5段階。武閃は無刀 / 木刀 / 鉄刀 / 豪刀 / 一閃刀。アーテリックは練習生 / フレッシュアイドル / スイートアイドル / ハートキャッチャー / シャイニング・スター。暗使は夕闇 / 白夜 / 月夜 / 闇夜 / 漆黒の使者。アルケィナは入門者 / 祈りし者 / 祝されし者 / 選ばれし者 / 超えし者。フォレールは一粒の種 / 朝露の芽 / 新緑の木 / 春風の林 / 古代の森。 →
