項目クエスト/所持枠増加

ルール（24 件）

  • カリスマ ポイント（CP）：一部のクエストで、クエストごとに 1 回だけ上がる値。最大 42（4+1+3+3+3+3+3+3+4+5+3+2+3+2）。同じクエストを繰り返しても増えない。CP が一定以上あることが条件のクエストもある（QoA、邪竜討伐 27、ミーリム近海 28）。上がると「（キャラクター名）はカリスマ度が上昇した」と表示される。ミッションポイントの画面に CHARISMA として表示される。 →
  • 所持枠と銀行枠の拡張：所持枠 12 + 16 = 28。PresentAge の銀行 12 + 51 = 63（課金ボックス込みで 93）。WarAge の銀行 12 + 3 = 15 で、PresentAge の銀行とは別。拡張はほとんど一度きり（一部のクエストは報酬を変えて繰り返せる）。銀行クエストはほとんどが NPC をダブルクリックして始まる。それぞれに必要なもののメモ表がある。所持枠の追加は 32 枠が上限、銀行は 128 枠まで。拡張できる場所は 88 か所：所持枠はエモネット +2 / +3 / +5、青の廟堂の3マップそれぞれの 5 層と 10 層で +1、マジック バッグ +1 ×6。銀行はこのページのクエストとデポジット ボックス +1 ×30。メモリーズ ボックスの一覧で、各入手元と増える枠数がわかる。 →
  • 青の廟堂：回帰の間（5 層ごと、6 か所）に着くたびに所持枠 +1（またはマジック バッグのアイテムで +1）。3つのマップそれぞれの 5 層と 10 層で、合わせて 6 枠。マジック バッグでも +1 が6回。所持枠の追加は 32 枠が上限。 →
  • エモネットの２つ星 / ３つ星 / ５つ星の依頼（所持枠）：［２つ星］チップ2枚をアンジェに渡し、トレード不可の竜神の涙をもらってエモネットに渡す。所持枠 +2、CP 3。［３つ星］ワンダー クロース。所持枠 +3、CP 3。［５つ星］アイリーンズ ベル。所持枠 +5、CP 3。 →
  • ジャネットの銀行拡張1-7：価格は 1,000 / 2,000 / 4,000 / 8,000 / 16,000 / 32,000 / 64,000 Gold で、合計127,000 Gold。銀行枠は順に +1、+1、+1、+2、+2、+3、+3。順番どおりにしか受けられない。 →
  • キャットの銀行拡張1 / 2：ティアーズ ドロップ、次にビサイド ユア ハートを渡す。それぞれ銀行枠 +2、CP +3。 →
  • バイソンの２つ星 / ３つ星 / ４つ星の願い（銀行）：生産品のセットを渡す。チップ9枚をマーレ伯爵に渡すと竜神の護符。チップ15枚をジョアン（夜間キャンプ 21:00-06:00）に渡すと名も無き骨10個。報酬は銀行枠 +2 / +3 / +4、CP 3 / 4 / 5。 →
  • ガータンの銀行拡張（ネオク山）：ナジャの爪を渡す。銀行枠 +4、CP +3。 →
  • イルムの銀行拡張：まずクエスト「時の歪みより迫る影」を受ける。ユグの加護と５つ星の依頼が必要。イーゴ マインドを倒すと、報酬はキノコの化石。化石をイルムに渡すと銀行枠 +3。イクシオンの友好度がほぼMAX必要。 →
  • 旅商の安全確保：レヴはスキル合計850でのみ反応する。サベージ キングを倒す（30 m以内の全員が進行）。報酬は銀行枠 +1。 →
  • 王国復興 極秘任務：ブラドに話すにはエルガディン軍の友好度が必要。武器 / 資材 / 飲食のセットをジャスティンに届ける。報酬は銀行枠 +1。 →
  • 悪しき贅沢と正義の盗み：ファントム（21:00-05:00）が、寂れた鉱山からインセーン スティールで貴族の隠し金庫を盗んでくるよう頼む。盗品はテレポート、死亡、ログアウトで消えるので、正規品にする必要がある。初回の報酬は銀行枠 +1。繰り返すとランダムな秘伝の書 / 宝石、または500 Gold。消えるアイテムには3つの種類がある。マップのエリアが変わると消えるもの、ログアウト後に次にワールドに入ったとき消えるもの、死亡して戻るときに消えるもの。 →
  • 邪竜討伐：ユノの依頼にはCP 27（「カリスマポイントが 27 以上必要」）とエルガディンの友好度が必要。サウザンド ドラゴンを倒す。報酬は銀行枠 +2と鱗。2つ目の段階の後に死亡してホームに戻ると、1つ目の段階に戻る。 →
  • エルアン宮殿の銀行拡張：賢王の証をラジスに渡す。銀行枠 +2、CP +2。 →
  • 侵略者の調査依頼：イーノス（ヌブール）の依頼。ナボに話を聞き、コロニー付近のキラーアント ガードを全滅させ、女王を倒して報告する。女王の討伐はパーティーで進行する。報酬は銀行枠 +3、CP +3。 →
  • ミーリム近海の銀行クエスト（船上のフルマン）：入場にはCP 28または水泳100が必要。ヒトガタか大魔王ダコを倒すか、謎のロブスターを捕まえる。ルートしたパーティーは肉 / 足を自動で得る。それぞれ銀行枠 +2。 →
  • ライオン討伐：フラビエの依頼。キ・カ ライオンを10体倒す（パーティーの討伐も数える）。報酬は銀行枠 +2。繰り返すと肉球。 →
  • WarAge「時の歪みに取り込まれし者」：勢力のNPC（アクセル / ミクル / フライハイト）の依頼。夜にイクシオン シャドウを倒す（約30 m以内なら誰でも進行）。精神の欠片を渡す。欠片は2-4個落ち、死亡すると優先してドロップする。報酬はWarAgeの銀行枠 +3。 →
  • ナチルの宝：地図、スカルレッドとトレジャーガーディアン、未鑑定品、ナイトメアの尾 + Bランク地図と続く。ナイトメアの尾をガベイ（WarAgeのヌブール）に渡すとWar銀行枠 +3。 →
  • 親子の絆：リンの手紙をジョディに届け、レター フローム ホームタウンを持ち帰る。報酬はCP +4と称号 ミス ラメント。 →
  • 水と眠る、古の指輪：ウィンド / バロン / クレアの間でエルアンの指輪と手紙を受け渡す。報酬はCP +1とハーブ。 →
  • 深海探索（12段階）：沈没船、結界石のかけら α / β / γ、完成した結界石、アストレア、ハーデス、宝物庫の宝箱と進む。宝箱の中身は、アストレアを飛ばすとランダム、そうでなければアダマンタイト。2周目以降は謎の魔石。160607パッチで沈没船の入場条件が変わった。報酬はCP +2、アダマンタイト x5。 →
  • 沈没船の鍵はアイテムではなく、キャラクターの進み具合として記録される。ドアに触れると全員に対して約 10 秒開く。鍵はルート順に 8 つ。スケルトンの再出現 3 分でプレイヤーが閉じ込められることがある。ベッドに約 1 分座ると絵がもらえる。 →
  • メモリーズ ボックス：ビスク中央の石板の横にある。ビスク中央の石板の横の箱をダブルクリックすると、完了・未完了の枠クエストとCPクエストがシステムウィンドウに一覧表示される。所持枠は16、銀行は51（デポジット ボックス n / 30 を含む）、カリスマは42。表示例は「キャット 銀行拡張1 ( ティアーズ ドロップ ) : + 2」「デポジット ボックス : + n / 30」。入手元ごとに増える数が出る。 →
