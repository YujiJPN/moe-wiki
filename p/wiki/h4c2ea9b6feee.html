ルール（35 件）

  • スキル制：レベルもクラスもない。スキルは行動で上がる。LOCK / UP / DOWN はいつでも変えられる。スキル画面のポップアップか、/setskillctrl <skill> up / down / lock で切り替える。上限に届いてもメッセージは出ない。スキルごとの上限は 100、合計は 850。合計を超えると、DOWN にしたスキルからランダムに下がる。 →
  • テクニックリストの並び順：/savetechlist <ファイル名> で保存、/loadtechlist <ファイル名> で読み込み、/techlistreset で元に戻す。テクニックウィンドウのポップアップからも操作できる。 →
  • ペットのコマンド：/petattack（飼い主を指定できる。160705）、/petauto、/petaway、/petcome、/petcorpse（死体を引き寄せる。20 m）、/petnoauto、/petsit、/petstop、/pettarget、/petchangename <no. or target> <name>（160112）、/petdisband、/petnum、/petdisbandall（青ネームも含めて全部。220322）、/summonpetdisbandall（飼うペット以外の全部。220329）。ペットのマクロ（ケイジからの解放、一時停止、/petattack）も使える。 →
  • レコード ストーン：バインダーには入れられない。/setlocmemo <文字> で、カーソルで掴んだストーンにメモ（半角10文字まで）を書ける。何も掴んでいないと「カーソルに何もありません」と出る。テレポートの行き先はホームポイントまたはこのストーン。 →
  • 装備マクロ：アイテム名に「*」が使える。複数当てはまるときはインベントリで一番前のものが優先される。製作者名付きのマスターグレード品は末尾に「*」を付ける。装備できないものに当てはまると失敗する。左手は /equipitem [武器] left（tgl とも併用できる）。書式は /equipitem <名前またはスロット> <tgl>。アイテムをドラッグすると /equipitem [名前] tgl が作られる。旧方式は /swapitembox と /swapequip。 →
  • おしゃれ装備：性能用の装備とは別に、見た目用の装備を専用タブで設定できる。のちに武器にも広がった。/fashion on / off で切り替える（一部のゾーンでは使えない）。表示を切り替えるオプションもある。 →
  • /split は停止中（2007-11-20）。パーティのお金は自動分配オプションで分けられる（拾った人が端数を取る）。 →
  • /tutorialcut：新キャラクターのチュートリアルを終え、ビスクのアルターへ移る。使えるのはミーリム海岸 ダイアロス島、隠れ里 ネヤ、幻影世界だけ。チュートリアルアイテムを持っているとキャンセルされる。技を覚え、クロース シャツ、クロース パンツ、ブランク ノアピースを受け取り、ビスク中央へワープする。お金は初期の700 Goldだけ。 →
  • 暦と /gametime：曜日は 7 つ（天の日、冥の日、地の日、水の日、火の日、風の日、沌の日）。1 年 365 日、1 か月 32 日。Present Age の年は 13050-13059 の繰り返し。War Age は 10 年後。Future は 3000 年後。Chaos は 45 億年前。表示は「Diaros:Year of Moras 130XX Day YYY Time ZZ:ZZ」と、パソコンの時計による実時間、「World」のカウンター。 →
  • AncientAgeへの行き方とノアピースの記憶：箱舟遺跡から行く。プレイヤーは土地を借り、NPCベンダーが代わりに販売する。後でアルターで移動できるように、2つの時の記憶をブランク ノアピースに記録しておく。/noahpiece で時代ごとに記録された記憶を表示する。ブランク ノアピースはチュートリアルの出口で渡される。 →
  • /warnorma：現在のウォーノルマのポイントと必要なポイントを表示する（Commander以上）。ノルマはCommander 1、Captain 3、Warlord 5ポイント。期間は82,944秒（23.04時間）で、ゲーム内の表記は24時間。残り2時間 / 1時間 / 10分 / 5分の表記で警告が出る（実際は6,912 / 3,456 / 576 / 288秒）。期限までに満たないと、その階級のポイントを失う。 →
  • ブレンド名と称号の表示：/window shipnameblend でシップブレンド名の編集画面を開く（120321）。オプションで、自分の称号またはブレンド名を名前の上に表示できる。もう一つのオプションで、他人にも見せられる。称号の表示は2023年にそのオプションとともに追加された。 →
  • チャットチャンネル：種類ごとに定員がある（募集は50など）。フェローシップチャットには自動で参加し、その参加・退出のメッセージは出ない。メンバー0人と表示されるチャンネルにはGMがいる。/chlist [A,C,I,R] <名前の一部> で一覧を見る。/achleave、/ichleave、/rchleave で退出する。/ish でゾーン内の自勢力に話す。オークションチャットは質問にも使われる。チャンネルは3つまで（1〜3）、カテゴリはA、C、I、F、R。ChatRoomには制限人数がある。チャンネル名は1〜31文字。勢力チャットはWar Ageのみ。チャンネルには名前とパスワードを付けられる。 →
  • チャットの届く範囲：エモート約15 m、say約25 m、yell約30 m、shoutはさらに広い。/yell で周囲約30 mに助けを求めて叫ぶ。次に使えるまで5秒。/yell はクリーチャーにも物音として聞こえる。 →
  • /dice：0〜1000、または指定した範囲でダイスを振る。/dice 最大値（1〜1000）か /dice 最小値 最大値（0〜1000）で使う。範囲の上限は1000。 →
  • フェローシップのコマンド：/fscreate、/fssetting（サブマスターの任命、譲渡。マスターのみ）、/fsinfo、/fsboard。作成費用は10,000ゴールドで、銀行から支払う。War Ageでは作成できない。霊体でも作成できない。 →
  • パーティのコマンド：/disband（保留中の勧誘を断るのにも使う）、/lfp「パーティ募集中」（AFKとは同時にできない）、/changeleader。パーティは5人まで。勧誘できるのはリーダーだけで、同じ勢力に限る。追放者は勧誘できない。勧誘は57.6秒で無効になる。お金の自動分配がある。 →
  • /afk on：AFKの表示を出すだけ。Tellへの自動返信はない。 →
  • 土地とベンダーのコマンド：/vendorlist <item> でプレイヤーのベンダーを検索する（Ancient Ageのゾーンのみ、最大50件）。/disparea enter / ownership で土地を色分けして表示する（許可は緑、禁止は赤、自分の土地は黄）。/townlist でAncient Ageの土地名を検索する。 →
  • /pickingstop：ロックピック（盗み）のルーレットを失敗として終わらせる。ロックピックには許容ミス数、カーソル速度、ピン、警告がある。スローにできる時間は 60 + 1.2 × 盗み フレーム。盗みのスキルが上がる。 →
  • オプションのコマンド：コマンドでしか変えられない設定がある。タイトル画面のOPTIONには独自の設定がある。35のコマンドがオプションダイアログと対応する。/density 0.25〜1.0、/namebblimith 16〜64、/effect OFF / MIN / NORMAL / MAX、/bgm、/se、/fashion はチェックボックスと連動する。設定はPCごと（game.ini）とキャラクターごと（usergame.ini）に保存される。 →
  • 操作モード：マウス、FPS（既定）、RPGの3つ。FPSはAltなしで動く。キー設定では、1つの動作に3つまでキーを割り当てられる（Escで消去、DEFで元に戻す、1つのキーに複数の動作も可）。既定のキー設定には約120の動作がある（移動、平行移動、視点、ジャンプ、座る、歩き / 走り、自動前進、自動戦闘、メッセージウィンドウ、パーティのターゲット、ショートカットのページ）。設定できる動作は全部で184。 →
  • メッセージウィンドウ：システム、会話、戦闘、Auction、Channel、Message5〜6、勢力、検索、演奏結果1〜2の11個。名前の変更、タブ、種類ごとに振り分けるメッセージフィルター、速度を設定できる。/msgclear all / 0-8 で、全部か1つのウィンドウを消す。 →
  • ショートカットバー：ShortcutとShortcut2の2つで、それぞれ10スロット × 10ページ。「Switch Shortcut」で向きを切り替える。Ctrl+Alt+Spaceでウィンドウをロックする。オプション「ShortcutとMenuの同期」は削除された（2011年8月9日）。 →
  • /viewport：3Dビューのサイズを表示または設定する（最小64 × 64、最大は画面の大きさ）。右と下は黒い余白になり、縦の視野角は変わらない。/viewport reset で元に戻す。サイズは解像度ごとに保存される。 →
  • ターゲットの書き方：/tar（/target）と、/cmd [..]、/useitem [..] のターゲット指定には、% の代入（%1〜%5 パーティ、%lt、%r）と <..> の指定（<player>、<enemy>、<pet>、<near ...>）が使える。%lt の名前は同じ名前のNPCに当たることがあり、<lt> が本当の最後のターゲット。buffのマクロでは他人のペットを名指しできず、PvPの味方と敵を区別できず、War Ageでは制限がある。例：/target <near enemy(pet)> name。ほかに /targetpc、/targetnpc、/targetcps、/targetnear（いちばん近いものを探す）がある。 →
  • マクロの保存と読み込み：マクロを名前を付けて保存・読み込みでき、使えるマクロのページが倍になる。コマンドは /savemacro、/loadmacro、/savecolor、/loadcolor。/forgetmacro でカーソル上のマクロを消す。マクロは100個まで、1つにつき6行。ショートカットは62個。 →
  • キャラクターを隠す：/dispotherchara 0-6 で表示を切り替える（0 全表示、1 他のPCを隠す、2 NPC、3 PC + NPC、4 ペット、5 他人のペット、6 PC + ペット）。/dispmyplayer で自分の画面から自分のキャラクターを隠す。 →
  • エモート：/sleep（120221）、/letsdance（ダンス 80 が必要、110726）。/emote または /em <text> で、名前を頭に付けた文を出す。エモートの後に " motion" を付けると、アニメーションだけを再生する。エモートは83種類あり、そのうち51種類にスラッシュコマンドがある。 →
  • 名前の表示：/dispcharaname で名前の代わりにシップ名を表示する。ほかに /disptargetbbname、/disptargetwindowname がある。Shift+F11 でNPCを含むすべての名前を隠す。オプションで他人の名前を隠したり、シップ名・ブレンド名を表示したりできる。 →
  • /sfxmode：マップの背景を1色に置き換える。QoA のイプス峡谷でのみ使える。使っている間は時刻が 12:00 に固定される。 →
  • コマンドのヘルプ：/codelist でコマンドを一覧表示する。頭文字で検索できる。/? <command>（/help と同じ）でそのコマンドの引数を表示する。コマンドの分類は NORMAL / EMOTE / WINDOW / SKILL。 →
  • /window：ウィンドウ名を一覧表示するか、指定したウィンドウを切り替える（/window <name> <on / off>）。/window durable（110111）で装備の耐久度ウィンドウを開く。耐久度は装備部位ごとに表示される。 →
  • /killmyself：28.8秒後に強制的に死亡する。カウントダウン中は4.8秒ごとにメッセージが出る。チュートリアルのエリアでは使えない。霊体は体を残してホームポイントへ行く（「迷った」ときの助言：Alt+M でマップ）。 →
  • ホームポイント：/homepoint で確認、/returnhome で戻る（死亡中のみ）。帰還すると呼吸、満腹度、潤喉度が100になり、スキルの損失を受け、疲労 0.1 が加わる。 →
