ルール（9 件）

  • 魔法の系統ごとの上げ方：どのスキル帯でどの魔法を唱えるかの段階がある。範囲魔法は、巻き込んだ相手ごとに判定が 1 回ある。魔法の難度は必要値 + 8。テクニックで上がるのは必要値 + 20 まで。 →
  • 回復の上昇：HP 満タンの相手ではよく上がらない。通常の回復テクニックは、相手の HP が減っていれば 1.0、満タンなら 0.5。包帯は HP が 1 でも減っていると上昇が倍。80 台後半では、セイクリッド サークルがヒーリング オールより早く上がる。魂のない死体へのリザレクションの射程は一定しない。 →
  • 系統ごとの複合魔法（破壊 約60、死 約50、回復 約45、神秘 約95、召喚 約70、強化 約90件）。条件の種類は、最低スキル、最大スキル（「10以下」など）、点灯中のバフ、シップ（称号）のマスタリー。必要スキルは最大8つ。バフ / マスタリーの条件には、すべての点灯が必要なものと、いずれか1つでよいものがある。 →
  • スキルと魔力ごとの効果量・効果時間（死の魔法のデバフ：スキル60-100・魔力0-200、回復：セルフ ヒーリング … セイクリッド サークル、エンチャントの効果時間、召喚の支援魔法、強化のバフ：スキル20 / 50-100・魔力30-150）は、どれも同じ形で決まる。スキル − 必要スキル に応じて伸び（伸び方と上限は魔法ごとに違う）、(魔力 + 300) ÷ 350 倍になる。ばらつきは ±10 %。 →
  • 基本魔法のコストはスキル段階ごとに決まっている。スキル1：MP 5、触媒 ND1、詠唱 115、ディレイ 180 … スキル90：MP 53、触媒 PNQ1、詠唱 277、ディレイ 378。強化魔法は詠唱とディレイが +20。ただし強化魔法スキル70は 241 / 334 で、この規則から外れる。詠唱とディレイの単位は16ミリ秒（詠唱 115 = 1.84秒、277 = 4.43秒）。 →
  • 魔法の成功率：必要スキルちょうどで80 %、1下回るごとに -10 %、1上回るごとに +2.5 %（+8で100 %）。最低は1 %。複合魔法の成功率はスキルごとの成功率の平均で、各スキルの分は100 %が上限。そのため、いずれかのスキルが低いと失敗しやすい。移動しても下がらない。目安は100 %になるスキル（回復魔法 68 / 88 など）。複合召喚は、必要スキルちょうどで80 %、両方を8上回ると100 %。 →
  • 詠唱妨害：攻撃を受けると詠唱が中断されることがある（集中力0で99 %）。継続する確率（%）= 集中力 × 0.6 + 詠唱妨害耐性バフの値で、集中力100とホールドで96 %。詠唱妨害耐性バフは最新の1つだけが有効。集中力は詠唱と移動しながらの詠唱も速める。判定のたびに集中力の上昇判定がある。 →
  • 回復には2種類ある。直接回復は ヘル パニッシュ を破る（グループ ヒーリング、ソールライト、フォース オブ ネイチャー の継続回復）。「1フレームバフ」型の回復（オーロラ ヒール、トワイライト・セイント・アフェクション）は、ヘル パニッシュ 中は防がれ、死亡したプレイヤーにも届き、先にかかったものが優先される。HPが変化すると終わる効果は、回復を受けても終わる。 →
  • 魔法のショップ：スキル 1-50 の魔法はビスク中央、ネオク高原、ムトゥーム地下墓地の魔法屋が売る。スキル 60 は夜間キャンプ／エルビン渓谷。系統のギルド（アルケィナ、暗使）。強化魔法はトレードできない。 →
