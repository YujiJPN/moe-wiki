スキル一覧・スキル上げガイド

ルール（26 件）

  • 熟練スキルとステータス：熟練スキルはステータスを変えない。ただし武器スキルは命中に影響する。ステータスに関わるスキルは筋力、生命力、持久力、知能、精神力、攻撃回避、着こなし、呪文抵抗力だけ。命中 = 武器スキル × 種族の倍率 × (0.8 + 0.2 × 必要スキル補正) + 命中への加算。 →
  • 熟練スキル：どれもテクニックや魔法を持つ。スキルを上げると成功率が上がり、多くは効果時間も長くなる。成功率 = 0.8 + 必要値を超える 1 ポイントごとに 0.025、足りない 1 ポイントごとに −0.1。必要スキルが複数あれば平均する。下限は 1 %。効果時間は 傾き × (スキル − 必要値) + 1 で伸びる。 →
  • 熟練スキルの一覧：素手、刀剣、こんぼう、槍、銃器、弓、盾、投げ、牙、罠、キック、戦闘技術、酩酊、物まね、調教、魔法の各系統、魔法熟練、自然調和、暗黒命令、取引、パフォーマンス、ダンス、音楽、盗み、シャウトの 30 種。武器も扱うスキルと、テクニックのためだけにあるスキルの 2 種類がある。 →
  • テクニック専用スキル：酩酊、物まね、パフォーマンス、ダンス、盗み。自分のテクニックの効果を上げる。盗みは上位のテクニックも解放する。高ランクのテクニックを使うと上がる。効果は最初の必要スキルで決まる。上昇の難度は、魔法と一部のテクニックでは必要値 + 8、それ以外は相手のステータス。テクニックで上がるのは、そのテクニックの必要値 + 20 まで。 →
  • 音楽：音楽テクニックの効果、QoA の音楽テクニックの命中、QoA の音楽魔法の効果を上げる。高ランクの音楽テクニック、防御の高い敵への攻撃、耐性の高い敵への詠唱で上がる。楽器演奏でも上がる（10 音以上弾いたあと、楽譜の難度による）。QoA のテクニックは、相手のステータスに対して通常どおり上昇判定がある。 →
  • シャウト：シャウトの効果を上げ、音楽テクニックの射程を伸ばす。無属性耐性の高い敵に高ランクのシャウトを使うと上がる。上昇は相手の無属性耐性で決まる。 →
  • ギャンブル：未実装のスキル。上限だけは悟りの石、賢者の石で上げられる。効果も上昇条件もない。 →
  • 補助・その他のテクニックスキル：戦闘技術（攻撃、命中）、暗黒命令（残酷なテクニック、攻撃で回復）、自然調和（危険な場所、調教）、物まね（隠れる、分身）、魔法熟練（マナ）、ダンス、調教（動物、人型、ドラゴンのペット）、取引（バンカー コール）、パフォーマンス（ネタスキル）、音楽（パーティーやペットへの Buff）。パフォーマンスはほかの熟練スキルより上がりやすく、0.0047 刻みでいちばん上がりやすい部類。取引は 0.0027 刻み。 →
  • 素手：素手攻撃の命中とクリティカル率を上げる。クリティカルと攻撃速度が高く、序盤は弱い。防御の高い敵に攻撃を当てると上がる。武器なしのクリティカル率は 素手 × 0.2 %（最低 3 %、最大 20 %）。素手のダメージ = 0.2 × 素手 + 0.001 × 素手²。 →
  • 武器スキル：刀剣、こんぼう、槍、銃器、弓、投げは、それぞれの武器の命中を上げる。刀剣は伐採 / 収穫の切る動作の命中も、こんぼうは採掘 / 掘る動作の命中も上げる。道具を使うときの命中の基礎は 武器スキル / 4。どれも防御の高い敵に当てると上がる。武器の系統は、刀剣が剣、斧、鎌。こんぼうが鈍器と杖で、大振り。槍が槍とレイピアで、速さと間合い。命中 = 武器スキル × 種族の倍率 × (0.8 + 0.2 × 必要スキル補正) + 命中への加算。 →
  • 盾スキル：装備しただけでは受け流さず、盾テクニックだけがガードする。装備すると防御力が上がる。盾スキルは基本の Avoid を上げ、盾テクニックのディレイを短くする（ディレイ × (1 − min(0.4, 0.004 × スキル))）。攻撃力の高い敵の攻撃をブロックするか、完全に回避すると上がる。盾の Avoid = 必要スキル補正 × 盾の回避値。軽減量 = 0.5 × 必要スキル補正 × 盾の power + 0.3 × 盾スキル。 →
  • 牙：牙テクニックの効果を上げる。噛みつき、変身、吸血系、相手の妨害などのテクニックがある。高ランクの牙テクニックと、防御の高い敵への命中で上がる。牙テクニックには牙の命中と攻撃力が加わる。上昇の係数は 1.7。 →
  • 罠：罠のダメージと設置速度を上げる。妨害やダメージを与える種を植える。種の効果は、その範囲内なら必ず当たる。対応する種のアイテム（触媒）が必要。高ランクの罠の設置 / 発動で上がる。罠を壊すテクニックや、罠を発動させない効果もある。 →
  • キック：ディレイの短いテクニックが多く、多くはサブスキルとして使う。キックの命中と威力は、キックスキルだけで決まる。キックを上げると、素手の通常攻撃とテクニックのディレイが短くなる（0.002 × キック、最大 0.2）。 →
  • 戦闘技術：戦闘技術のテクニックの効果と、シールド ガード成功時の ST 回復量を上げる。高ランクのテクニックで上がる。ガードなどの動作中は、攻撃を受けるたびに ST が 戦闘技術 / 10 回復する（最大 ST まで。ミスや DoT も数える）。 →
  • 遠隔攻撃の弾薬：弓、銃、投げには弾薬（矢、弾、投げ武器。肉団子 / ナイフ）が必要。弾薬がないと攻撃できない。テクニックに合った種類が必要。必要スキルに足りない弾薬は、武器と同じく攻撃力と命中を下げる。弾薬のダメージ × 必要スキル補正が武器の攻撃力に加わる。弾薬は攻撃のたびに消費される。 →
  • 遠隔武器での近距離：遠隔武器（弓、銃、投げ）では、相手との距離（双方の体の半径を除く）が 5.0 m 未満だと、アタックが素手の殴打に変わる。銃も同じ。銃の通常攻撃は、クリティカルのとき以外は移動を止める。 →
  • 照準：弓 + 矢、銃 + 弾、投げ武器を装備すると黄色い照準が出て、射撃はそこへまっすぐ飛ぶ。大きく外れるか障害物があると「ミス ザ マーク」になる（回避によるミスとは別）。低い相手（ヘビ、クモ、スライム。特にパンデモスにとって）は当てにくい。フュージョン中は射撃が当たらない。透明なプレイヤーには必ずミス ザ マークになる。ミス ザ マークではダメージが入らず、攻撃テクニックならモンスターにヘイトが 1.0 加わる。照準のサイズと色はオプションで変えられる。 →
  • 酩酊テクニック：どれも酩酊度 0.1 以上が必要。酔っていないと「酔っ払っていません」と表示されて使えない。一部は酩酊度 3〜12 が必要で、使うとその分だけ酩酊度が下がる（センスレスは強すぎたため、パッチで消費が追加された）。酩酊度は酒を飲むと上がる。 →
  • テクニック（技）：ST を消費して、攻撃、回復、状態変化を与える。魔法と違って基本的に詠唱時間はない（例外は音楽テクニック、キヨミズ パッション）。基本的に触媒も要らない。アイテムが必要なものもあり、消費するものとしないものがある。それぞれ固有のディレイを持つ。 →
  • 魔法の系統スキル（破壊魔法、回復魔法、強化魔法、神秘魔法、死の魔法）：魔法の効果を上げる。高ランクの魔法を使うと上がる。破壊魔法は高耐性の敵への詠唱でも、回復魔法は大きな回復と蘇生でも、死の魔法は死の魔法で敵を倒すことでも上がる。上がりやすさは 必要スキル + 8 を基準に決まる。HPの低い相手への魔法は、そうでない相手への魔法の2倍上がりやすい。 →
  • 魔法熟練：魔法使用効率、MPの自然回復量、レジスト貫通力が上がる。より過酷な状態で魔法熟練技を成功させると上がる。MPの自然回復は、毎秒62.5回、魔法熟練 × 0.2 ÷ 6000 ずつ増える（魔法熟練100で毎秒 +0.21）。 →
  • 召喚魔法：効果を上げ、同時に出せる召喚ペットの数を増やす。一部の召喚体は、スキルが高いと強くなったり種類が変わったりする。召喚体のレベル = スキル + 召喚ごとの値（1〜150）。レベルが固定の召喚体もある。リコール インセクト、リコール モノアイ ロボ はスキル40 / 70で種類が変わり、リコール エレメンタル は一番高い属性抵抗で種類が決まる。同時に出せるペットと召喚体は 1 + trunc(スキル ÷ 30) まで、最大3。合計レベル + 新しい召喚のレベル は 2 × スキル まで。操作できるモンスターは10体まで。捕獲したペットも数える。 →
  • ペットのスキル：調教は、より高位のNPCをペットにでき、高レベルのものを捕獲すると上がる。自然調和は動物の捕獲成功率を上げる。暗黒命令は、ペットが消えるまでの時間を延ばす（死霊系の召喚体の時間 × (1 + 0.008 × スキル)）。捕獲には 1.2 × 調教 − ペットの合計レベル − モンスターのレベル ≧ 0 が必要。2体目は調教30、3体目は調教60が必要。確率 = (0.7 × C + 0.3 × B) × f。C はモンスターのレベルが高いほど小さく、自然調和 × 0.1 が加わる。B はモンスターの勢力との友好度、f は減ったHPで決まる（HP満タンなら0）。自分のペットに有益な技（チェリッシング、チアー ショット、ドミニオン …）を使うと調教が上がる。 →
  • 取引：上位の取引テクニックが使えるようになる（高いランクでバンカー コール）。ペットとのトレードが成立すると上がる（基本の上がり方 0.0027）。NPC の店やほかのプレイヤーとのトレードでは上がらない（Wiki：トレードの成功で上がる）。バンカー コールは召喚で、呼んだ銀行員は銀行を開いたあと消える。 →
  • 狙いのコツ：細かく狙うなら固定カメラモード1 / 2 / 3（一人称）を使う。手動カメラはおすすめしない。初心者はロックターゲットを使うとよい。ただし速い敵にはロックターゲットの射撃が外れる。カメラモードはオプションのキー設定で、ロックは /locktarget と /autolock で切り替える。 →
