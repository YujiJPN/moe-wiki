入会を受け付ける NPC: シレーナ（ビスク港）

ルール（8 件）

  • 比較用の料理系イヤリング：アップル イヤリング（最大HP +5、料理のゲージ速度 −10）、メロン イヤリング（ヒットゾーン +2）、チェリー イヤリング（最大MP +5、グレードゾーン +1）、装飾細工品。マジック オブ セイバー（ゲージ −3）。 →
  • 隠し要素「デックの日記」：釣り上げる文書（モラ暦 13049）で、デックがビスク港でシレーナと出会った経緯を語る。 →
  • ランクアップで料理ギルドのショップ NPC カマロンの品が増える：★★★調理人でレシピノート 2 種、★★★★料理長で品物 14 種。 →
  • シェル・レランの通常ギルドクエスト ★ から ★★★★：「蛇肉を、カリッと」（30 GP）…「酸味で、すっきり」（550 GP）。報酬はgold、アイテム、レシピノート。刺身5個単位で繰り返し受けられる。★★★のスー・メリアのクエストではマジック オブ セイバー、秘伝の書、取引 +0.5（上限20）がもらえる。 →
  • シェル・レランのランクアップクエスト：「【皿洗い】へのオーダー」（グロボの10問のクイズ）、「【見習い】へのオーダー」（魚介マリネ）、「【調理人】へのオーダー」（魚の塩釜焼き）。報酬は究極奥儀の書、レシピノート、料理 +0.5（上限まで）、200-300 GP。ギルドクエストのウィンドウはギルドの町でだけ開く。 →
  • シェル・レランのシップ装備クエスト：「[料理]のお味はグッド・テイスト？」（料理30、黒ごま アイスと再利用できるコーン フレーク -> 料理師 包丁）。「厨房師へのオーダー」（料理、醸造、呪文抵抗力40。マーレ伯爵にシーフード リゾット -> 厨房師装備）。 →
  • 料理人ギルド シェル・レラン：ギルドマスター シレーナ、ギルドガイド グロボ、本拠地 ビスク港。ランクは 皿洗い → 見習い → 調理人 → 料理長 → 海鮮王（5番目は未使用）。入会にはレシピバインダー、初心者用フライパン、料理(焼く)の技が必要。ギルドスコアは料理 x1、f = 0.6。 →
  • ギルドランクアップの式：ギルドスコア = f x GP + (1 - f) x 100 x（スキル x 重みの合計）。f は戦闘系 0.5、生産系 0.6。ランク r にはスコア (r / 4)² x 10000 = 625 / 2500 / 5625 / 10000 以上が必要。戦闘系では GP + 100 x 4スキルの平均 >= 1250 / 5000 / 11250 / 20000。生産系では GP + 66.7 x スキル >= 1041.7 / 4166.7 / 9375。グロム・スミスは GP + 33.3 x（採掘 + 鍛冶）。 →
