ルール（21 件）

  • ギルドごとのシップ装備クエスト：武閃は★★で剣士 サーベル、キッカー シューズ、ワイルドマン スカルヘルム、ガーズマン シールド、★★★でウォーリアーとブレイブナイトの装備。暗使 4 + 2。アルケィナ スペル ブック4 + 装備3。フォレール 5 + 2。グロム・スミス 2 + 1。テクスエンド 1 + 1。シェル・レラン 1 + 1。アーテリック 3 + 1。 →
  • ギルド以外のシップ装備クエスト：スキルを満たしていないと表示されないか、断られる。称号が条件のものもある（例：レクスール・ヒルズでは称号 デュエリスト）。一部のクエストのオブジェクトとNPCはクエスト中にだけターゲットできる。2015-08-25にクワ、フライパン、カナヅチ、フレッチングキットのクエストが追加された。 →
  • ウィンドのクエスト：「商いに生きる、旅人へ」（ジェフの取引サインボード -> ベンダー リュックサック）。「水と呼吸する、旅人へ」（水路の宝箱の女神の涙 -> スイマー フィン）。「投げを極めた、旅人へ」（投げでしか傷つかないスマッシャー ゴーレム -> 投げ士 グローブ）。 →
  • 「始まりの一盗」（ジュディス）：盗賊の木人からスティールで「ペンダント オブ シーフ」を盗む（通常攻撃は無効。ロックオングルー）-> スリ マスク。 →
  • ゴッドファーザーのクエスト：「狙撃する魂」は、21:00-05:00にオークの魂を銃器のみで倒す。ドワーフの友好が必要で、報酬はガンナー ピストル。「傭兵装備 取得作戦」は、銃器でドワーヴン マークを5つ破壊する。報酬は傭兵装備。 →
  • 「鎮魂の帯」（ソフィー）：ノア バンデージで夜の亡霊を倒す。報酬はヘルパー キャップ。 →
  • デックのクエスト：「釣り上げる、命」は、ダイアロス マーリン 77 cmを釣る（シレーナ コイン）。報酬は釣り人 ロッド。「熱くたぎる、海の誓い」は、槍の攻撃のみで海の悪魔を自分で倒す。報酬は海戦士装備。 →
  • フラビエのクエスト：「朽ち果てぬ、戦いの記憶」は、夜のゴーストランサーを槍で倒す。報酬はランサー レイピア。「闘う覚悟 己の力で成し遂げよ」は、ジャイアント デュエリストに合計300のダメージを与える。与えたダメージは死亡やログアウトでも消えない。報酬はデュエリスト装備。「竜を討つ力」は、ドラゴンスレイヤー スピアでベビー ドラゴンを3体倒す。報酬は「効果アップ：ドラゴン系」。 →
  • ゼノの生産道具のクエスト：岩茸5個を収穫 → 耕作師 カマ。ジャガイモ20個 → クワ。セードロの丸太3個 → 木こり アックス。ネオクビールを醸造 → バーテンダー シェイカー。トレント ナールド スタッフ → 木工師 のこぎり。染色液 → 調合師 混ぜ棒。スチール リング → 細工師 ペンチ。「イルヴァーナの風景画」の複製 → 筆記師 ペン。MGグレードのチキン ステーキ → 料理師 フライパン。木製の防具 → 木工師 カナヅチ。ウッドゥン ハンティング ボウ3張 → フレッチングキット。龍の彫刻 → 筆記師 彫刻刀。ほかに「創造主」の2クエストがある（クリエイター装備）。 →
  • 「己の野望、殴打に込めて」（アクセル）：こんぼうの攻撃のみでビスク新兵を倒す。報酬はメイサー マレット。 →
  • 「謎を読み解け」（インディアナ）：謎箱「week,N」を、その日のゲーム内曜日に対応するバッグのスロットに入れる（天〜混沌がスロット1〜7）。次に、対象をターゲットした状態で /say で発言する。報酬は解読者 ルーペ。なお、岩茸は再生が遅いため、収穫70未満ではゼノのカマのクエストが難しい。 →
  • ミストのクエスト：「洗練されし、魔法の知識」は、天井のラル・ファクの光にリトル ツイスターを当てる。報酬は魔術師 スペル ブック。「知識溢れる 祭司への試練」は、透明のスピリット ドレインをレスト イン ピースのみで倒す。報酬はドルイド装備。 →
  • 「想い出の酒に酔って」（ピエール）：ピエールのひょうたんを持ってヴァルグリンドの酒樽を調べ、「蛮族の酒」Buffを得る。Buffはテレポートで消える。報酬はドリンカー装備。 →
  • 「レクスール フォーリング ラリー」（カイザス）：7分間のBuff中に6つのチェックポイントの看板を回り、ドロップに話しかける。Buff中は落下ダメージが下がり、技が使えない。報酬はフォールマン ウイング。 →
  • 「死に寄り添い、闇を回収」（デリック）：霊体のまま闇の魂から闇の力を7個集める。霊体での死亡、ゾーン移動、ログアウトで最初からになる。報酬はデッドマン マスク。 →
  • 「剣の道を極める一歩」（テッシン）：テッシンのBuffを受け、案山子10体を刀剣のダメージのみで破壊する。案山子はそれぞれ50ダメージの爆発を起こす。報酬はサムライ装備。 →
  • 「荒くれし者よ イチバンを目指せ」（ハルク）：練習生キャンディとジェットに勝つ。報酬は荒くれ者装備。 →
  • クノッヘンの美容のクエスト：「美への追求」は、レントンにシャンプーをする。報酬は理髪師 ハサミ。「容姿の追求」は、顔見本 No.4でハルカを整形する。報酬は理髪師 メス。「色彩の探求」は、シルク ローブを染める。報酬は仕立て屋 染色棒。 →
  • イ オーフェンのクエスト：ニクス銀貨10枚でパンチャー ナックル、ニクス金貨10枚でアサシン装備がもらえる。銀貨と金貨は山賊と盗賊が落とす。 →
  • 「酒の力で敵を討て」（シャオティエン）：渡された酒「電撃」を飲み、素手とキックのみでイェンを倒す。報酬は酔拳士装備。 →
  • 「走れ、金メダルへの道」（カントク）：アスリートの条件を満たす場合のみ表示される（2024-05-14）。12分間のBuff中に18のチェックポイントを通過する。チェックポイントごとにスタミナが回復し、パッシブはオフになる。報酬はアスリート装備。 →
