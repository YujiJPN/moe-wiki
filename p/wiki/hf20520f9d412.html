項目アイテム/防具/精錬の泉

ルール（6 件）

  • 染色：色付きの名前のものは染色できる。染色版を精錬するとデフォルトの色に戻る。 →
  • 生産金属セットの精錬段階：「〜 オブ レゾナンス」、続いて +1〜+9（スケールは着こなし36、チェイン51、プレート71）。段階ごとのセットAC（スケール 45.3 → 53.6 など）、耐久 17 → 19 → 22。素材は鉄で、+3 から銀。1部位ごとの効果が増えていく（スケールは最大で命中 +2、耐水属性 +10、耐風属性 −12、最大重量 +6。チェインとプレートはペナルティと最大ＨＰ／ＭＰ／ＳＴ）。 →
  • 精錬盾：ウォー シールド オブ レゾナンス +0〜+9（HG 11.3 → 16.5、最大ＳＴ −3 → −30、4属性耐性 +3 → +20）、コダチ オブ レゾナンス（回避 64 % → 80 %、+8 から逆手持ち）、グラディエイター シールド +1〜+3（「呪文抵抗UP」＝全耐性 +5）、課金のダークナイト シールドとアニマの盾 +1〜+3。 →
  • 精錬課金セット：カーミラ／ブラムストーカー／スカウト／隠密 +1〜+9。月影周郎、臥龍武侯、シルヴァンガード、デザイン パイレーツ、ノア ユニット、魂振、アニマ、インペリアル ハウンド +3（セット効果の強化、モーションの変化）。スクール +3 は染色できる「カラー スクール」になる。シュヴェルツェ フューラー +2 / +3 もある。セット効果は全部位に同じ常時発動の効果が付いていて、1部位で効き、複数部位でも重複しない。これに各部位の補正の合計が加わる。 →
  • その他の精錬品：望月のヘッドドレス +1〜+9、ペネトレイティング シューズ +1〜+9、スネーク アーム +1〜+3、単品の精錬品（シールド アーム Type A ＋ Type B → Type C、天使の両翼）、アニマル レッグ 猫 → 虎 → 豹 → チーター（移動速度 +3 / +4 / +5）、ブリ社長に至る釣りの帽子（釣りゲージ速度 +25、釣りヒットゾーン +5、釣りゲージ長 +10、泳ぎ速度 +10）。 →
  • 精錬の泉：「精錬可能」なアイテムを泉に通すと次の形態になる。精錬防具の一覧（787 種、24 分類）。レフト トンファーは盾のトンファー ガードになる。天冠はランダムで2系統に分かれる。精錬の泉はウェブのミニゲームで、対象のアイテムは先にウェブのアイテムボックスへ移される。生産の「精錬」はインゴットの精錬で、泉とは別。精錬後の形態は普通のアイテム。 →
