  • 武閃の通常クエスト：蛇 / 蟲 / 狼（★、50-80 GP、刀剣 / キック / 戦闘技術 +0.5、上限10まで）、熊 / 獅子 / 翼（★★、10個ごとに獅子の肉）、獣 / 竜 / 「白・抱・望」（★★★、スー・メリアで究極奥儀の書 [ ブレイブナイト ]）、岩（★★★★、秘伝の書 [ シリアル シュート ]）。報酬はアイテム、お金、GP。クエスト名は「蛇・即・斬」…「白・抱・望」、「竜・即・斬」、「岩・即・斬」など。 →
  • 武閃のランクアップクエスト：「【無刀】への果たし状」はギルドガイド メイヴの10問のクイズに連続で正解する。「【木刀】への果たし状」はダーインの鉱夫からマイナーズ ワイフを持ってくる。「【鉄刀】への試練」は夜にラトロボスから母の形見を取り戻す。 →
  • 武閃のシップ装備クエスト（★★、スキル30、装備を持っていないこと）：刀剣の達人マーノ（剣士 サーベル）、キックの達人クルス（キッカー シューズ）、カプトの試しの岩（ワイルドマン スカルヘルム）、スクードの時間制の6回のガード（ガーズマン シールド）。「ウォーリアへの果たし状」は4スキル40、夜の古代の戦士フォルト / ドゥールス、空き枠7が必要。「ブレイブナイトへの果たし状」はドゥボルグが相手で、空き枠5。Mobはガルム回廊の入口とイルヴァーナにいる。不具合：複数のマスタリーがあると、シップクエストのMobへの攻撃が外れる。 →
  • NPCギルド：戦士ギルド 武閃（ギルドマスター オグマ、ビスク西。刀剣 / キック / 盾 / 戦闘技術）。芸人ギルド アーテリック（ギルドマスター アドニー、ネオク。音楽 / ダンス / パフォーマンス / 水泳）。闇教徒ギルド 暗使 / マブ教（ギルドマスター エクア、ムトゥーム地下墓地。牙 / 死の魔法 / 召喚魔法 / 暗黒命令。入会には習得済みの技が必要）。錬金術師ギルド アルケィナ（ギルドマスター代理 フレッサ、ビスク大聖堂。4種の魔法。入会にはマイナー バーストが必要）。フォレスターギルド フォレール（ギルドマスター ガスト、ランダル洞窟。弓 / 自然調和 / 物まね / 調教）。ギルドは9つと「無所属」があり、この5ギルドは4つのスキルを0.25ずつの重みで数える。ランクは5段階。武閃は無刀 / 木刀 / 鉄刀 / 豪刀 / 一閃刀。アーテリックは練習生 / フレッシュアイドル / スイートアイドル / ハートキャッチャー / シャイニング・スター。暗使は夕闇 / 白夜 / 月夜 / 闇夜 / 漆黒の使者。アルケィナは入門者 / 祈りし者 / 祝されし者 / 選ばれし者 / 超えし者。フォレールは一粒の種 / 朝露の芽 / 新緑の木 / 春風の林 / 古代の森。 →
  • ギルドランクの式：GP + 25 x（4スキルの合計）が 1,250 / 5,000 / 11,250 / 20,000 に達すると、ランクアップクエストでランクが1上がる。下回ると降格する。GPは0-10,000。ギルドクエストを破棄すると、ランクに応じて -10 / -50 / -200 / -400 / -800 のGPを失う。失敗などのもう一方の場合は -5 / -25 / -100 / -200 / -400。ギルドクエストのスキルボーナスは、各クエストの上限未満かつスキル合計850未満の場合のみ。究極奥儀の書の報酬は、すでに所持または習得済みなら与えられない。 →
