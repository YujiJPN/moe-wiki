項目ミニゲーム/精錬の泉

ルール（3 件）

  • 精錬の泉の強化ルール：カッパー製は不可、ほかの金属は可。素材が影響するのは最初の段階（「レゾ」化）だけ（ブロンズがいちばん失敗し、スチール / シルバー / ゴールドはあまり失敗しない）。グレード NG / HG は引き継ぐ。レゾ化したばかりはシルバーより弱く、+1 でブロンズくらい、+2 でアイアンくらい。最大 +9 で、段階ごとに難しくなる。確率は非公表。プレイヤーの測定：鉄 1,000 個でレゾ 69.7 %、+2 93.4 %、+4 52.8 %、+7 3.1 %。天冠系は 97.1 %の後 18.8 %。2020-21 年のナイフ検証もある。+N の段階はダメージ / AC に 0-9 を加え、グレードの ×1.1 はそのまま。段階が上がるごとに発動確率、補正、耐久度が増える。 →
  • 精錬の泉に入れられるアイテムと変化の系統：強化できる武器約60、防具19セット、盾6。段階強化ではなく変化するアイテム：スティック ソード類、ハンドガンのカラー、メンズ シャツ、天使の片翼から天使の両翼へ、アニマル レッグ 猫 → 虎 → 豹 → チーター、アニマ ライト → ノーマル（消失なし）、2系統3段に分かれる天冠、幼精 → ペット召喚アイテム（「Gold」で 100 %返却）、+1 → +3 と進みアニマル ケイジで終わる装飾品、消失しない頭乗りプルルーム、光放つ魔道書に至るグリモア系。 →
  • 精錬の泉（Webミニゲーム、2006年7月4日）：マイページに送ったアイテムを投げ込むと、強化されて（+1〜+9）戻るか、別のアイテムになって戻るか、失われる。「精錬」モードでは、未使用のアイテムがランダムな別のアイテムに変わり、失うことはない。キャンペーンチケットも同じ方法で交換する。泉はWebのマイページから使う（/window webshop）。アイテムは先にゲームからWebのアイテムボックスへ移しておく。強化の「+N」は、武器のダメージか防具のACに固定で 0 / 1 / 2 / 3 / 4 / 5 / 7 / 9 を加える。 →
