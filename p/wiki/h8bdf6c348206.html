ルール（5 件）

  • 暗使の通常クエスト：「出でよ…、我が僕」（コウモリの心臓 + 肉）、「血の霧に、紛れて…」（配達）、「死者に、闇の引導を…」（ニカワ）、「目覚めよ…、死の国」、「闇の祝福を、携えて…」、「毒を圧する…、暗使の牙」（サソリの抜け殻10個ごと）、「穢れなき手を、引いて…」（スー・メリア、書 [ ワー ウルフ ]、サンライズ キラー）、「肉を裂き…、骨と踊れ」、「影を剥ぎ…、闇を纏え」、「我捧げる…、供物」（悟りの石<牙>）。 →
  • 暗使のランクアップクエスト：「【夕闇】への実験」（マラクスのクイズ、書 [ イビルナイト ]）。「【白夜】への実験」（マミーのDebuff「デッドマンズ カース」の効果中に話しかける）。「【月夜】への実験」（暗使の杯、ムトゥームの霊水）。 →
  • 暗使のシップ装備クエスト：クエストのMobはクエスト中にだけターゲットできる。昼05:00-21:00はイルミナ城北西の塔のラル・ファク教徒、夜はムトゥーム墓地の神官の亡霊。「召喚 / 死 / 牙 / 暗黒に魅せられし者よ…」はスキル30で、その系統だけがダメージを与える。壊れた装備をサモナー スカルピアス、シャドウ ソード、ブラッドサッカー マスク、小悪魔の羽根と交換する。ペットも手伝える。「ネクロマンサーへの実験」と「イビルナイトへの実験」は4スキル40で、神官の亡霊 ブルート / ハイマ / ボイドが相手。 →
  • NPCギルド：戦士ギルド 武閃（ギルドマスター オグマ、ビスク西。刀剣 / キック / 盾 / 戦闘技術）。芸人ギルド アーテリック（ギルドマスター アドニー、ネオク。音楽 / ダンス / パフォーマンス / 水泳）。闇教徒ギルド 暗使 / マブ教（ギルドマスター エクア、ムトゥーム地下墓地。牙 / 死の魔法 / 召喚魔法 / 暗黒命令。入会には習得済みの技が必要）。錬金術師ギルド アルケィナ（ギルドマスター代理 フレッサ、ビスク大聖堂。4種の魔法。入会にはマイナー バーストが必要）。フォレスターギルド フォレール（ギルドマスター ガスト、ランダル洞窟。弓 / 自然調和 / 物まね / 調教）。ギルドは9つと「無所属」があり、この5ギルドは4つのスキルを0.25ずつの重みで数える。ランクは5段階。武閃は無刀 / 木刀 / 鉄刀 / 豪刀 / 一閃刀。アーテリックは練習生 / フレッシュアイドル / スイートアイドル / ハートキャッチャー / シャイニング・スター。暗使は夕闇 / 白夜 / 月夜 / 闇夜 / 漆黒の使者。アルケィナは入門者 / 祈りし者 / 祝されし者 / 選ばれし者 / 超えし者。フォレールは一粒の種 / 朝露の芽 / 新緑の木 / 春風の林 / 古代の森。 →
  • マブ教の伝承と友好度：マブ教の教祖はモラ族のイーゴで、8年前に先代教祖を殺害した。チュートリアルのリン以外のソウル・バインダーは、すべてマブ教徒。ゲオの加護とマブ教の友好度は、ランクアップで一度だけ上がる（降格後には再び上がらない。脱退して再入会した場合を除く）。 →
