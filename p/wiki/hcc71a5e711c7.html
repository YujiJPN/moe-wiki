  • モンスターとペットはレベルに応じて技を覚える（「Lv25.1：噛み付き」のように書く。「初期」は捕獲時から）。例：ネオク ビークの自爆技 カミカゼ ストライク（捕獲時から）、下僕のジャブ / ロウ キック / フレイム ブレス / ショックボルト。技は、モンスターのレベルがその技のレベル以上になると使える。使う技は、状況ごとの重みと技ごとの重みで抽選する。状況は近接、回復、強化、魔法、弱体、遠隔、ガード、マナ、治療、スタミナの10種類。 →
  • アクティブ性：A = プレイヤーの強さに関係なく襲う。下（格下アクティブ）= 自分より弱いプレイヤーを襲う。上（格上アクティブ）= 強いプレイヤーを襲う（ダークナイト、異国の剣士）。夜だけアクティブ（ナイト ハンター）、弱いとアクティブ（ヒルトップ ライオン）もいる。2013年の報告では、AとされるMobの多くは実際には下だという。格下アクティブは、プレイヤーのレベルが 1.4 × 自分のレベル + 2 + モンスターごとの値 以下のときだけ襲う。格上アクティブは、自分よりレベルが決まった値より多く下のプレイヤーを襲わない（異国の剣士は120）。友好度とレベルに関係なく襲うモンスターもいる。プレイヤーのレベル = (最大HP ÷ 3 + 攻撃力 + 命中 + 防御力 + 回避 + 魔力 + 5種の抵抗) ÷ 11。 →
  • 捕獲：アニマル / マンカインド / ドラゴン フェイタライズ（AF / MF / DF）、牙のブラッド シェアー、取引の技 ハイアー ボディガード / ハイアー マーシナリー は、P（ペット）または 僕（下僕）の印のあるモンスターを捕獲する。結果は青ネームペット。技ごとに捕獲できるモンスターの種類が決まっている。モンスターが捕獲する本人かそのパーティーをターゲットしている必要がある。1.2 × 調教 − ペットのレベル − モンスターのレベル ≧ 0 が必要。確率 = (0.7 × C + 0.3 × B) × f。C はモンスターのレベルが高いほど小さくなり、自然調和 × 0.1 が加わる。B は勢力の友好度で決まる。HPが満タンだと f = 0 で捕獲できない。ペット枠に入るものが青ペット、入らないものが下僕になる。 →
  • 青ペットと下僕の違い：青ペットは地名を名前に残し、名前を変更でき、成長し、ゾーン移動やログアウトをしても残る。下僕（ピンク / 黄色ネーム）は成長せず、ゾーン移動、ログアウト、死亡で消え、調教の制限に数えられない。 →
