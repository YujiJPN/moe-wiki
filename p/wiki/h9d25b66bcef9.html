項目FutureAge/赤の廟堂

ルール（15 件）

  • 赤の廟堂の攻略メモ：ヒーラーに役立つテクニックはターン アンデッド、グレイブヤード ミスト、マッド コート、レスト イン ピースなど 20 種。ヒーラーの装備は闇の加護の装備、懐中時計、魔力重視。火力の構成は神秘魔法サムライ、伐採 + 採掘と弓、複数の武器など。ダメージを上げるには、ディレイを短くする、近づきながら攻撃する、見えない Mob に範囲攻撃で先制する。役立つ火力テクニックはポール シフト、ペネトレイション、シール ショット、ゴルゴタ ショットなど 21 種。プレイヤーの助言をまとめたもの。 →
  • 範囲攻撃の分類：タイプ a はターゲット不要、タイプ b はターゲットが必要（バーニング シード、ペット、ミラージュ ミミック を起点にできる）。射程の分類は A 5.9 まで、B 6〜9、C 9〜15、D 15 以上。 →
  • 廟堂の宝箱：ほとんどは一度開けると消える。範囲の罠が発動することがある。部屋のモブに十分なダメージを与えると、罠なしで開けられる（宝箱が弱く光る）。右クリックの連打が有効。条件を満たすと再出現する宝箱もある。宝箱の罠は範囲内のすべてのプレイヤーとNPCに当たり、複数が同時に発動することもある。罠の種類：回避 0 %（エクゾシズム で治る）、固定の魔法ダメージ、瀕死 など。2007-10-16 に緩和された。赤の廟堂では、条件を満たしているとき、開けた宝箱が 1〜100 の判定を行い、70 未満なら中身の代わりにモンスターが出る。ほかの宝箱の罠は、ノックバック、変身2種、大爆発、瀕死、毒 から選ばれる。リムーブ トラップ を持っていれば罠を逃れ、持っていなくても 1/5 の確率で逃れる。 →
  • 赤の廟堂の宝箱の中身は、ステージとパターンで決まる（ステージ2 ハズレ。ステージ3 防具 / シップの宝箱。ステージ4 時の石 とシップの宝箱。ステージ6、8 時の石、マスク オブ クリムゾン、ポイズンバットマスク など）。宝箱は17種類あり、中身は宝箱ごとに重み付きで抽選される：素材、レアな素材（オリハルコンの破片、玉鋼、ノアピース、秘伝の書、ソウル オブ ヤマト など）、カッパーとフューチャーの防具セット、マスク、翼、カッパーと騎士の武器、ボーン ソード / ミスリル ナイフ / ミスリル ダガー（70 : 15 : 15）、石（悟り 55 : 賢者 25 : 時 20）、ノアクリスタル（個数も抽選）。 →
  • 廟堂のモブのドロップ：石柱から金属片 x5（銅 60 %、鉄 40 %、銀 30 %、金 20 %、ミスリル 10 %。錫、炭 x1）。コンバイン から ノア キューブ x10（78 %）、ファイン シルク バンデージ x5（48 %）、ラーニング クリスタル C（0.5〜1 %）。スカルパス の骨。クラスター から ブラッド オブ イーゴ（30 %）。ソレスの箱 / ゲオの箱。 →
  • 誕生の間の報酬：1人のプレイヤーがクリスタル4種1セットをバリア デバイス（右前方）にトレードして報酬を得る（部屋にいないメンバーは失う。1:30の制限）。報酬の順序：ホムンクルスなし → 生命の卵、ホムンクルスはあるが時の石なし → 時の石、両方あるがラーニング クリスタル A なし → ラーニング クリスタル A、すべてあり → ブラッド オブ イーゴ ×10（「持っている」は Present のインベントリ、銀行、ペットを数える）。生命の卵からはホムンクルスが出る。ホムンクルスは普通のペットとして成長する。 →
  • ラーニング クリスタル：ホムンクルスのペットに特定の技を教える。A / B / C があり、消費技ポイントは 1 / 2 / 2。教える技はホムンクルスのシップタイプで決まる。 →
  • 廟堂の未鑑定アイテム：武器13種（ボーン ソード、ボーン ブレイド、カースド ソードなど。攻撃力、攻撃間隔、射程、耐久、スキル、重さ、素材、追加効果：カース Lv1 33 % / 60 %、フリーズ 45 %、サンダーボルト 35 %）、防具21種（マインド リスト は詠唱速度 +5 だが実際は詠唱が延びる、ソーン リストなど）、装飾品15種（ポイズン バット マスク、殺人鬼マスク、狐マスク類、マスク オブ クリムゾンなど）、装備品以外の宝箱アイテム21種（触媒、修理素材、フューチャー クロース、ノア ストリング、オリハルコンの破片、悟りの石 / 賢者の石など）。武器の追加効果は攻撃の開始時に判定され、当たったときにかかる。 →
  • 選択の部屋：入場すると目標と制限時間が表示される。目標を満たして全員がスイッチを押すと、ワープゲートへの扉が開く。タイマーが00:00:00になったとき全員がゲートの上にいればクリア。黒いピラミッドの要石のスイッチには、青い石が示す人数が必要。ステージ1では5人全員で5人用の柱のスイッチに同時に触れ、ゲートで待つ。 →
  • 赤の廟堂のステージ（攻略）：ステージ2は3パターン（迷宮のクラスター / ベビー クラスター、スイッチ）。ステージ3は毒ガスのベノム クラスター（石柱、近道または宝のルート）。ステージ4は迷宮か広間のクラスター クイーン（睡眠と耐久の罠、シップの宝箱）。ステージ6は地雷のある長いルートのスカルパス（スカルパス メイジのいる二手の分岐）。ステージ7は1パターン（エンチャント メイジ2体、分かれたコース、閉まる扉）。ステージ8はコンバインとコンバイン ソーサラー（3人用の扉のスイッチ、宝箱3個）。ステージ10はスカルパス ロードとエンチャント ナイト4体（4人用スイッチからの炎の罠）。モンスターのレベル：石柱 50、クラスター 32、ベビー クラスター 16、ベノム クラスター 38、クラスター クイーン 48、コンバイン 90、コンバイン ソーサラー 95、コンバイン アブノーマル 150、スカルパス 45、スカルパス メイジ 45、スカルパス ナイト 47.5、スカルパス ロード 100、エンチャント ナイト / メイジ / スカウト 80、エンチャント ブルーナイト 90。 →
  • 赤の廟堂の挑戦の条件：パーティーを抜けたり帰還したりすると失敗。進むには5人全員が生きている必要がある（蘇生が必要）。廟堂のメッセージでは、5人のうち1人が死亡すると挑戦が終わる。メインスキル90未満や3次シップ未満のプレイヤーは断られることが多い（プレイヤーの慣習）。宝箱は罠付きだが、ステージ10の大きな宝箱は必ず開けるべき。罠が有効なときは1-100の抽選で70未満なら、宝箱から戦利品の代わりにモンスターが出る。 →
  • 赤の廟堂：バハにある 5 人パーティの時間制ダンジョン。部屋の順は待機部屋、チュートリアル、セレクションルーム 3 つ、回帰の間、セレクションルーム 3 つ、回帰の間、セレクションルーム 10、バースルーム（12 部屋、40-50 分）。各段階でランダムな配置を1つ選び、パーティが完全に解散するまでルートは固定。セレクションエリアは 4 つある。 →
  • 赤の廟堂の入口と待機部屋：小さな赤い建物に入り、5 人のメンバーがドアの前の 5 つの輪（半径 2.0）に立つ（5 人以下のパーティ）。移動を起こすのはリーダーだけ。ワープゲートは北／東／南／西の 4 つ。各ゲートは 3 分（180 秒）ごとに、そのうち最初の 60 秒の間に輪に立っているプレイヤーを送る（NPC は「5 分ごと」と言い、11 分ごとという説もあるが、実際は 180 秒）。遅れたメンバーは置いていかれる。送られるときに帰還地点がイプス雪原(Future Age) に設定される。 →
  • 回帰の間とバースルームの出口：タイマーを待てば先へ進む。未鑑定品を持ち出すには、浮いている記憶の石にトレードする（その後自動で退出）。1 人最大 4 個。石を右クリックすれば退出だけできる。バースルームでまだ持っているアイテムは持ち帰れない。未鑑定品は必ず呪われた状態で落ち、回帰の間から出す必要がある。案内には「脱出：記憶の石を右クリック。未鑑定品を持ち出すには、先に記憶の石にトレードする」と出る。 →
  • 廟堂の罠：オンとオフを繰り返す。モブにも当たる（強い火の罠はロードに使う）。空中では当たらない（ジャンプ、滑空）。罠の種類：黄色い霧 満腹度と潤喉度 −20、深緑の霧 毒（詠唱と包帯を妨害）、赤い霧 睡眠、輪 減速、水しぶき 耐久度低下 など（8種）。 →
