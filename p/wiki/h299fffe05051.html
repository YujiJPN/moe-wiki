ルール（15 件）

  • 牙の上げ方：合う相手なら、武器スキルと同じように上がる（スキルが敵の AC − 5 まで）。0〜100 の帯ごとに相手の目安がある。ブラッド サックとワーウルフはクエストでもらえる。攻撃用の牙テクニック 3 つは必ず成功する。 →
  • スキル別の効果量と持続時間：シャドウ ストライク / バニッシュ クラウド / シャドウ スティッチの持続時間（投げ）、曲の持続時間と効果量（音楽）、牙 40〜100 での効果、自然調和の効果（霊体時を含む）、スパルタン フィストの回復量（0 で 31、100 で 60〜69）。 →
  • 牙の攻撃力：攻撃の少ない噛みつきスキル。攻撃力は牙スキルだけで決まり、筋力、攻撃力、攻撃 Buff、装備の攻撃 / 命中は影響しない。ただし装備の「牙攻撃力 / 命中補正」は例外。回避の高い相手にはミスが増える。 →
  • スキルごとの複合技：投げ、音楽、ダンス、牙、自然調和、素手にもそれぞれ複合技がある。2 つ目の必要スキルやマスタリーが要るものが多い。 →
  • 牙のテクニックの射程：ブラッド サック、グール ファングなど牙のテクニックの射程は、武器の射程 4.5。バイトとハンガー バイトも同じで、バイトは移動中に使えるスキルによる近接物理攻撃で、当たると ST が少し回復し、モーションがキャンセルされる（発動 110 → 63）。 →
  • ブラッド サック：移動中に使える。射程内の相手に必中の魔法攻撃。相手の AC で軽減され、半減の抵抗もある。与えたダメージの分だけ回復する。 →
  • ハンガー バイト：牙の近接物理攻撃で、対プレイヤーのみ、攻撃ディレイ × 1.5 のデバフを与え、満腹度と潤喉度を減らす（パッチ 071120）。 →
  • ワーウルフ：狼（コボルトの姿）に変身する。回避と耐風属性が上がり、魔力が下がる。一部のバフと重複する。テクニックの発生時間が変わる。牙 73.9 までスキル上昇の判定がある。 →
  • グール ファング：ダメージを受けると解ける麻痺（攻撃も移動もできない）を与える。相手の AC で抵抗される。成功すると、使用者が前方へ 1.84 跳ぶ。成功時はヘイトが発生しない。スキル上昇の判定が 2 回ある。 →
  • ブラッド レイン：ターゲット不要。自分中心の半径 7.1。約 0.3 秒おきに 10 回、相手を引き寄せて ST ダメージを与える。ST ダメージは AC で軽減される。ルート ダンスとスワン ダンスで無効になる。 →
  • ハッキング バイト：近接の物理攻撃。命中すると、対象にかかっている新しいバフ / デバフ / DoTを2つ奪う。効果量と残り時間はそのまま。被ダメージで消える効果は通常奪えない。 →
  • バット フォーム：約 4.2 上昇し、その高さを飛ぶ（空中ではテクニックを使えない）。効果中は、他のバフの効果時間がそれぞれ元の効果時間の分だけ延びる。 →
  • ブラッド シェアー：人型のモンスターを時間制限なしで捕獲する（マンカインド フェイタライズと同じ。人型の16種類が対象）。捕獲したペットは青ペットになり、調教の上限内で成長する。捕獲には 1.2 × 調教 − ペットの合計レベル − モンスターのレベル ≧ 0 と、ペットの数の制限を満たす必要がある。自然調和が成功率を上げる（確率の C に 0.1 × スキル が加わる）。捕獲に失敗するとヘイトが1.0上がる。 →
  • 牙攻撃力・命中率補正の装備とバフ：フル ムーン、クレセント ムーン イヤリング、キョンシーの御札（2015/9/29 以降は重複できる）。バフの値は +5〜+25。命中／攻撃の補正がある装備は約50部位。牙100での実測ダメージ表がある（補正は最大 +150）。非複合シップ装備の命中補正は最大 +22、複合は +26。 →
  • 基本のテクニックはギルドのショップで買う：投げ 1-40 と自然調和 1-50 はフォレールギルド（アルビーズの森）、音楽 1-50 はカミラ（ネオク山、2012-07-24 パッチ）、牙 1-50 は暗使ギルド（ムトゥーム地下墓地）、素手 10-40 は武閃ギルド（ビスク西）。 →
