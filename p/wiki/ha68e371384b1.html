項目アイテム/防具/特産品

ルール（12 件）

  • 軍の装備（ビスク / エルガディンのソルジャー一式）：AC は Present / War で表記（24.5 / 35.0、上級 40.2 / 57.6）。「WarAge 以外では性能が低下する」。WarAge の NPC から 300 で買える。価格と錆状態のパッチ履歴がある。WarAge 以外では ×0.7（24.5 / 35.0 = 0.7 ちょうど）。武器も防具も同じ。 →
  • アイテムの状態：ダンジョンの宝箱の装備は「呪い」の状態で始まる（27種）。グレード表記は 呪 0.0 / 硬 0.5 / NG 0.6、錆 10.4 / NG 13.0。呪いは ×0.1、錆は ×0.8（13.0 × 0.8 = 10.4）、×0.5 になる状態もある。呪いを解く効果がある。復元が必要なアイテムもある。 →
  • 装備のレアリティ表記：ゴージャス プレートに「E」、ダンジョン報酬の刀剣に A / B / C。 →
  • グレード別（劣 / NG / HG）の AC と攻撃力、セットのまとめ（グレード別のセット AC、合計重量）。HG / MG は ×1.1、HG は耐久度が半分を切るとさらに ×0.9、劣は ×0.8。例：HG 41.8、NG 38.2、劣 30.5。 →
  • シップ制限装備：ペネトレイティング シューズはシップ「ハイキッカー」以上でないと装備できない。錬金術師の腕輪はアルケミスト系シップの前提スキルが必要。 →
  • 武器と防具に付く固定ステータスボーナス：攻撃力、命中、防御力、回避、魔力、最大ＨＰ／ＭＰ／ＳＴ。課金セット効果の最大値は SEEING +80、全耐性 +48、最大ＨＰ／ＭＰ／ＳＴ +40。 →
  • 装備の属性耐性ボーナス：耐火属性、耐水属性、耐風属性、耐地属性、耐無属性。 →
  • 装備の入手先：鍛冶、裁縫、木工、装飾細工、合成、NPC販売（Pre／War／War奇跡）、モンスターのドロップ、クエスト、宝箱、錬金の各弾、ガチャ、キャンペーン。 →
  • 特産品防具の一覧：ドロップとクエストから178種。部位、素材13種。属性のブレスレット、足枷（移動速度 −5.0）、10 / 18色の長靴とゴム手袋、アンティーク ランプ ベルトの光、女性専用5種。 →
  • 素材別の修理：綿、絹、皮、カオス → 布修理。木、竹、トレント → 木修理。金属 → 鉄修理（サークレットはアクセサリー修理も可）。骨、石、コバルト、クリスタルは修理できない。素材ごとに修理スキルと必要レベルが決まっている。修理すると最大耐久度が 0.9-0.96 倍に下がる。修理できるのは、CR でなく、素材があり、耐久度のあるアイテムだけ（それ以外は「修理できないアイテムです」）。 →
  • 修理費 = 購入価格の 40 %（売却価格の約 4 倍）。NPC の修理には2つの料金がある。最大耐久度の回復（復元が必要なアイテムだけ）は価値 × 0.4 で、これが 40 %。通常の耐久度の修理は 素材の品質（カッパー 80〜ゴールド 220）× 修理する量 × アイテムごとの係数（必要スキル ÷ 40、最低 0.025）× (2 − 現在 / 最大耐久度)。 →
  • NPC の売値は消耗とともに下がる（価格は新品で確かめる）。売値 max(1, trunc(価値 × 0.1)) に 現在 / 最大耐久度 を掛ける（買い戻し価格も同じ）。壊れた装備は売れない。 →
