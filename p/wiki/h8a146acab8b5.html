項目クエスト/特殊レシピ

ルール（19 件）

  • 鍛冶／木工／裁縫／装飾細工のレシピノートと宝珠の交換（ゴウテツ、ウィルコックス）：紅玉／深緑／蒼天／閃光／黄金／漆黒の宝珠などのアイテムを、レシピノートか完成品と交換する。 →
  • 古文書解読（クウェルク、ヌブール）：古文書と鍛冶・木工のレシピノートの交換が約 32 種。 →
  • レシピノートのクエスト：報酬はレシピノートで、バインダー番号で整理される。たいてい繰り返し受けられる。会話でレシピか完成品かを選べる交換もある。納品アイテムは40種類。 →
  • 魔法少女フィニュを救え！：邪神はマップの罠でしか倒せない。攻撃と魔法は効かない。近くに立つと30、罠で100のダメージ。封印の箱を再び封印する。報酬は5つのレシピノートから1つを選ぶ。 →
  • 未来の暗黒物質蒐集（naze、イプス雪原 FutureAge）：ダークマターは、そこでボスを倒すとたまるポイント。25 / 50 / 100 でレシピが解放される。クエストを破棄するとリセットされる。交換アイテムはトレード不可。カオスへの階段にいるはもはもは、ビスクへのテレポートとカオスの報酬の物々交換をしてくれる。 →
  • GG開発計画：GG-04、GG-05、GG-06A をティムに渡す。各段階でそのレシピノートがもらえる（習得済みなら出ない）。 →
  • 欲しい物は皆違う（Nietzsche、ヌブール）：神殿の宝具を矢と弓に交換する。累計7 / 15個で弓とそのレシピが一度だけもらえる。もう一度もらうには受け直す。 →
  • 山の香りを、ほんのり：ロザリー（シェル・レランへの所属が必要）がトリュフのクリームパスタを求める。報酬は100 G、アイテム、レシピ。 →
  • 熟されしは、腐の香り：ディアの依頼。熟成肉の香草焼きをサミュエルに届ける（なければレシピがもらえる）。報酬は200 G、レシピ、マブの友好度。 →
  • 味の決め手は、あなたの一指：サベージを倒し、指を渡す（1個25 G）。料理30以上ならレッド スープのレシピがもらえる。マブの友好度とゲオの加護も上がる。 →
  • 姉妹の愛：リリィ（21:00-03:00）の依頼。ロザリーと話し、エルビン風 パスタを渡す（時間外でも受け取ってもらえる）。報酬はレシピ スキヤキとエルビンの友好度。 →
  • 歓暖の鍋：店が開いた後にコンニャク芋3個をリリィに渡す。報酬はレシピ ドミグラス ソース。 →
  • ドンドコ丼（アンジェロ、ユグ海岸）：魚の浮き袋50個 + イクシオンの唇10個、次に丼20杯、次に大盛り20杯を渡す。報酬は3つのレシピ。 →
  • 新種の生物を発見せよ2！：1つ目のクエストの後、アビス クラブを右クリックで捕獲し、1匹をフルマンに渡す。レシピノートを持っていない間は繰り返し受けられる。 →
  • 殺人蜂の駆除：ヘルダーの依頼（サスールの友好度が必要）。キラービーの巣（HP 約3,000、AC 約150）を破壊する。壊した巣が多いほどロイヤルゼリーが増える。報酬はレシピ ロイヤル ミルク。 →
  • 闇と混沌の狂気：アリスリエルの依頼で浮遊都市 バハを調べる。城の扉の前にいる同じ姿のNPCを右クリックするか、「アリスリエル」とsayするとムービーが始まり、堕天使が出現する。堕天使の宝箱からは334-31,659 Gold。報酬はレシピと大天使の涙（繰り返し時の個数は5個とも2個ともいわれる）。懺悔のアイテムで秘伝の書がもらえる。 →
  • 発言で反応するNPC：一部のNPCは、ターゲットして決まった言葉を言うと反応する（右クリックの代わり）。ペットの芸、「生贄」、戦争の陣地などで使われる。 →
  • NPC の時間帯：一部の NPC はゲーム内の決まった時間帯にだけいる、または受け付ける（リリィ 21:00-03:00、ダーイン山方面の亡霊の夜間キャンプ 21:00-06:00 で会話、売買、トレード）。 →
  • ランダム チャンス ボックス：イプス峡谷の交換箱で、チャンス チケット50枚と交換する。精錬の泉に投げ込むと、ランダムな貴重品が出る。精錬の泉と錬金の森は、アイテムボックス（マイページ）を通してアイテムをやり取りするWebのミニゲーム。 →
