ルール（47 件）

  • WarAge とスキル：WarAge で上げたスキルは PresentAge でも残る。PvP の戦闘ではスキルは上がらないが、Buff のスキルは上がる。WarAge では上昇確率が 1.5 倍になる（一部の魔法を除く）。 →
  • ウォーエイジの調整：「壺の魔人」の威力はウォーエイジで調整された（2017-02-28）。「ひよこのペンダント」のモデルの大きさはウォーエイジで変わった。テクニックにはウォーエイジでだけ値が違うものがある（例：アルティメット バースト 3 → 0.5）。 →
  • ウォーエイジで役立つテクニック：クウェイク ビート（こんぼう 90、広い吹き飛ばし）、キャノン プレイスメント（銃器 50、約 150 ダメージ、味方にも当たる）、コーマ プラント（罠 40、約 10 秒の睡眠、ワサビで治る）、タックル（ノックバック、落下ダメージ）、センス オブ ワンダー（移動しながら攻撃）、ブラッド レイン（スタミナダメージと引き寄せ）、シャドウ スティッチ（鈍足）、サイレント ラン（ウォーエイジでは数秒間、敵のターゲットを外す）、リーシング スカイ（雨のときだけ、強い鈍足）、盾のテクニック（スタン ガード、カミカゼ、インパクト ステップ、リベンジ ガード）、チアー ダンス と スワン ダンス。タウント はウォーエイジでは相手のターゲットを術者に固定する。 →
  • WarAgeで役立つ魔法：バインディング ハンズ（減速）、ロットン ブレス（新しいバフを5つ解除。食べ物のバフ5つで対抗できる）、ポイズン ミスト、アイス ボール、サンダーボルト（水中で強力）、グループ ヒーリング、セイクリッド サークル、リザレクション、スティーム ブラッド、シー インヴィジィブル、ディスペル サモン、リコール アルター（集団輸送）。死体をルートすると、その死体は消えて蘇生できなくなる。リコール アルター で召喚される陣営オブジェクトは、WarAgeでの所属で決まる。 →
  • War Age のNPCとモンスターの信頼度は Present とは別。軍属の間は固定、中立は行動で変わる。「嫌っている」= 会話も取引もできず、兵士や拠点のモンスターが襲ってくる。「気にしていない」と「友好的」= 会話と取引ができ、襲われない。通常のモンスターは誰でも嫌う。軍属は敵拠点の店を使えない。中立は両方から嫌われた状態で始まり、勢力のNPC、拠点のモンスター、生産施設を倒すことで信頼度が動く。国に属するモンスターは、War Age では相手国の敵になる。 →
  • War Age の通常のモンスターはおおむね Present と同じ。Present の強いモンスターは War Age では弱く、ドロップ率と数も低い。War Age のマップのモンスターは、レベルとドロップが独自に決まっている。 →
  • 階級章：倒された軍属はその階級の階級章を落とす。自軍の給料支給NPCに渡すとボーナスがもらえる（Warlord 800 … Newbie 50）。敵の給料支給NPCを倒して得る ジェネラル メダル（ビスク / エルガディン ジェネラル メダル）は 20,000 Jade になる。 →

  • 軍の給料：ゲーム内で 1 日 1 回（00:00）。受け取らなかった日の分は消える。階級で給料が上がる（Amateur 200〜Warlord 5,000、Newbie 300 Jade）。Amateur、Newbie、Guard は条件なしで受け取れる。それより上の階級はレベル 60 以上が必要で（特定の称号があれば不要）、足りないと「体がなまっているので給料はなし」と言われる。2007-11-20 から給料の受け取りに戦功がかかる（Commander −1、Captain −1、Warlord −2）。 →

  • 時代間の移動：NPCに「時の記憶」をブランク ノアピースへ記録してもらう。AncientAge用は箱舟遺跡のラッカ・メリア、WarAge用はヌブールの長老イーノスからヤーナ・タングン。それを身に着けてアルターを使うと、その時代が行き先に出る。箱舟遺跡のアルターに乗ると開通する。WarAgeに初めて着いたとき、帰還用のノアピースが装備される。時代間の移動はテレポートウィンドウで行う。 →
  • WarAge：Presentから10年後の世界。ビスクとエルガディンが戦争中。PvPが可能で、倒した敵からアイテムを奪える。対人エリアでは国が異なれば敵になる。死亡するとアイテムはWarAgeの死体に落ちる。/gametime には「Year of War」と表示される。 →
  • WarAgeの移動速度：上限が130 %から120 %に下げられた（2017-01-10。水中での速度は影響なし）。マップ 3100 とマップ 2071 では上限が100 %。やきいもの上昇と黄金のゆで卵の変身は、WarAgeでは働かない。ほかにもWarAgeでは働かない技の効果がある。 →
  • 軍の目標：敵の本拠地を奪う。すべての拠点を保持すると「奇跡」が起こる（中立は拠点を取れない）。任務は拠点の占領・奪還・防衛（/warinfo）、敵の給料長の討伐（約8ゲーム時間後に再出現）、自軍の給料長の護衛、ゲリラ、偵察。拠点の旗を倒したとき、その拠点の守備隊がいなければ、拠点は倒した側の国のものになる。新しい守備兵が出現し、変更はWarAgeの全マップに告知される。 →
  • プリズン・マイン：NPCがルート権を持つ状態で敵の本拠地で死亡すると、プリズン・マインへ送られる。看守ルドにプリズンマイン ゴールド10個を渡すと出られる。錆びた針金も持っていると脱獄の試みとみなされ、針金とゴールドを取られてやり直しになる。出るときは監獄のアイテム（プリズナーズ ピックアックス、プリズンマイン カッパー、ゴールド、ブレッド、ウォーター、錆びた針金）をすべて取られる。釈放先はWarAgeのヌブールの村か、レクスール・ヒルズ(War_Age)の自軍支配地域付近。ミルキーがカッパー20個で水とパンを渡す。道具を持たないプレイヤーは、ピッケルと採掘の秘伝の書をもらえる。監獄で死亡すると所持品の一部を失う。 →
  • 給料長による移動：自軍の給料長（BSQはアクセル、ELGはミクル）に話しかけると、自軍の支配地域へアルター移動できる。移動時に、パッシブ以外のすべてのBuffとチャージ中の魔法が解除される。アクセルはビスク港(War_Age)、ミクルはエルガディン王国にいる。かつては給料長からノアピース「ペリドット」（ソルジャーのメダル）を受け取り、リコール アルターは使えず、支配の変更がWarAgeの全ゾーンに告知された。2024年から、中立はタルタロッサ・パレス(War_Age)のフライハイトからペリドットを受け取り、中立地域へ移動する。 →

  • 奇跡と呪いの時：DA / CCをすべて保持すると、その側に奇跡、敗者に呪いが訪れる。その後、本拠地は元に戻り、拠点は中立になる。期間は2012-05-22から約8ゲーム時間（以前は24時間）。2012-05-22には奇跡のカウンタ（+1 / -1）で給料、商品、価格が変わるようになった。カウントは2012-06-05に停止し、追加されたNPCと商品は残った。戦争フェーズ以外の時間に、勝った側の本拠地には七賢者が現れ（奇跡）、負けた側には呪いが訪れる。 →
  • 奇跡の間：本拠地の勢力NPCはすべて消え、古代モラ族の七賢者と三人の雑貨屋が現れる。各賢者は はい / いいえ を尋ねてBuffを1つ与える。シスは直接攻撃に雷、ミトヤは命中と素早さ、ユグは最大MPと魔法耐性、ゲオは最大HPと重量、ソレスは透明、フェンネは採掘力（オリハルコンを掘れる）、ロザロトはスタミナ回復が速くなる。Buffは一度に1つで、掛け直しができ、Presentに持ち越せる。「最大値まで」のBuffは、実際には一律 +50.0。賢者の説明では、効果は24時間で、受けられるのは賢者1人のみ。 →
  • 中立としてWarAgeを観光する：布の服を着る、自己紹介する、座って挨拶する、オープンセラーを使う。勢力NPCは信頼のない訪問者を攻撃する（AC 0で40-100ダメージ）。本拠地のNPCは、同じ側のプレイヤーが攻撃されるとリンクする。大規模な戦闘はたいてい20:00-24:00（プレイヤーの慣習）。ヌブール以外はどこでも攻撃されうる。 →
  • War Ageの所属：ビスク軍（BSQ）、エルガディン軍（ELG）、中立（NEU）の3つ。中立は山賊のように振る舞う。両軍とほかの中立から狙われ、奇跡の恩恵を受けない。中立の範囲攻撃はほかの中立にも当たる。勢力が違えば敵どうし。追放者と、同じパーティでない中立どうしは、自由に攻撃できる。勢力を持つクリーチャーは、War Ageでだけ他勢力の敵になる。 →
  • 軍への入隊：入ったばかりは無所属（白旗）。名前が赤ならビスク、青ならエルガディン。ピエールが勢力について説明し、入隊管理人は村の広場にいる。入隊するとアルターから自軍の本拠地へ飛べるようになり、日給がもらえる。 →

  • 亡命：階級Newbie以上で、追放されていないプレイヤーが対象。亡命斡旋NPC（クレフ、ヴァイト）に5,000 Jadeを渡すと「亡命の密約書」がもらえる。これを敵軍の総隊長に渡すと勢力が変わり、War Ageのヌブールの村へ移される。総隊長は代わりに中立になる道も示す（「すべての軍に狙われる」）。フライハイトを通じて中立になることもできる。密約書はトレード不可で、ログアウトすると消え、死亡時には優先的に落とす。密約書を持ったまま死亡またはログアウトすると失敗となり、銀行以外のすべて（シップ装備も含む）を失ってプリズンマインへ送られる。ホームポイントも強制的にプリズンマインになる。ガードは密約書を持つ者を襲う。中立になると両軍との友好がなくなる。亡命者を倒すと報酬用の密約書を落とす。追放者はパーティに入れず、戦争ポイントも得られず、誰からも自由に攻撃される。 →

  • 階級と戦争ポイント：階級は敵を倒して得るポイントで上がり、倒されると下がる。給料は階級で決まる。上位の階級にはノルマがあり、War Ageでの滞在時間24時間以内に達成できないとポイントを失う。ポイントの上限は9999。階級ごとのポイント／給料／ノルマ／倒した者が得るポイントは次の通り。Warlord 51以上／5,000／5／10。Captain 31〜50／2,500／3／8。Commander 21〜30／1,500／1／6。Soldier 11〜20／1,000／なし／4。Guard 6〜10／600／なし／3（Warlordが倒したときは0）。Newbie 1〜5／300／なし／2（Captain以上が倒したときは0）。Amateur 0以下／200／なし／1。敵軍に倒されると2〜10ポイント失う。中立やmobに倒されたとき、落下や自殺で死んだときは失わない。ノルマの期間は表示では24時間だが、実際は23.04時間。残り2時間、1時間、10分、5分（表示上の時間）で警告が出る。ポイントがもらえるのは、倒した者と倒された者の階級の差が4未満のときだけ。100 m以内のパーティメンバーは、それぞれ (1 + 0.05 ×（人数 − 1）) ÷ 人数 倍のポイントを得る。War Ageのダーイン山とイルヴァーナ渓谷の一部のマップではポイントが入らない。 →
  • 呪いの時：イーゴが呪いの言葉を唱えると、勢力のNPCがすべて消え、マブの使徒が歩き回る。マブの使徒は、その時にしか手に入らないアイテムを落とす。マブの使徒とイーゴは、両軍の本拠地（エルガディン王国、ビスク港）に現れる。 →

  • WarAge の死亡ドロップ：落としたアイテムは死体に残り、約60秒保持される。ルートの保護はない。 →
  • WarAge の死亡時のアイテムドロップ：ペナルティは個人のアイテム喪失だけ。原因を問わず、死亡すると装備と所持品からランダムにアイテムを落とす。軍属が落とす数は、階級と場所（自軍 / 中立 / 敵の領土）による：Warlord 2 / 3 / 3、Captain と Commander 1 / 2 / 2、Soldier と Guard 0 / 1 / 2、Newbie と Amateur 0 / 1 / 1。国のない中立は敵の領土と同じ扱いで、階級がないので1つ落とす（ヌブール以外）。領土は本拠地、CC / DA のゾーン（保持している側で数える）、自由ゾーンに分かれ、ヌブールは非戦闘。ダーイン山とイルヴァーナ渓谷では落とさない。スタックは個数の半分を失う。「死亡時ドロップしない」アイテム（シップ装備はすべて）は落ちない。「先に落ちる」アイテムが優先して選ばれ、最大6個まで。軍属の死体は階級章を持つことがある。 →
  • WarAge の復活：ヌブール以外では、死んだプレイヤーは1分以上の猶予時間のある死体として残る。猶予中に蘇生されると、透明かつ無敵で立ち上がる（移動で解除）。猶予が過ぎるかホームポイントを選ぶと、霊体にならずにヌブールへ行く。WarAge に霊体はない。ホームポイントへの自動帰還は 60 + 0.6 × 死体回収 秒後。 →
