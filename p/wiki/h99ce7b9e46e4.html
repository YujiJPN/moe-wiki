ルール（12 件）

  • 素手の上げ方：攻撃間隔の短い武器で、スキルより強いが離れすぎていない相手を攻撃する。0〜100 の帯ごとのお勧めは、白ヘビ … ギガース、タルタロッサ。 →
  • スキル別の効果量と持続時間：シャドウ ストライク / バニッシュ クラウド / シャドウ スティッチの持続時間（投げ）、曲の持続時間と効果量（音楽）、牙 40〜100 での効果、自然調和の効果（霊体時を含む）、スパルタン フィストの回復量（0 で 31、100 で 60〜69）。 →
  • 素手のパッシブ：素手攻撃の攻撃力と命中を上げる。ナックルなしのときだけ、素手攻撃のクリティカル率も上げる（素手 98 で 17 %、ナックル付きで約 3 %）。 →
  • キック 100：素手攻撃とテクニックのディレイが 20 % 短くなる。 →
  • テクニックのディレイ：ほとんどのテクニックのディレイは、テクニック自身のディレイ + 武器の攻撃間隔。パッチ 070626 で、素手テクニック 5 つの射程が変わった。 →
  • 素手の特徴：速い攻撃を何度も出せるが、射程は短い。キックや酩酊と組み合わせて使う。序盤は弱い。 →
  • 攻撃力：ATK = 0.2 × STR × 種族係数 + (STR + 300) / 350 × 武器ダメージ + 必要スキル補正 + Buff。 →
  • 素手の武器ダメージ：0.3 × 素手 × (素手 + 200) / 300 + ナックルのダメージ。素手 100 の素手攻撃は、ダメージ 30 の武器と同じ。 →
  • 素手の攻撃間隔：180 + ナックルの間隔。手動攻撃のディレイは間隔 × 0.9、自動攻撃は間隔そのまま。素手扱いで武器を持っていないときは、テクニックのディレイが 3.2 秒長くなる。 →
  • 左手のナックル：右手に何も持たず、左手にナックルを着けていると、攻撃は左手のナックルで行う。威力、ディレイ、消耗もそのナックルのもの。それ以外のときは、左手のナックルはジャブ専用。 →
  • スキルごとの複合技：投げ、音楽、ダンス、牙、自然調和、素手にもそれぞれ複合技がある。2 つ目の必要スキルやマスタリーが要るものが多い。 →
  • 基本のテクニックはギルドのショップで買う：投げ 1-40 と自然調和 1-50 はフォレールギルド（アルビーズの森）、音楽 1-50 はカミラ（ネオク山、2012-07-24 パッチ）、牙 1-50 は暗使ギルド（ムトゥーム地下墓地）、素手 10-40 は武閃ギルド（ビスク西）。 →
