ルール（14 件）

  • モンスターとペットはレベルに応じて技を覚える（「Lv25.1：噛み付き」のように書く。「初期」は捕獲時から）。例：ネオク ビークの自爆技 カミカゼ ストライク（捕獲時から）、下僕のジャブ / ロウ キック / フレイム ブレス / ショックボルト。技は、モンスターのレベルがその技のレベル以上になると使える。使う技は、状況ごとの重みと技ごとの重みで抽選する。状況は近接、回復、強化、魔法、弱体、遠隔、ガード、マナ、治療、スタミナの10種類。 →
  • 出現の注記：数と頻度（「10分に1匹」「5分に4匹」「付近の豚を全滅させた後」）、条件POP、期間限定のものがある。War Age のミーリム タイガーは、リアル時間で約7.5時間ごとに、ゲーム内時刻 23:00〜1:00 に出現し、4:00 に消える。モンスターごとに、再出現までの秒数（ランダムなものもある）、出現する時間帯（ゲーム内時刻）、特定のモンスターやグループがいる / いないという条件が決まっている。消える条件もある（例：5時〜20時の間はいない）。 →
  • 捕獲できるモンスターの体質と速さ：高HP、超低HP、高速攻撃（約3秒。準高速は約5秒、その他は約7秒）、飛行高度、移動速度の分類がある。ステータスはモンスターの種類とレベルで決まる。攻撃の間隔と移動速度も種類ごとに決まっている。 →
  • レアの抽選POP：レア ネオク ビーク、蹴りタイプのヴァルグリンド アマゾネス、魔法タイプのパレス タルタロッサ、リザードマンの各タイプが、通常のものの代わりに低確率で出現する。どれが出るかは出現時に重みつきの抽選で決まる（例：ネオク スパイダー 70 / 30）。 →
  • 捕獲：アニマル / マンカインド / ドラゴン フェイタライズ（AF / MF / DF）、牙のブラッド シェアー、取引の技 ハイアー ボディガード / ハイアー マーシナリー は、P（ペット）または 僕（下僕）の印のあるモンスターを捕獲する。結果は青ネームペット。技ごとに捕獲できるモンスターの種類が決まっている。モンスターが捕獲する本人かそのパーティーをターゲットしている必要がある。1.2 × 調教 − ペットのレベル − モンスターのレベル ≧ 0 が必要。確率 = (0.7 × C + 0.3 × B) × f。C はモンスターのレベルが高いほど小さくなり、自然調和 × 0.1 が加わる。B は勢力の友好度で決まる。HPが満タンだと f = 0 で捕獲できない。ペット枠に入るものが青ペット、入らないものが下僕になる。 →
  • ペットの分類：特殊ペット（干渉しない、調教不要）、鑑賞ペット（育成できない）、特別入手青ペット（アイテムから。調教が必要）、青ペット（捕獲）、下僕ペット（一時的）。青ペットは調教なしでLv 7.5まで育つ。成長上限 = clamp(3 × 調教 − ほかのペットのレベル, 1, 1.5 × 調教)。調教は最低5として扱われる（上限 7.5）。特殊ペットは調教100として成長する。 →
  • 飼い主がパフォーミング ウィップを使うとペットは特殊技1を、ブリーディング ウィップを使うと特殊技2を使う。 →
  • タイプ別のペットのレベルごとのHP増加：高HP 0.1 Lvにつき +1 HP、準高 +0.6〜0.9、中 +0.5、低 +0.2〜0.4（AF系はほとんど低）。同じ種類のペットなら、同じレベルで同じステータスになる。 →
  • 捕獲できるモンスターは、青ペット59体（Present Age 18ゾーン、War Age 5ゾーン、ゲオの大空洞）と下僕約81体（ベビー バット Lv 0.9 以上）。ステータスの記載は初期値で、個体差が少しある。召喚ペットは含まない。 →
  • ペットのエサは16種類（草食物、肉食物、食べ物、飲み物、酒、薬、骨、皮、金属、石、クリスタル、木、紙、布、お金、その他）。ペットごとに大好きな物（◎）、好きな物、嫌いな物がある。例：エルビン バイソン 牝は草食物が◎で、肉食物が嫌い。 →
  • 生産ペット：レクスール コボルト マイナーは、忠誠度50以上で銀鉱石3個以上を同じ数のコバルトインゴットに変える。ガルム コボルト クリエイターは、コバルトインゴット10個をリングに、15個をイヤリングに変える。エルビン バイソン 牝（忠誠度33以上）は、飼い葉1個 + 空瓶10個からミルク10個を搾る。羊のペットの毛を刈ると、たまった分の羊毛が得られる（最大1000。刈ると0に戻る）。ジャッカロープの搾乳は、ゲーム内の曜日ごとに1回。忠誠度が低すぎるとできない。 →
  • 魔法系のペット（パレス タルタロッサ 魔法タイプ、エルアン / ハティル リザードマン メイジ）は、忠誠度50以上でAIを切り替えられる。変化の秘石は、エルアン / ハティル リザードマンを同じリザードマンの別タイプに変える。どちらもペットにアイテムを使うかトレードしたときに、レベルと忠誠度を確かめて行われる。 →
  • ペットの死亡：青ペットは失われない。HP 0で Dead になり、最大忠誠度が約 Lv / 6 下がる。ラブペット M で防げ、慈愛のペンダントで半減する。蘇生したペットはHP 1。/petcorpse で死体を動かせる（同じゾーン）。/petsensecorpse もある。死亡すると解放されるペットもいる。 →
  • 最大忠誠度で制限される技：ネオク グリズリーは、最大忠誠度100でないとベアダウンを使わない。ゲオ モールはLv 45、忠誠度55〜60でツインクロウを使い始め、敵の岩石落としを無効化する。ペットの技には、最大忠誠度と忠誠度の条件がつくものがある。 →
