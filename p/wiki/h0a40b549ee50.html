項目アイテム/防具/生産販売品（非金属）

ルール（13 件）

  • 名前つきのアイテム効果：励起する魂、漆黒の力、風の加護、クラフトマン ソウル / ハート、モーション変化、アイテム使用ディレイ短縮 Lv1 / Lv2、治癒能力アップ、クリティカル率UP A Lv1、マーメイドの加護、落下ダメージ軽減、弓 / 銃 攻撃ディレイ短縮、魔法剣、マナ フォース、玄武の加護 など。効果は装備してから一定時間後にかかる。同じ効果を複数の部位で持っていても1回分だけ。WarAgeとFutureAgeのマップでは効果が消える。 →
  • グレード別（劣 / NG / HG）の AC と攻撃力、セットのまとめ（グレード別のセット AC、合計重量）。HG / MG は ×1.1、HG は耐久度が半分を切るとさらに ×0.9、劣は ×0.8。例：HG 41.8、NG 38.2、劣 30.5。 →
  • 性別限定装備：貝殻、風、撫子、フェザーは女性専用、大和は男性専用。非金属装備で女性専用33部位、男性専用10部位。 →
  • 武器と防具に付く固定ステータスボーナス：攻撃力、命中、防御力、回避、魔力、最大ＨＰ／ＭＰ／ＳＴ。課金セット効果の最大値は SEEING +80、全耐性 +48、最大ＨＰ／ＭＰ／ＳＴ +40。 →
  • 装備の属性耐性ボーナス：耐火属性、耐水属性、耐風属性、耐地属性、耐無属性。 →
  • 装備の感覚補正：SEEING、HEARING、SMELLING。 →
  • 水着の息（BREATH）と泳ぎ速度：スイムスーツ BREATH +3、貝殻セット +10 と表示されない回避 +4。info に表示されない隠しボーナスもある（カオス ローブ 耐水属性 +2）。 →
  • 装備によるスキル判定の補正：盗み補正、牙命中率補正、キック命中率補正とキック攻撃力補正。 →
  • 装備の入手先：鍛冶、裁縫、木工、装飾細工、合成、NPC販売（Pre／War／War奇跡）、モンスターのドロップ、クエスト、宝箱、錬金の各弾、ガチャ、キャンペーン。 →
  • 非金属防具の一覧：252種（着こなしの区分、部位、素材10種）。ガチャセットの生産版には精錬できないもの（17種）と転送できないもの（8種）がある。 →
  • 装備の生産ゲージ補正：料理、醸造、薬調合、鍛冶、裁縫、装飾細工、複製（ペン槍）、美容のヒットゾーン、ゲージ速度、グレードゾーン、ゲージ滑り。クエストの生産用イヤリング。 →
  • 素材別の修理：綿、絹、皮、カオス → 布修理。木、竹、トレント → 木修理。金属 → 鉄修理（サークレットはアクセサリー修理も可）。骨、石、コバルト、クリスタルは修理できない。素材ごとに修理スキルと必要レベルが決まっている。修理すると最大耐久度が 0.9-0.96 倍に下がる。修理できるのは、CR でなく、素材があり、耐久度のあるアイテムだけ（それ以外は「修理できないアイテムです」）。 →
  • 死亡時のアイテムの扱い：ND（死亡時ドロップしない）、CA（カオスエイジで死亡しても消えない）、DL（所有者が死ぬと消える）。カオスの装備には DL と CA の両方が付いている。ヘルカイザー のセットは ChaosAge で残る。ハイリヒト リッター は「PM、ミスリル強化可能」。WarAge で死ぬと最大6個のアイテムを落とすが、ND のアイテムは落ちない。落とす数は戦争の階級と領土による（0〜3）。WarAge 以外では落とさない。DL アイテムは、死亡後にホームポイントへ戻ると消える。ChaosAge の6マップ（カオス・スペースの地・火・水・風・天・冥の門）では、死亡後の帰還で CA アイテム以外のインベントリ、装備、レンタル収納ボックスの中身がすべて消える。 →
