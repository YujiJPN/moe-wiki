項目アイテム/クラフト

レシピ

クラフト ゲートと強化釜で手に入る品。名前に「フューチャー」が付くレシピ: フューチャー クロース、フューチャー シェル シールド。ほかのレシピはレシピ一覧。

ルール（13 件）

  • 時の秘石：使うたびにスキルブースト合計の上限が 5 上がる。500 から 1000 まで上げられる（100 個）。青の廟堂で手に入る。 →
  • ブースター：アタック / マジック / アジリティ / デクステリティ / ディフェンス（攻撃力 / 魔力 / 回避 / 命中 / 防御力 +20 %）、効果時間 576秒。5つすべてを同時に使える。ディレイはほとんどない。ダンジョン限定。 →
  • エレメンタル ガード：火 / 水 / 地 / 風 / 無属性のダメージ −50 %、効果時間 576秒。5つのうち有効なのは一度に1つだけで、新しいものが前のものを置き換える。魔法ダメージを半減するだけで、耐性低下のデバフは軽減しない。 →
  • ノア リジェネレーター：11.52秒ごとにHP、ST、MPを40ずつ回復する。効果時間は230.4秒（20回）。ディレイ約20秒。レアな魔法アイテムとは別の系統なので、それらと重複する。 →
  • レアな魔法アイテム（互いに重複しない、ディレイ約20秒）：ノア リバイブ（57.6秒：死亡時に完全復活。他のバフはすべて消える）、ノア ベール（19.2秒の魔法無効化。グレーター マジックシールド のように攻撃魔法を回避する）、ノア プロテクター（300ダメージを吸収。聖壁 と一緒に削られる）、ノア ブレッシング（毒 / DoT以外の負の効果を19.2秒無効化）。 →
  • 特殊条件の略称15種（NT、OP、CS、CR、PM、NC、NB、ND、CA、DL、TC、LO、AL、WA、DA）は課金武器とクラフトのページでも同じ。NT、LO、AL のアイテムにも CS の表示が出る。DA の実際の働き：DA のアイテムの攻撃力、防御力、すべての追加効果は青の廟堂(Future Age) のダンジョン内でしか働かない。エリア外でも表示は残る。DA のアイテムは204種。エリアの外ではダメージ／AC が 0 になり、追加効果、武器の追加効果、弾のテクニックも働かない。青の廟堂(Future Age) では、すべてのアイテムの常時発動の装備効果が外れる。 →
  • 青の廟堂のフューチャー ノア装備：武器（ブレイド、クラブ、スピア、トンファーの対、銃、ボウ、ワンド。スキル30、耐久32、重さ3、鋼鉄）。攻撃力はレベルごとに基本値の +1/6（+9 ＝ × 2.5。トンファーは15 %）。命中 +15〜+60 と攻撃ディレイ −2〜−20 がレベル別、ワンドは魔力 +15〜+60。盾は AC 4.5 → 18、ブロック 82 → 100 %、耐性 +15 → +60。防具（脳筋向け、5部位）と防具（魔法使い向け、4部位）は +9 で AC × 4、ＨＰ／ＳＴ または ＭＰ、攻撃力／魔力、回避のボーナス付き。弾はノア アロー 25、ノックバック付きのノア ラウンド ショット 30、ノア スロー ナイフ 45、売価0。+0〜+9 はそれぞれ別のアイテムで、フューチャー ノアのアイテムは181種。 →
  • 強化段階ごとの特殊条件：+0〜+8 は PM / DA、+9 は DA / NC / NB で PM なし（運営が確認）。 →
  • ノア ポーション類（青のダンジョン内専用。特殊条件は NT、DL、DA。重さ 0.07）：ヒーリング / スタミナ / マナは薬調合0で 63-75、100で 105-114 回復。ノア ドランク ポーションは酩酊度 +10.1（薬と同じ扱いで使う）。ノア リムーブ ポーションはストーンアイ、ガイアブレスを含むステータス ダウンと状態異常を解除。ノア エリクシル ポーションは HP、ST、MP を約235回復（基本値は各 250）。ヒーリング / スタミナ / マナの基本値は 70。効果量は基本値に使用者の薬調合による伸びを掛け、さらに × (1 + 0.01 × スキルボーナスの合計)。アイテム使用のカウントダウンはすべてのアイテムで共通。ノア ポーション類はクラフト ゲートで手に入る。 →
  • 青の廟堂装備の入手：もとのアイテムは「クラフト ゲート」から、+1〜+9 は強化釜から。どちらもマイページへ転送できない。リペア マテリアルを装備と一緒に強化釜にトレードすると修理され、+9 装備の染色がリセットされる。クラフト ゲートには6色のクラフト マテリアルのうち違う2つを渡し、1組につき1回クラフトする（組み合わせは15通り。条件によっては別の表から出る）。出る個数の確率は 1個 53 %、2個 32 %、3個 15 %、5個 1 %。エンハンス マテリアル α 10 個で β 1 個、β 10 個で γ 1 個。強化釜にはフューチャー ノア装備とエンハンス マテリアルを渡す：+1〜+3 は α 4 / 8 / 16、+4〜+6 は β、+7〜+9 は γ（最大 +9）。リペア マテリアルは最大耐久度を下げずに修理する。 →
