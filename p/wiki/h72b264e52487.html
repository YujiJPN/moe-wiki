ルール（11 件）

  • 観賞用ペット（見るだけ）：育成できず、出しておくだけ。命令を受けず、エサも食べない。通常13種類、タイアップ11種類。 →
  • ミラクル キャット：War Age で「奇跡」を起こした勢力の本拠地の雑貨屋NPCが売るキャット ケイジ。Lv 10.1、HP 46、歩き / 座りモーション、エサなし、成長しない。奇跡が起きた後、戦争の期間外には七賢人が現れる。 →
  • ゲートキーパーの像：木工の「モンスター人形 [○○ゲートキーパー]」は、カオスの板材35個 + 魂の欠片で作る。木工99.0（成功マスが狭い）。像は10種類、Lv 1、HP 18、MP 16。ドミニオンで乗り移れる（HPは減らない）。ボスの武器を持つと見た目が完成する。パーフェクト ミミックは何もしない。一部は巨大になる（LoCは50 %。NGKから降りると18 mの落下）。HP 0の像は、蘇生か回復するまでケイジに入れられない。 →
  • 進化できる像とキット：ノア・タイタンの像（QoA ジャスパーのクエスト「二人の絆」。Lv 1、HP 18.5）はミニ タイタンに進化する。からくり トレントとからくり ウォープレートは、育成できるペットに進化する。からくり ビスクナイト / ドラゴンナイト（Lv 30、HP 148、MP 30）、からくり デュラハン（儀式の間の報酬）。進化はペットにアイテムを使うかトレードしたときに、レベルや忠誠度を確かめて行われる。 →
  • その他の観賞用ペット：ブラックナイトの像（「混沌の記憶」）、スカイドラゴン ベビー（Lv 26〜28。サウザンド ドラゴン近くのサソリの洞窟にいる1体をテイムして入手）、ミニ スノーマン（クエスト「雪合戦」、2013）。 →
  • 成長する観賞用ペット（チンチラ キャット、おさんぽ あびにゃん、ミニ ヤッターワン、アクビちゃん）：単独ではヘイトを取らず、範囲攻撃やデバフに巻き込まれると経験値が入る（確率 = ダメージ ÷ 最大HP × 10）。エサと最大忠誠度があり、かかれ / 逃げろは受け付けるが攻撃はしない。3体の制限には数えるが、召喚のレベル制限には数えない。 →
  • 壺の魔人（2017）：1種類のポーションを1〜1,000個預かり、飼い主のそのステータスが60 %を下回ると1個使う（Lv 10で40〜46回復、ディレイ約10秒）。忠誠度9以上が必要。アバタータイプ（範囲物理攻撃とデバフを受けない）。エクスペリエンス パウダーが効く（経験値 +50）。 →
  • 回復するお供ペット：シマエナガ（2021）と、いやしましゅまろシリーズ（2018〜）。無敵で、出している間は約10秒ごとに飼い主のHP / ST / MPを10回復する。シマエナガは2体、3体と出すと回復する種類が増える（ペットウィンドウで数える）。回復のポップアップは出ない（ヘル パニッシュを剥がさない）。エサ不要。2022年から、特定の3体の組み合わせでチームBuff（攻撃 +10、移動速度 +10、最大HP / ST / MP +30、魔力 +10、被ダメージ −10 %）。 →
  • 範囲内の飼い主を強化するサポートペット（3分。Buff枠1。範囲内で自動更新。ケイジ内で保持。War Age では効果なし）：ハロウィン キャット（魔力と移動速度 +10 %。変化の秘石で育成できるペットに変わり、また戻る）、まほいくのアバター（スノーホワイト アバター 魔力 +5〜10 %とMP回復、ラ・ピュセル アバター 攻撃 +5〜10 % / 防御 +10 %、リップル アバター 命中と回避 +10〜15 %、トップスピード アバター 移動速度と移動詠唱速度 +10〜15 %）、ディスガイアSD（ラハール SD 攻撃 +10 %、エトナ SD 確率で50 %反射、フロン SD 物理ダメージ −15 %）、FAIRY TAIL（ハッピー 回避 +15 %と30秒の浮遊、メイビス 魔力 +10 %とフェアリー グリッターを教える、シャルル MP消費 −10 %と浮遊）。 →
  • アクビちゃん：右クリックで変身し、6形態からランダムに1つになる。3分続く（2分という報告もある）。ジャンプやケイジでは終わらず、ゾーン移動かリログで終わる。金魚の形態は息継ぎゲージを回復する。 →
  • ミニ パンダマン：公式ダイアロス･バザールのイベントステージの参加賞（5枚）。プレイヤーと同じ速さで移動する。パフォーミング ウィップで5種類のパフォーマンスをする。 →
