項目アイテム/防具/生産販売品（金属）

ルール（8 件）

  • 装備の特殊条件は15種（NT、OP、CS、CR、PM、NC、NB、ND、CA、DL、TC、LO、AL、WA、DA）。どの武器ページにも載っていて、ページごとの件数（PM、CS、NT、NC、NB、ND、CA、OP、LO、TC、DL、CR）と印（カオスの DL / CA、PM、OP、NB、精錬可能、モーション変更）がある。アイテムの説明には全部で20の表示があり、魔法チャージ、属性チャージ、強化可能、WarAge での性能低下、指定エリアが加わる。 →
  • グレード別（劣 / NG / HG）の AC と攻撃力、セットのまとめ（グレード別のセット AC、合計重量）。HG / MG は ×1.1、HG は耐久度が半分を切るとさらに ×0.9、劣は ×0.8。例：HG 41.8、NG 38.2、劣 30.5。 →
  • 金属の段階：金属ごとに同じ基本アイテムがあり（銅〜オリハルコン）、変わるのは攻撃力／AC、耐久、重さ、価格だけ。耐久は金属だけで決まる（銅27、青銅26、鉄19、鋼鉄17、銀27、金24、ミスリル22、オリハルコン16、カオス25）。付加効果は、銀＝アンデッドに効果アップ、金＝最大ＨＰ +1（金属フルセットで +7）、オリハルコン＝攻撃力 +1（セットで +7）。金の投げ武器は最大ＨＰ +1、ミスリルの投げ武器はミスリル強化できない。銀の武器はアンデッドへの攻撃力 +20 %。 →
  • ミスリル強化：+4 版と +7 版。無印のミスリルに比べてセットACが +4 で +28.0、+7 で +63（スケール 48.8 → 76.8 → 111.8、ヴァルキリー 66.2 → 94.2 → 129.2、フィニュ 9.1 → 29.1 → 54.1）。「強化可能」の表示がある。魔神の爪と槍の +4 の数値もある。強化レベルごとに1部位あたり 0 / 1 / 2 / 3 / 4 / 5 / 7 / 9 が加わる（+4 は +4、+7 は +9）。強化は1段階ずつで、+1〜+7 のヒットゾーンのマス数は 20 / 15 / 10 / 7 / 5 / 3 / 1（装備の補正で増える）。+4 未満で失敗すると1段階下がり、+4 以上で失敗するとアイテムが壊れる。 →
  • 生産金属セット（42種：全金属のスケール、チェイン、プレート、トール、カオス系、守人、暗黒、ベヒモス）と系統ごとのセットペナルティ（スケールは魔力／回避 −7、チェイン −14、プレート −21、カオス −28、トールは −21 / −35・耐風属性 +35・WarAgeでは性能が低下）。1部位あたり −1〜−5。 →
  • 装備の入手先：鍛冶、裁縫、木工、装飾細工、合成、NPC販売（Pre／War／War奇跡）、モンスターのドロップ、クエスト、宝箱、錬金の各弾、ガチャ、キャンペーン。 →
  • 金属防具の一覧：325種、着こなし 0-91、グレードごとの AC、部位、素材9種。サークレット、ジェット ブーツ（移動速度 +1）、トール（耐風属性 +5）、価格。 →
  • 素材別の修理：綿、絹、皮、カオス → 布修理。木、竹、トレント → 木修理。金属 → 鉄修理（サークレットはアクセサリー修理も可）。骨、石、コバルト、クリスタルは修理できない。素材ごとに修理スキルと必要レベルが決まっている。修理すると最大耐久度が 0.9-0.96 倍に下がる。修理できるのは、CR でなく、素材があり、耐久度のあるアイテムだけ（それ以外は「修理できないアイテムです」）。 →
