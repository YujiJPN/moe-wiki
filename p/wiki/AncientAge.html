  • 自動販売（ベンダーのアセット）：オフラインの間も売る。特殊アセットが必要で、土地グレード 2 から置ける（グレード 1 は特殊アセットの上限が 0）。銀行の 9,999,999 G の上限の前に清算する。「準備中」のベンダーは収納として使える。アイテムと価格を設定、販売開始、並べ替え、お金をクリックして清算。ベンダーは毎日 04:00 に使用回数を 1 失い、150 回 = 30 日（清潔度が高い屋内では最大 75）。「契約解除」でベンダーを削除。ベンダーとノアドールは一度置くと二度とリストに戻らない（最大 300 回の種類もあるとされる）。販売枠はベンダーごとの数まで（最大 16）、合計 10,000,000 未満。一人一個のアイテムは置けない。耐久度 0 や期限切れの土地では変更できない。外すには契約解除しかない。 →

  • 時代間の移動：NPCに「時の記憶」をブランク ノアピースへ記録してもらう。AncientAge用は箱舟遺跡のラッカ・メリア、WarAge用はヌブールの長老イーノスからヤーナ・タングン。それを身に着けてアルターを使うと、その時代が行き先に出る。箱舟遺跡のアルターに乗ると開通する。WarAgeに初めて着いたとき、帰還用のノアピースが装備される。時代間の移動はテレポートウィンドウで行う。 →
  • Ancient Age：ハウジングの時代（Presentの13,000年前）。プレイヤーはハウジングマップで区画を持ち、家を建て、家具や装置（アセット）を置き、自動販売店（ベンダー）を開く。誰でもベンダーから買い物ができ、そこに置かれた銀行や生産アセットを使える。 →

  • 2017年11月の更新：蓄音機のアセット（七賢者の箱 Lv3）は、マナレコードを土地の音楽として流す。曲のリストはキャラクターごとに残る。旅の商人のアセットは自分の土地に置くNPCショップで、修理以外のすべての自動販売アイテムを売る。使用可能回数300（60日）、10,000 G。修理できず、ほかのアセットの上には置けない。ノアドールの美容が修正された。 →
  • ハウジングマップの便利機能：メインアルターで待つと移動速度上昇のbuffがつく（シスでは落下速度低下も）。ゾーン移動やログアウトで消え、/walk で遅くできる。ホーリー レコードは使えるが、外からテレポートはできない。マップの読み込みは遅く、まだ描画されていないアセットは透明な壁になる。ゾーンに入ってから土地情報を受け取り終わるまで、ハウジングの操作はできない。 →

  • 区画の購入：管理エリアの看板に、権利書とエンシェントコイン1枚をドロップする。権利書は使い捨て。1キャラクターにつき6区画までと、予約1つ。区画のグレードで機能は変わらない。権利書はマイレージチケットやキャンペーンでも手に入る。 →
  • 区画の種別と維持日数：コイン1回分で、住宅地6日、高級5日、特別5日、最上級4日。この4種別は1回分がコイン1枚。ほかの種別では1回分にコイン3枚または10枚が必要。 →
  • 引越し：区画を予約し（すでに区画を持っている必要がある）、アセットを片付け、ベンダーを解雇し、家を解体する。グレード、残り日数、ストレージは引き継がれる。予約は1つまで。期限が切れた予約は10日間の返還準備期間に入る。 →
  • 維持費の支払い：ハウジングウィンドウを開き（ボタン、F6のCommand、または /housing）、延長を選んでコインをドロップする。どの時代からでも払える。1枚から払え、365日先までが上限。 →
  • 期限切れと支払保障：期限切れの区画は10日間の準備期間に入り、その後、家とアセットは削除される。一度に30〜49日分払うと保障回数が1減り、50日分以上で2減る（0より下にはならない）。猶予は3回まで。保障回数は「（回数） / 3」と表示される。残り日数が3日未満になると進入できない。 →
  • 土地グレード：所有期間で上がり、毎日約05:00に更新される。グレードポイントは1日100増える。耐久度71〜100 %の完成した家があると1.05倍になる。グレードが上がるポイントは3,000 / 6,000 / 12,000 / 18,000 / 30,000 / 50,000で、それぞれ30 / 30 / 60 / 60 / 120 / 200日かかる。グレード1〜6のアセット上限は32 / 48 / 64 / 80 / 96 / 112、ストレージは8 / 12 / 16 / 20 / 24 / 28、特殊アセットは0〜5。グレード7はアセット128、ストレージ32、特殊アセット6。拡張1回につきアセットは+16、ストレージは+4。 →
  • アセットを置ける範囲：20×20の区画のうち内側の18×18マスと、隣り合う2つの所有区画の間の帯。上にほかのアセットを載せられないアセットがある（栽培、特殊など）。モラハウス系とブロックハウスは屋上にアセットを置ける。禁止されたマスには置けない。アセットリストはアイコン表示と一覧表示を切り替えられる。 →
  • アセットの消耗：消耗度1は使用可能回数40。アセットをリストに戻すと使用可能回数を1消費する。屋外では1日に使用可能回数5を消費する（消耗度1につき8日）。屋内では家の清掃値で変わり、71〜100 %で2、21〜70 %で3、1〜20 %で4、0 %で5を消費する。設置していないアセットは消耗しない。0になると壊れる。耐久度2未満のアセットは設置できない。 →
  • アセットの修理：テクニック「アセット(修理)」で、アセット リペアー キット（30 G、キャンセルしても消費）と修理素材を使う。所有者か、進入を許可されたキャラクターが行える。アイテムとして修理することもできる。 →
  • 特殊アセット（販売員、特殊販売員、ノアドール）：土地グレードによる上限があり、置けるのは「グレード − 1」個まで。上限を超えた分はアセットリストで待機させておけない。上に通常のアセットは載せられない。/tar <near enemy> ノアドールNF でターゲットできる。 →
  • 栽培アセット：1区画に6つまで（アセットの総数に含まれ、設置していないものも数える）。上にも下にも何も積めない。グリーンハウスの屋根には当たり判定がない。入手元ごとの種の容量と初期栄養値は、課金 S 40 / M 60 / L 100 / 鉢 5（栄養値は200中80）、生産 20 / 30 / 50（40）、NPC販売 10 / 15 / 25（20）。栽培アセットごとに必要な土地グレードがある。 →
  • 土地のストレージ：所有者専用の枠で、銀行や所持枠とは別。数はグレードで決まる（8〜32）。エンシェントコイン1枚で4枠ずつ拡張でき、6回まで（+24）。ストレージアセットはそれぞれ2〜4枠を足し、1つのウィンドウにまとめて表示される。NPCキーのアセットは1区画に1種類1つまで。スペシャルキーのアセットは重ねて置ける。権限で他人と共有できる。 →
  • 家の建築：使い捨てのハウスキットを、ポストの家タブにセットする。位置と向きは変えられない。モラハウス2とレンガハウスは隣り合う2区画が必要。建築時間はコテージの約48時間からレンガハウスの約120時間まで、種類ごとに2日、2日12時間、3日、3日12時間、4日、5日のいずれか。スペシャル ハウスキットはすぐに建つ。新築の家は耐久度100 %、完成するまで進捗度0。入るには進捗度100が必要。 →
  • 家の耐久度と清掃値：毎日、耐久度は約02:00、清掃値は約03:00に下がる。修理は木工の「日曜大工」+3と「家(修理)」+30。掃除は美容の「お掃除」+2と「ハウス クリーニング」+30。清掃値の区分は71〜100 高い、21〜70 普通、1〜20 低い、0。耐久度0の家に入ろうとするとポストへ送られる。清掃値が高いと、耐久度の減りと屋内アセットの消耗が少なくなる。家の耐久度は1日1.00 %に係数を掛けた分減り、係数は清掃値71〜100 %で0.75、41〜70 %で1.0、21〜40 %で1.25、1〜20 %で1.5、0 %で2.0。清掃値は1日1.00 %減る。耐久度71〜100 %だとグレードポイントが1.05倍になる。 →
  • 進入権限：土地と家それぞれに「禁止された者以外」（初期設定）か「許可された者のみ」を選ぶ。リストは1つ100名まで。禁止された、または許可されていないプレイヤーはポストの前に出される。中でスモール ワープを使ってもポストへ送られる。禁止されたプレイヤーも、ベンダーからは買える。所有者、許可された者、その他ごとに、銀行、アセットの操作、撤去、ストレージ、ベンダーの設定、ベンダーとの取引ができるかが決まる。土地の役割は管理者、ベンダー利用者、ストレージ利用者、アセット利用者。存在しない名前は追加できない（追加できれば、その名前は使われている）。所有者自身は追加できず、同じ名前は二重に登録できない。 →
