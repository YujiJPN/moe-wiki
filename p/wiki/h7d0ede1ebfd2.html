ルール（20 件）

  • 栽培の上げ方：栽培は肥料を与えたときにしか上昇判定がないので、種取りがおもな方法になる。適した帯の植物なら、成功でも失敗でも上がる。上昇判定は植物の必要値 + 8 を基準にする。 →
  • 栽培のテクニック：栽培（ST 5、発動 200、ディレイ 350）、栽培(種採取)（発動 150、ディレイ 600、植物に少しダメージ）、テンタクル プラント（栽培 80、ST 38、ディレイ 1800、種を消費）、サモン デビル プラント（召喚魔法 90、栽培 90）。 →
  • ドラゴンズ ペレット（薬の材料）は通常のドロップではない。消えていく ストパニ の死体のところでスカベンジャー（デザート スカベンジャー）を倒すと、一定の確率で手に入る。 →
  • 栽培で召喚する植物のモンスター（ファンガス召喚70：Lv 61 …）。ペットのレベル = 栽培 − 9。それぞれ最低スキルがある。 →
  • 栽培（2013/05/07）：畝、グリーンハウス、原木のアセットに種・種芋・菌糸を植えて栄養を与える。植えられるのは種だけで、栽培スキルが種の必要スキル以上であること。苗床の種類はグリーンハウス、畝、原木、植木鉢。育成アイテム、栄養度、収穫の段階、成長段階がある。 →
  • 栽培スキルを上げると、蒔ける種や肥料の種類、種を採れる作物の種類が増え、種採取がうまくなる。種と育成アイテムにはそれぞれ必要スキルがある。 →
  • タイマー終了時の最終栄養度で収穫が決まる：失敗、普通、多い、豊作（タイプA 0-30 / 31-70 / 71-120 / 121-170 / 171-200、タイプB は 121-180 / 181-200 など、キノコ 0-50 など）。戻ってくる種のグレード（初栽培で豊作なら蒔いた種の約30 %）。栄養過多で失敗する作物もある。種ごとに5つの帯（失敗かどうか、栄養度の範囲、主産物、副産物1と2）がある。タイプAの種が100種、タイプBが23種、いちばん上の帯 181-200 が失敗になるものが9種（栄養過多：キノコ）、ほかに小さなグループ。 →
  • 土壌：Ancient Age に土壌アセットを置く（質によって肥効と栄養の減り方が変わる）か、Present Age で貸し農地を借りる。アセットの土壌にはグレードがある。 →
  • 種は土壌の種類に合わせる必要がある（植木鉢はどれでも可）。種のグレードは土壌のグレード以下。アセットの大きさとグレードにより、土壌1つにつき 10-100 個。 →
  • 作物は60分ごとに1段階成長する。作物の所要時間ごとの段階の区切り（120〜360分、ミトヤ 1440）。段階の区切りは種ごとに 60 / 120 / 180 / 240 分など。収穫できる期間は 3日。土壌のグラフィックは段階ごとに変わる。肥料は作物1つにつき5個まで（植木鉢は3個）で、段階ごとに5回ではない。 →
  • 土壌の栄養度の最大は 200。栄養度のバーには色の帯がある。 →
  • タイマーが0になると収穫できる（収穫スキルは要らない）。副産物は種1つごとに判定される。主産物の枠は8、副産物の枠は4。受け取ると「（アイテム名）(個数) を取得しました」と出る。 →
  • 最終値の予測：初期値 + 肥料 − 100。ウィンドウは秒を切り捨てて表示するので、実際の最終値は表示より 0-2 低くなることがある。 →
  • Present Age の貸し農地：アイテム「ノウチ カ リール」5,000 Gold で翌日の23:59まで、30日まで延長できる。グレード1 / 2（種15 / 25個、初期栄養度 20 など）。場所と農地の数。苗床1つにつき契約は1つで、契約者だけが使える。 →
  • 肥料（育成アイテム）の表（水、肥料、虫、金属など：必要スキル、タイプ、栄養効果）。作物の好きなタイプは効果が2倍、嫌いなタイプはマイナスになる。タイプは1-8。栄養度の変化 = 強さ × 個数。促進剤は時間を減らす。 →
  • 種の表：畝（18作物 × NG / HG / MG の種）、グリーンハウス（26作物 + 花6種）、原木（キノコ3種）、副産物（貝割れ菜、わら、モンスターの種）、ミトヤの種（24時間）、収穫例と読者の報告。種は161種で、それぞれ必要スキル、好きなタイプ、段階の時間、作物と戻る種の数が決まっている。 →
  • NPC ブロス（ビスク東）は栽培を説明し、書、アセット、種を売る。種はノッカー、スプリガンもドロップする（モンスター 1 体につき 1 個）。 →
  • 他人の土地での栽培：他人の土地に植えるには進入の権限が必要。進入の権限だけでは、その人のストレージは開けない。ストレージには別の権限（ストレージ利用者）がいる。権限のない土地の区画からは収穫できない。 →
  • Ancient Ageの栽培アセット：1区画に6つまで（どの土地でも同じ）。畝、グリーンハウス、原木 S / M / L があり、土のグレード、同時に植えられる種の数、初期栄養値、消耗度、入手元がそれぞれ違う。土地グレードがそのアセットの必要グレード以上でないと置けない。設置解除すると、栽培中の作物は消える。 →
  • ？？？の種：2013年5月14日〜28日のイベントのアイテム。300分、水を好む。高得点だと宝石が手に入る。 →
