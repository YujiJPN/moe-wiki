項目初心者ガイド

ルール（57 件）

  • キャラクター作成：種族（4種）、性別、髪型、顔、髪の色、名前を選ぶ。髪型と顔は5種ずつ。髪の色は RGB で自由に決められる。職業の選択欄はあるが、作成時のスキルセットは常に「旅人」になる。 →
  • 名前のルール：半角3〜12文字（全角1文字は2文字分）。使えるのは英字、ひらがな、カタカナ。数字、漢字、全角英字は使えない。ほかのキャラクターと同じ名前は付けられない。名前はあとから変えられない。削除されたキャラクターの名前は長いあいだ使えない。 →
  • 作成後の外見変更：髪型、顔、髪の色は美容サービスで変えられる。髪の色は2〜4色の染料を掛け合わせて作る。プレイヤー同士で美容をすることもできる。種族と性別の変更は高額。美容テクニックはほとんど自分には使えない。髪の汚れは、泳ぐか浅瀬で爪先立ちをすると落ちる。髪の伸び具合と汚れ具合は手鏡で確認できる。 →
  • 種族：ニューターはすべての係数が1。コグニートは MP、命中、魔力、呪文抵抗力が高く、HP、ST、攻撃力、防御力、回避、重量が低い。エルモニーは ST、命中、回避が高い。パンデモスはその逆。補正の合計はどの種族も同じ。移動速度の差はない。生産のゲージにも影響しない。採集のダメージには種族の差が出る（攻撃力の筋力の部分に種族の倍率が掛かるため）。称号には種族が限られるものがある。 →
  • 走る・歩く・座る：Alt+Z で走りと歩きを切り替える。走ると ST が減る。歩くと ST がゆっくり回復する。座る（Alt+X）と HP、ST、MP の回復が速くなり、座っているあいだに少しずつ速くなる。自然回復の量は立っているとき、移動中、座っているとき、戦闘中で違い、自然回復スキルで増える。ST が最大 ST の 1 割を切ると、地上での移動が遅くなる（速度 ×（ST の割合 × 4 + 0.6））。ST 30 % 未満の息切れは見た目だけ。 →
  • 重量と重量オーバー：アイテムとゴールドには重さがある。ゴールドは 50 Gold で 0.1（カバンのお金と取引画面のお金に掛かる）。最大重量 = 種族の初期値 + 筋力 × 1.5 × 種族の倍率で、魔法のレイジング、装備、アイテムでも増える。上限を超えると、超過 1.0 ごとに速度 −5 %（+0.1〜+19.9 で −1〜−99 %）。+20 で動けなくなる。ジャンプも座ることもできないが、テクニックは使える。重量の表示は 50000 で止まる。+18 以上で走っても ST は減らない。筋力が 40 未満なら、重量オーバーで歩くと筋力が上がる。 →
  • スキルとステータス：戦士なら筋力、持久力、戦闘技術。魔法使いなら精神力、集中力、魔法熟練。ステータスの元になるスキルは次のとおりで、どれも種族の倍率が掛かる。HP = 生命力 × 3、MP = 知能 × 3、防御力 = 着こなし × 0.2、回避 = 攻撃回避、魔力 = 精神力、耐性 = 呪文抵抗力、重量 = 筋力 × 1.5、ST = 持久力 × 3。 →
  • 隠れ里ネヤのスキル上限：ネヤでは一部のスキルが 5.0 を超えると上がらなくなる（採掘など。破壊魔法と水泳は上がる）。これはネヤの採集ポイント（銅鉱石、苗木、ごま）で鍛えられるのが 5.0 までのため。ネヤのモンスターにはこの上限はない。ほかの場所の訓練用カカシは 30 / 75 まで。モンスターや採集ポイントごとの上限は、テクニックによる上昇だけに掛かる。アンチマクロの疲労が減るのは、ルートと移動距離だけ。 →
  • スキル制：レベルもクラスもない。スキルは行動で上がる。LOCK / UP / DOWN はいつでも変えられる。スキル画面のポップアップか、/setskillctrl <skill> up / down / lock で切り替える。上限に届いてもメッセージは出ない。スキルごとの上限は 100、合計は 850。合計を超えると、DOWN にしたスキルからランダムに下がる。 →
  • 盾：おもに、敵の攻撃に合わせて盾テクニックを使うことで働く。装備するだけでも防御力が少し上がる。ガードに 2 回成功すると盾が 1.0 になり、スキル 1 以下ではとても上がりやすい。ガード中に攻撃されると盾が上がる。ガードの動作中は防御力 × 1.1。回避判定に失敗したときは、軽減量の 80〜120 % を軽減する。防御力では盾の AC × 必要スキル補正が防具と同じように数えられ、盾スキルの項はない（(着こなし + 300) / 350 × AC の合計）。 →
  • 相手の強さを調べる：Alt+C（/consider）でターゲットの強さを調べる。7 つのステータスを比べ、ターゲットが自分の 1.1 倍以上のものがいくつあるかでメッセージが決まる。メッセージは「相手にするのも時間の無駄だ…」から「このターゲットの強さは見ることができない」までの 7 種類だが、実際に出るのは 5 種類。弱い相手へのアクティブ判定とは別。当てにならず、テクニックを使うモンスターは表示より強い。解読スキルが高いと、ターゲットのレベルの詳細も出る。 →
  • テクニックの成功率：必要スキルちょうどで 80 %。1.0 上回るごとに +2.5 %、1.0 下回るごとに −10 %。必要スキルが複数あるときは、スキルごとに計算して平均する。上限 100 %、下限 1 %。基本の武器攻撃は失敗しない。 →
  • リコール ドリンク と リコール レイション（神秘魔法10）は、飲み物と食べ物を召喚する。 →
  • 逃げ方：ガードは連れてこられたモンスターを倒す（例外あり。例：ランダル洞窟のガードとスプリガン）。ガードは戦闘中のモンスターを狙う。モンスターはゾーンをまたいで追ってこない。ターゲットは通りすがりの人に移ることがある。 →
  • 死体の寿命とルートの保護：アイテムの入った死体は288秒で消え、保護時間は115.2秒。ゴールドだけの死体は144秒で消え、保護時間は57.6秒。空の死体は9.6秒で消える。War Age でドロップした死体は57.6秒で消え、保護時間はない。保護時間が切れると「Free」になる。全部取ると死体は消える。ルートウィンドウには分単位で表示される（アイテムの死体なら5分 / 2分）。保持者かそのパーティーが一度ルートすると解放される。Alt+U でルート、中クリックで閉じる。 →
  • ルート権を得るのは誰か：そのモンスターのヘイトが最も高い生存中の相手（ヘイト = 実際に与えたダメージ、吸収、挑発）。横殴りは禁止されていない。撃破メッセージにその名前が出る。パーティーのメンバーが勝てば全員ルートできるが、ダメージは個人ごとに数える（30 + 30 は 40 に負ける）。NPCが勝つと死体は消える。DoTは数えない。ペットや召喚が勝てば、その飼い主がルート権を得る。 →
  • ドロップの分類：7属性のコイン、ランク F〜S の 古びた地図（ランクは地図の番号で決まる）、七賢者の箱（7種類、レベル 1〜3）、悟りの石、宝石、沈没船の耳飾り（shipwreck earrings）。 →
  • チュートリアル用品：秘伝の書とノアピースはログアウトしても消えないが、ネヤの外へは持ち出せない。多くの道具や材料はログアウトで消える。ビギナーズ武器はほかのスキル1の武器より弱い。LO は「ログアウトすると消える」、AL は「現在のエリア限定」。どちらもベンダー、収納、レンタルボックスに入れられない。 →
  • 必要スキル：武器 / 防具の性能は必要スキルの 80 %を超えたときだけ出て（ちょうど 80 %では足りない）、必要スキルに届くと満額になる。そのためスピア（必要 51）は 40.9 から効き、スキル 41 の槍を売る NPC はいない。性能の割合＝スキル ÷ 必要スキル（0.8 未満は 0、1 以上は 1）。命中は 0.8 ＋ 0.2 × この割合。 →
  • 初期武器と消耗：スキル1の武器から始める（スキル21のウッドゥン ソードは 16.9 まで攻撃力が出ない。21 × 0.8 = 16.8）。採集道具のほうが攻撃力が高くて安い（15 G、錆落としに +6 G、200回使うと壊れる）。NPC の武器は錆 / ヒビの状態のカッパー製（修理で攻撃力が上がる）。序盤のサブ攻撃：キック、牙など。耐久度による性能は ×0.6〜1.0 で、劣はさらに ×0.8。耐久度 1 は 40 回分（200回＝5）。道具の採集ダメージは固定。 →
  • 包帯：ターゲット <1> で自分に巻く。NPC の包帯は 8 Gold。コットン バンデージはコットンの布束からハサミを使って洋裁で作る（18 Gold で3つ）。包帯を使うと包帯スキルが上がる。 →
  • ポーション：プレイヤーから買う（NPC のものは割高な見本品）。ポーションの連続使用は対人戦以外では成り立たない。トマトジュースは時間をかけて回復する（140秒で110）。効果の強さは、テクニックの威力曲線に 薬調合 − 必要値 × (1 + 0.01 × スキルボーナスの合計) を当てたもの。アイテム使用のディレイはすべてのアイテムで共通。 →
  • 銃と弾はプレイヤーが鍛冶で作る。NPC が売るのはドワーヴン トライアル−モデルだけで、イルヴァーナ渓谷のドワーフの店で買うにはドワーフの友好度が必要。 →
  • 光源：トーチ（弱）とランタン（中）は NPC から買える。魔法 ライト（明るさはスキル次第、神秘魔法1）、ナイトメア クォーツ（持っているだけで効く）。装備が必要なものもある。アクセサリーの光についての注記もある。なお、リビングデッドはエクゾシズムで解除されず、ウェイクアップ ポーションはアイテム使用ができる間は効く。夜だけ働く光源があり、明るさは時刻で変わる。 →
  • 生産と作成可能リスト：材料がわかっていればレシピは要らない（一部のアイテムは必要）。ボックスに余分な材料がある場合やスキル不足の場合、アイテムは表示されない。2022-01-11 のパッチで、材料の足りないバインダーのレシピを隠す「作成可能」チェックボックスが追加された。必要スキルをすべて満たし、必要な道具を持っていないと候補に出ない。365 のレシピはレシピバインダーが必要。材料の枠は 8。 →

  • プレイヤー間のトレード：相手のキャラクターにドラッグ＆ドロップするか、テクニック トレード（最初から覚えている。忘れるとメニューからのトレードができなくなる）を使う。自動の露店にはオープン セラー／オープン バイヤーが必要。大きな取引は取引チャンネルで。自動販売の上限 100,000 Gold。トレードできるのは、相手が 100 以内にいて、霊体・釣り中・演奏中でなく、フィルター対象でないとき。アイテム 4 枠とゴールドを出せる。NT と盗品は渡せない。ゴールドは 10,000,000 未満。露店は売り／買いのトレード。 →
  • NPC 価格：ほとんどのアイテムは安くしか売れない（肉、骨、牙と一部の採集品は例外）。NPC ショップの価格は大半の触媒を除いて高い。序盤のアイテムの価値の表（ヘビ／ネズミの肉 生 5、焼くと 8。動物の生皮 4 など）。売値 = max(1, trunc(価値 × 0.1))、装備は × 耐久度の割合。買値はショップごとの価格、なければアイテムの価値。 →

  • 操作モード：マウス、FPS（既定）、RPGの3つ。FPSはAltなしで動く。キー設定では、1つの動作に3つまでキーを割り当てられる（Escで消去、DEFで元に戻す、1つのキーに複数の動作も可）。既定のキー設定には約120の動作がある（移動、平行移動、視点、ジャンプ、座る、歩き / 走り、自動前進、自動戦闘、メッセージウィンドウ、パーティのターゲット、ショートカットのページ）。設定できる動作は全部で184。 →
  • メインバーとウィンドウ：メインバーは隠したり表示したりできる。ウィンドウの一覧がある。ウィンドウは最小化でき、最小化したときの位置は別に保存される。方位表示を切り替えられる。時計を右クリックすると、4つの表示（Disp Time / FPS / Net / Direction）を選べる。 →
  • メッセージウィンドウ：システム、会話、戦闘、Auction、Channel、Message5〜6、勢力、検索、演奏結果1〜2の11個。名前の変更、タブ、種類ごとに振り分けるメッセージフィルター、速度を設定できる。/msgclear all / 0-8 で、全部か1つのウィンドウを消す。 →
  • ショートカットバー：ShortcutとShortcut2の2つで、それぞれ10スロット × 10ページ。「Switch Shortcut」で向きを切り替える。Ctrl+Alt+Spaceでウィンドウをロックする。オプション「ShortcutとMenuの同期」は削除された（2011年8月9日）。 →
  • /viewport：3Dビューのサイズを表示または設定する（最小64 × 64、最大は画面の大きさ）。右と下は黒い余白になり、縦の視野角は変わらない。/viewport reset で元に戻す。サイズは解像度ごとに保存される。 →
  • カメラモード：固定1（一人称）、2と3（キャラクターの後ろ）と手動がある。切り替えるとシステムメッセージが出る。キー設定の「視点切替1-3」で切り替える。 →
  • 水と呼吸：止まっていると体が沈む。完全に水中にいると呼吸ゲージが減り、0 になると死ぬまでHPが減る（毎秒 3.125）。PageUp / PageDown で浮上と潜水。水泳スキルで呼吸が長くなり、泳ぎも速くなる。呼吸が続く時間は、水泳0で約26.7秒、70で約123秒。泳ぐ速さは、水中で 0.2 + 0.4 × 水泳 ÷ 100、水面で (1 + 水泳 ÷ 100) × 0.4。水中で水泳が上がる。 →
  • 落下ダメージ：一定の高さを超えて落ちると受ける。重量オーバーで増え、落下耐性、テクニック、装備で減る。新しいキャラクターは8〜10 mの落下で死ぬ。ダメージ = (落下した高さ − (落下耐性 ÷ 100 × 30 + 2))² × 0.8 × (1 + 3 × min(1, 0.05 × 重量オーバー)) × 落下ダメージの倍率。倍率はテクニックや装備で下がり、最小 0.001。ダメージの上限は5000で、完全に軽減しても最低5のダメージを受ける。 →
  • 満腹度と潤喉度：筋力が高いと満腹度が、精神力が高いと潤喉度が速く減る。移動中は × 1.5、ハティル砂漠では × 2（満腹度は夜、潤喉度は昼）。シップが旅人でスキル合計が100未満なら減らない。20未満になると自動で飲食する。満腹度が 0.5 以下だと、座ったときの回復ボーナスと 自然回復 の上昇判定がなくなる。潤喉度が 20 未満だとSTの回復が遅くなる。100から減るたびに髪が伸びる。 →
  • /killmyself：28.8秒後に強制的に死亡する。カウントダウン中は4.8秒ごとにメッセージが出る。チュートリアルのエリアでは使えない。霊体は体を残してホームポイントへ行く（「迷った」ときの助言：Alt+M でマップ）。 →
  • 自分の死体と復活：死ぬと死体が残る。霊体は歩いて死体まで戻るか、ソウルバインダーにスキルのペナルティと引き換えに死体を引き寄せてもらう。死体の回収時間は 死体回収 0 で28.8秒、100 で0.86秒。復活時の HP / MP / ST は 20 %。死体で復活すると満腹度と潤喉度が 0 になり（リザレクション ではならない）、死体回収 の上昇判定がある。死体のルート中は座りと同じように回復する。泳いでいる間は耐火属性 +10。ホームポイントへの自動帰還までの時間はマップごとに決まっている。決まっていなければ、WarAge では 60 + 0.6 × 死体回収 秒、それ以外では1時間。 →
