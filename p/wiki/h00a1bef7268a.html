項目モンスター

行動の種類

各モンスターのページにある行動の種類。

種類行動数
アクティブ（A）プレイヤーを見つけると、レベルに関係なく襲ってくる。601
格下アクティブ（下）プレイヤーを見つけると襲ってくるが、プレイヤーのレベルが 1.4×自分のLv＋2 を超えると襲わない（＋2 の部分はモンスターによって違う）。317
格上アクティブ（上）自分よりレベルが一定以上低いプレイヤーは襲わない。6
友好度次第所属勢力への友好度が一定以下のプレイヤーだけを襲う。231
リンク（L）近くで仲間が戦っていると加勢する、または仲間が戦っている相手を襲う。仲間は同じグループのモンスターと、友好的な勢力のモンスター。726
〜〜がリンク配置ごとに決まった相手で、戦闘になると一緒に襲ってくる。各モンスターのページの「出現場所」にある。

Wiki: 格下アクティブの判定は「(HP＋ST＋MP)/10＋攻撃力＋防御力＋回避＋命中＋魔力＋属性抵抗値合計 ≧ 16.726×Mobのレベル（？）」 実際は強さの評価値ではなく、プレイヤーのレベルで判定する。プレイヤーのレベル ＝ (最大HP÷3＋攻撃力＋命中＋防御力＋回避＋魔力＋属性抵抗 5 種)÷11（各項 0 以上、攻撃力・命中は手に持つ武器込み）。標準の設定では、この 11 項の合計が 11×(1.4×Lv＋2) ＝ 15.4×Lv＋22 を超えるプレイヤーは襲われない。

ルール（32 件）

  • ダメージカット：通常の計算のあと、ダメージと Debuff のステータス低下が、Mob ごとに決まった割合でカットされる。トレント系、ロック マッシュルーム、FutureAge の触手 / 石柱は 80 %、ゴーレム系は 5 %。採集テクニック、ミートボムの追加魔法、特殊矢、光の弾、ソニック ケイジとイーヴル オーメンの固定ダメージ、反射された物理ダメージすべて、武器の固定追加ダメージはカットされない。リープ カーニバルの固定ダメージは通常攻撃として数えられ、カットされる（刀剣 500 → 100）。被ダメージ増加の効果は × (1 + 値)、属性ダメージカットは × (1 − 値 / 100) で掛かる。 →
  • X 無効：Mob が特定の種類の状態異常や攻撃を受けない。 →
  • 詠唱妨害不可：ダメージでも、専用の妨害アイテムやテクニックでも、Mob の詠唱を止められない。詠唱が中断されるかは、妨害への耐性で決まる。 →
  • X 吸収：特定の種類の攻撃を受けると、与えるはずだった量だけ Mob が回復する。属性吸収では、その属性のダメージが 回復量 × 値 になる。ガードにも吸収の種類がある。 →
  • 抽選POP：再POPのときに、決められた種類の中から決められた確率で抽選し、出現するものが決まる。低確率で通常のものの代わりにレアなものが出る。条件Mobが複数いれば、複数同時に出ることもある。抽選で出る場所が決まっていることもある（例：ガブスは寂れた鉱山の5ヶ所中1ヶ所）。単純な抽選POPの組み合わせは17組（ゴールデン ゴーレム / シルバー ゴーレム、ゴールデン ガーディアン / ミスリル ガーディアン、タルタロッサ スパイラル、謎の覆面レスラー、アルビノ スネーク、黒竹 …）。確率の例：ネオク スパイダー 70 / 30。 →
  • repop時間：倒されてから次にPOPするまでの時間。リアル時間で数える（ゲーム内時間ではない）。再出現までの時間がランダムなMobもいる。時間経過だけでは再出現しないMobもいる。 →
  • アクティブの種類：アクティブは、気づく範囲に入った相手をプレイヤーの強さに関係なく襲う。格上アクティブは、強さが一定を超えるプレイヤーだけを襲う。たとえば異国の剣士（レベル145）は、レベルが120より多く下のプレイヤーを無視する。 →
  • 格下アクティブ：自分が弱いと判断したプレイヤーだけを襲う。判定には装備とBuff込みのステータスと抵抗を使う（/consider の評価ではない）。プレイヤーのレベル = (最大HP ÷ 3 + 攻撃力 + 命中 + 防御力 + 回避 + 魔力 + 5種の抵抗（無、火、水、風、地）) ÷ 11。このレベル − 1.4 × モンスターのレベル が モンスターごとの値 + 2 を超えるプレイヤーは襲われない。合計で言えば、15.4 × モンスターのレベル + 22 + 11 × モンスターごとの値 を超えると襲われない。呪文抵抗力を上げると、スキル値 × 種族補正 が5種の抵抗それぞれに加わるので、この判定に強くなる。 →
  • リンク：あるMobがターゲットへのヘイトを持つと、他のMobがそのターゲットにだけ加わる。きっかけは戦闘中のMobなので、密集した群れは一度に複数リンクする。リンクしたノンアクティブのMobは、ターゲットが死ぬかタゲ切りすると戻る。名前つきのリンク（「〜〜がリンク」/「〜〜にリンク」）は、特定の他のMobが戦うと特定のMobが加わるもの。双方に記載がない限り一方通行。 →
  • 同属リンク（例：デスナイト）、無差別リンク、格下無差別リンクについて：野生のモンスターどうしが加勢するのは、決まった仲間を呼ぶ救援だけ。範囲内の同属や、戦闘中のモンスターなら何にでも加わるという加勢の仕方はない。 →
  • 高速攻撃：通常攻撃の間隔が一般的なものより明らかに短い（半分くらい。目安は約5.5秒より速いもの）。攻撃の間隔だけで判断する。攻撃間隔はモンスターごとに決まっている（1149、949、750、500、100 ミリ秒など）。モンスターの攻撃間隔も武器のディレイと同じように扱われる。 →
  • 強さ欄 = Mobのレベル。レベルが高いほどスキルが上がりやすく、そのレベルくらいまでペットを育成できる。レベルは戦闘力ではない（Lv 80 のバルドス デストロイヤーと Lv 85 のケイブ ギガースは、種族で強さが違う）。今は博識でレベルを正確に調べられる。/consider でレベルとステータスが表示されるのは、相手のレベルが解読スキルに応じた上限以下のとき。ペットの成長は、相手のレベルを超えると急に遅くなる（除数 2 + (ペットのレベル − 相手のレベル)² × 2/3）。 →
  • 博識が入る前は、レベルは捕獲、ペットの成長、レゾナンスエイジ時代のレベルから調べていた。一般的な雑魚Mobは ATK = DEX = AGI = レベル（「調べる」コマンド）だが、上位Mobや魔法系Mobはそうではない。モンスターのステータスは 基礎値 + レベル × ステータスごとの伸び で決まる。 →
  • 友好度・信頼度・神の加護は同じ仕組み。NPCやモンスターの勢力どうしが抗争していて、7柱の神のいずれかの加護を受けたキャラクターを同胞とみなす種族もいる。討伐で値が変わる。一定以下になると特定のNPCがアクティブになり、一定以上でノンアクティブになる。「友好を取る」とは、少なくとも「気にしていない」に達すること。友好度は勢力ごとに ±10,000 の範囲。勢力には7柱の神、国家、種族がある。標準的なモンスターは、友好度 −4000 以下のプレイヤーを敵、+4000 以上を味方とみなす。勢力の種類によって、加護 / 好感度 / 信頼度 / 敵対心 と呼び方が変わる。 →
  • 友好度の状態：「友好的だ」= 襲われない。自分のペットのAuto行動で攻撃しない。会話・商店・銀行を利用できる（一部は異なる）。「気にしていない」= 襲われない。ペットは攻撃しない。サービスを利用できる。「嫌っている」= 襲われる。ペットのAuto行動はConsider値によっては攻撃する。サービスは利用できない。ペットは飼い主の友好度に従う。 →
  • 友好度の変動は、倒した本人と、同じパーティーのメンバーに起こる。変わるたびにシステムメッセージが表示される（「Xの敵対心が下がった / 上がった」など。言い方は勢力の種類で変わる）。段階が変わったときもメッセージで知らされる。 →
  • 1体あたりの変動量はMobごとに決まっている。種族全体から疎まれている長（イクシオン族の キング ザブール、青オルヴァン族の オルヴァン マザー）を倒すと、その勢力の友好度だけを大きく得られる。変動量 = trunc(勢力ごとの値 × √倒された側のレベル × 倍率)。倍率はほとんどのモンスターで 1.0、イクシオン族、キング ザブール、工作員タルタロッサ、キャプテン リゴス、ゼウールは 10.0、アクセル / ミクルは 100.0。 →
  • 主な対立7組：スプリガン / トレント ⇔ 青オルヴァン（アルビーズの森）、オーク ⇔ ドワーフ（イルヴァーナ渓谷）、エルビン村 ⇔ ハンター ウルフ / アナコンダ、イクシオン ⇔ タルタロッサ、エルガディン正規軍 ⇔ 反乱軍、マブ教 ⇔ 拝火教、グレイブン ⇔ ビスク / ネオク / サスールNPC。勢力どうしの友好度は勢力ごとに決まっている。 →
  • 神の加護：ユグ = イクシオンの友好、ゲオ = アンデッドの友好。ロザロトはタルタロッサと思われる（上げる方法がない）。ほかの神は何もしない。7柱の神はロザロト（Lazarhoto）、フェンネ（Fenne）、ソレス（Thoress）、ゲオ（Geoz）、ユグ（Yug）、ミトヤ（Mytoja）、シス（Sthis）。討伐による加護の変化の例：タルタロッサを倒すとシス、ロザロトを失い、ユグを得る。イクシオンを倒すとユグ、ミトヤを失い、ソレスを得る。モンスターは、自分の勢力がその神のとき、その神の加護を見る。 →
  • 友好度と加護を変える行動：ビスク / ネオク / サスール / 反乱軍 / 正規軍 / グレイブン / フォレスター / マブ / デスナイト / イクシオン / タルタロッサ / キング ザブールの討伐、チケット無しでの伯爵 フィッシュの釣り、暗使ギルドとサスールのクエストなど。スプリガン、オルヴァン、フォレスター、ドワーフ、エルビン オーガの友好度も変わる。討伐での変化量は 勢力ごとの値 × √レベル × 倍率。クエストなどでは、友好度が加算されるものと、決まった値になるものがある。 →
  • ドワーフの友好の獲得：イルヴァーナ渓谷のオーク ギャング、鉄砲玉オーク、オーク ヤクザだけを倒す（他ゾーンのオークは数えない。ドワーフを倒してもオークの警戒心は下がらない）。初期状態から鉄砲玉10体足らずで「気にしていない」、61体で友好的。オーク ギャングなら9体で「気にしていない」、77体で友好的。ドワーフ マフィアの初期友好度は −5,000。 →
  • オルヴァンとスプリガン両方の友好の獲得：A案 オルヴァンを倒してからオルヴァン マザーを倒す（オルヴァンだけが上がる）。B案 一方をMAXにしてから、他方をその半分程度倒す。友好度に関係しないMob：三竜、オルヴァンの卵、ドライアッド ガーディアン、森の外のオルヴァン、ノッカー。初期状態からの数：スプリガン ウォッチャー15体 + スプリガン ウォリアー49体 → オルヴァンが「気にしていない」。オルヴァン ブルート63体 → スプリガンが「気にしていない」、163体 → 友好的。初期友好度はどちらも −9,000。オルヴァン ブルート1体につき80上がり、ちょうど63体で −4,000 を超え、163体で +4,000 に届く。 →
