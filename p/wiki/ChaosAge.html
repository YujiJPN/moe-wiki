ルール（6 件）

  • ChaosAge：多くのプレイヤーが強大な神獣と戦う。毎週末の決まった時間にのみ開く。カオス・スペース【時の間】から6つの門へ入る：地 NGK、火 SGK、冥 IGK、風 EGK、水 WGK、天 LoC。門番のノーザン / サザン / ウェスタン / イースタン / インフェルノ ゲートキーパーはレベル 230 / 240 / 250、ロード オブ カオスは 260 / 280 / 300。天の門は時刻が18:00に固定されている。 →
  • カオスゲートの開放時間：公式の開催は土曜と日曜の17:40、19:40、21:40で、各9分（週末に6回戦）。ゲーム内では、ゲーム内の曜日と時刻 17:50-17:59、19:50-19:59、21:50-21:59 で開く門が決まり、入場メニューにその門が出る。 →
  • 入場条件：総スキル850未満のキャラクターは、ChaosAge「時の間」へ入れない。判定はイプス雪原のカオスの入口で行われ、満たさないと総スキルが850に達していないと告げられる。 →
  • 各門の定員：350人。満員の門に入るとイプス雪原に戻される。通常のマップの定員は2000人、1人用インスタンスは1人。 →
  • ChaosAgeの報酬：全門制覇で、HP +3の非破壊の胸装飾と、カオスバインダー用のクリスタル3個。マナレコード [ BGM List : 2 ]（蓄音機にトレード）が、クリア報酬、黒の廟堂、沈没船、トレジャーハントに追加された（パッチ171024）。CAの生産武器 メフィスト シリーズ（鍛冶と裁縫、パッチ171031）。カオスの宝箱からは、カオスの布束 / なめし革 / 板材 / インゴット、カオス ポーション、クリスタル、光の弾 / 光の矢、ゴッド アイ、原初の粉、混沌のコイン、レア装備が出る。 →
  • ゲート内（ChaosAge のカオス・スペース6マップ）で死亡して帰還すると、ゴールドと CA（カオスエイジで死亡しても消えない）のアイテム以外は、バッグ、装備、レンタル収納ボックスの中身がすべて失われる。パッチ 170124 で アニマル ケイジ が CA になり、中でペットを入れ替えられるようになった。 →
