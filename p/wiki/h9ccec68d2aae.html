項目シップ/シップブレンド

ルール（6 件）

  • ブレンド名：使えるのは、キャラクターが現在就いているシップの単語のみ。「ランダム」はその中から3つを選ぶ。ブレンド名は、STATUS、ゾーン情報、considerのメッセージで本来のシップ名と併記される。チャットでは使われない。個人を特定しない公開名として意図されている。画面には「就いているシップ一覧」「選択できるブレンド名」と、オプション「他ＰＣの名前表示をブレンド名に変更」がある。 →
  • ブレンドの単語：シップ称号ごとに単語のグループがあり、各最大7語（戦闘のみのスキルにはない）。グループは85、単語は874語。旅人は種族名 ニューター / コグニート / エルモニー / パンデモス と、つなぎの語 オブ / なる / の を与える。すべての基本スキルと、すべての複合シップ（WAR … ELM）にグループがある。例：ボク / サー / フィスト / マスター。後から追加された称号の単語もある。 →
  • 特別な称号：2024-03-05から、コラボレイド「ジャガーノート」の討伐で特別な称号が得られる。2024-05-18以降、称号はすべて期間限定。 →
  • 特別な称号の単語：ダンまちコラボレイド（8語）、青の廟堂オープンテスト（8語）、クイズアタック！ほか（4つの入手元、32語）。グループはダンまち8語、ベータテスター8語、アニバーサリー7語、新成人1語、ありふれた8語。 →
  • シップブレンド名の編集ウィンドウ（2012-03-21 のパッチ）：最大3語から表示名を組み立てる。/window shipnameblend、コマンド一覧のボタン、ゾーン情報のPC一覧の「SHIP NAME BLEND」ボタン、またはステータスウィンドウから開く。 →
  • 称号表示のオプション（2023-12-12）：キャラクター名の上に称号とブレンド名を表示する。System > Option > 表示 > ビルボードで設定し、既定はオフ。「他PCへの表示を許可」もある。ブレンド名はゾーン情報の「Blend」ボタンから設定する。 →
