自然回復

このスキルだけで使えるテクニックはない。

ルール（19 件）

  • 落下耐性の上昇：落下ダメージを受けると上がる。ダメージ 0 では判定がない。小さなダメージでは上昇も小さい（上昇のレートは min(ダメージ, 10)）。100 % 軽減の装備でも、落下ダメージは 0.1 % 残る。 →
  • 水泳の上昇：息継ぎをせずに水中にいると上がる。呼吸ゲージが低いほど速く上がる（レート (1 − 呼吸 × 0.01) × 0.7。潜った直後は 0.3）。タイプ C で、一定時間ごとに判定がある。深さによるアンチマクロがあり、場所を移すと解除される。 →
  • 死体回収の上昇：自分の死体を回収して蘇生すると上がる。水中で回収中に沈みすぎると判定がない。ウィル オー ウィスプでの失敗上げは 70 まで。スキル値ごとに必要な死亡回数の表がある。 →
  • 包帯の上昇：相手の HP が減っていると上がりやすく、約 2 倍（減っていれば 1.0、満タンなら 0.5）。他人に使うと判定が 2 回かもしれない。どの包帯でも 100 まで上がる。97.67 で 1 回 +0.0010。0.0042 刻みで上がる。 →
  • 自然回復の上昇：HP、MP、ST のどれかが最大の 1/1.1 未満のときに座ると上がる。満腹度 0.5 以下の空腹時は上がらない。HP を減らして座るのが上げ方。プレイヤーの計測記録がある。 →
  • 包帯の中断：包帯の使用中に 3 回攻撃を受けるとキャンセルされる。回復せず、スキルも上がらず、包帯は消費される。包帯のように 3 回目の被弾で止まるもの以外は、集中力に応じた確率で使用を続けられる。 →
  • 自然回復を止めるもの：バーサーク、エピデミック オール、ディスロケーション、パラライズ ファング。自然回復スキルが効果ごとの必要値以上なら、その効果の下でも回復が続く。バーサーク中も60からSTが回復する。約57で走ってもSTが減らなくなる。自然回復量を 0.25 倍にする効果もある。 →
  • 60秒あたりで示される回復バフ：HP / ST / MP 自然回復量UP Lv1-3、HP/スタミナ などの複合の自然回復量UP、スペシャルドリンク、コンデンスマインド、ブラッド ディール、魔法熟練、荒くれ者 と アスリート の マスタリー、加護。スキルの効果が止まってもバフは効き続ける。魔法熟練 100 で MP が毎秒 +0.2 回復する。 →
  • 包帯はテクニック：無印、コットン、シルク、ファイン シルク、カオス（ChaosAge のみ、30から）、マグネット（ST）。時間 8-15秒、重さ 0.01 / 0.02。スキル別の回復量表がある（目安はスキルの40-90 %）。リフレッシュ バンデージ（70、ST と ＨＰ を回復）とジェネレート バンデージ（80、最大ＨＰと自然回復のバフ）。70台後半から包帯がポーションを上回る。包帯の必要スキルは 0 / 30 / 60 / 70 / 80。 →
  • 泳ぐ速さ = 地上の速さ × (A + 0.4 × 水泳) × (1 + 泳ぎ速度ボーナス) / 100。A は水中 20、水面 40、近海 60（ミーリム近海など）。泳ぎ速度の装備がある。 →
  • 水中での行動時間 × (2 − 水泳 / 100)、近海 × (1 − 水泳 / 500)。ディレイには影響しない。 →
  • 水中では浮くのが沈むより遅い。沈む速さは最大 5.6 m/s、浮く速さは最大 2.8 m/s で半分。ジャンプ力を変える効果は水中では沈み方を変えるので、Hands of Curse を受けると水中で下に引っぱられる。 →
  • /killmyself：強制的に死亡するコマンド。実行まで約30秒（28.8秒）かかる。プレミアムではすぐに実行される。受けるダメージは HP + 1。 →
  • 落下ダメージ：安全な高さ = 落下耐性 × 0.3 + 2 m。ダメージ = (落下した高さ − 安全な高さ)² × 0.8 × (1 + 3 × min(1, 0.05 × 重量オーバー)) × 落下ダメージの倍率。上限は5000。計算結果が 1 以下ならダメージはない。水中ではダメージを受けない。真のダメージで、装備は消耗しない。 →
  • 呼吸と溺れ：潜っていられる時間は、水泳0で約26.7秒、100で200秒。呼吸が 0 になると溺れて、毎秒 3.125（毎分 187.5）HP 減る。溺れても霊体にならない場所がある。水中呼吸の効果があると、呼吸は100のまま。 →
  • 死体の回収時間：死体回収 0 で28.8秒、100 で0.86秒。 →
  • WarAge では、死亡から 60 + 0.6 × 死体回収 秒後にホームポイントへ強制的に帰還する。マップごとに時間が決まっている場所ではその時間。WarAge 以外では3600秒。 →
  • 自然回復（60秒あたり、スキルごと）：座りHP 24〜99、座りST 180〜305、立ちHP 6〜42、立ちST 120〜180、立ちMP 14〜50。テクニックの使用中と走り中はSTの回復が下がる。r = 自然回復 ÷ 100 として、HPは立ちで (6r + 1) × 基本値、座ると (12r + 4) × 基本値まで増えていく。MPは立ち (3r + 1)、座り (18r + 4) に 魔法熟練 の分が加わる。STは移動中、静止、座りで回復量が違う。詠唱中やチャージ中は 自然回復 スキルの分だけになり、その後1.44秒立っていると立ちの回復量に戻る。 →
  • 満腹度と潤喉度が低いと回復が下がる。満腹度が 0.5 以下だと、座ったときの回復ボーナスがなくなり、自然回復 の上昇判定もなくなる。潤喉度が 20 未満だと、STの回復が × (潤喉度 × 0.0375 + 0.25) になる。 →
